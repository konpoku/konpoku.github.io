变拍子的创作方法

2026.09.05节奏论
节奏论进阶节奏：复拍子、摇摆律动与变拍子

在上一讲学习了“多重节奏（Polyrhythm）”之后，仿佛通往更繁复深邃的节奏宇宙的大门已被正式推开。而在本讲中，我们将探索若想在节奏上玩出与众不同的颠覆花样时必不可少的主角——“变拍子（非常规拍子）”。

1. 何谓变拍子

流行通俗音乐的律动绝大多数均以“4”或“3”为基本脉搏。 以桑巴为代表的“2/2拍”本质上与4拍子非常相通，而“6/8拍”则是3与4嵌套的复拍子。 除通俗大众音乐中所使用的这些常见规整拍子之外的所有拍子，统称为变拍子（Irregular Time / 非常规拍子 / 奇数拍）[1]。

节奏是音乐赖以立足的基石骨架，将其复杂化往往意味着会在很大程度上牺牲通俗大众的传唱度。正因如此，在纯粹面向大众市场的流行歌曲中鲜少见到变拍子的踪影，它更多活跃在前卫摇滚（Progressive Rock）或爵士乐等极富技术探索与艺术野心的实验流派中。

2. 聆听变拍子

创作“变拍子”曲目的核心手法，通常是对已有规整拍子进行拼贴组合、或做加减法。

7拍子（七拍子）

将4拍子与3拍子拼接在一起，或者将“4拍子 × 2”减去1拍来构建节奏，得到的就是“7/4拍”。在所有变拍子中，7拍子属于亲和力最强、相对最易上手的经典款。

由于其推进速度比常规的4拍子×2更为紧凑急促，极易营造出速度感、焦灼感与剑拔弩张的紧张悬念，在音乐情感表现上极富感染力。 在人声歌曲中，有时为了兼顾副歌的洗脑流行感，会特意只在副歌处回归常规拍子——在上述歌单中的《scat》，其副歌便回归了标准的4拍子。

依托歌词巧思的7拍子

 打开音乐示例 ↗ 这是一首极其风趣幽默的佳作：因为主题是一周的“7个星期天”，于是顺理成章采用了7拍子。从1:12开始连续报菜名式念诵星期名称时，从周一到周日悠闲数来刚好严丝合缝占据“7拍”；然而当换作双倍速快嘴演唱时，念完一轮自然只耗费了原本一半的“3.5拍”，导致伴奏底轨与人声旋律的周期发生了错位——此处巧妙叠加了*多重节奏（Polyrhythm）*的高阶技法。在尾声部分甚至还穿插了一个星期占1.5拍的变异模式，将节奏游戏推向了极致。

5拍子 / 10拍子

在3拍子上追加2拍，或者在4拍子上追加1拍，得到的就是5拍子。相比7拍子，5拍子的律动掌控难度陡增，更偏向高阶进阶者。

霍尔斯特（Holst）的交响诗《火星》（Mars）以及《碟中谍》（Mission: Impossible）标志性的主题旋律，均采用了独树一帜的5拍子律动；但它们都通过将极具辨识度的标志性乐句翻来覆去不厌其烦地循环往复，帮助听众建立起听觉惯性。这种体贴听众认知的巧思，在驾驭变拍子时至关重要。

King Crimson的《Larks' Tongues in Aspic, Pt. 2》以6/8拍为基底，在此基础上追加了4拍，因此在本质上构建成了“10/8拍”。

其他奇绝变拍子

变拍子的可能性浩瀚无垠。许多前卫音乐家早已跨越了7拍子与5拍子等常规套路，向更加天马行空的非对称拍子发起了挑战。

这是日本殿堂级前卫摇滚乐队“KENSO”的代表作。开头由11拍与9拍交替出现，随后的独奏段落则通篇维持在9拍子，节奏编排令人目不暇接。其9拍子段落的骨架依然能依稀嗅出4拍子鼓点的痕迹，尤其在第2拍准确敲响军鼓；然而下一声军鼓的落点却并未落在第4拍，而是错位滑到了后半拍反拍上，以此切分音为契机落点一路颠簸，最终不是以8拍而是以9拍构成一个循环闭环……

9拍子段落的骨架大体如上所示。如果它只是单纯的“3拍子 × 3 ＝ 9拍”，自然不能叫变拍子；但这种节奏明明以4拍子为底盘，中途却产生错位颠簸，不知不觉间拉长成了9拍，堪称如假包换的硬核变拍子典范。

4与2的复合交错

由4拍子与2拍子相互穿插构成的节奏，乍听之下似乎并不觉得十分古怪，但这同样属于广义上的变拍子。  打开音乐示例 ↗ 这首歌由“4 + 2”的6拍子构筑，核心在于它绝不同于传统“3 + 3”的温和6拍子。“4的律动”与“2的律动”轮番交替登场，听起来别有一番捉摸不透的奇妙悬浮感。  打开音乐示例 ↗ 这首作品在主歌部分则采用了“2 + 4 + 4”的10拍子组合，架构极为新颖独特。

这种“通篇只用4和2”的把戏，美妙之处在于让听众心中同时涌起“熟悉亲切”与“陌生新奇”的双重错觉，带来宛如被施加了迷魂法一般的奇异快感。

拍数规整却无比诡谲的异常节奏

行文至此大家应该已经体会到：决定节奏灵魂的并非拍子的纯粹总数，而是重音的具体安放点。因此在这个世界上，还存在着大量“总拍数算起来平平无奇、听起来却诡异荒诞至极”的先锋神作。  打开音乐示例 ↗

这是弗兰克·扎帕（Frank Zappa）于1969年创作的先锋之作。旋律支离破碎、极不规整，乍听之下仿佛彻底摆脱了拍号的束缚；然而在底层架构中，所有声部完全是严格以3拍子为周期单位精密严整编写的。由于重音被故意虚化模糊，普通聆听极难辨析为3拍子，但各乐器声部均严格遵循3的倍数展开，洞悉这一数学逻辑后再去审听，便能神奇地感受到3拍子的底层脉动。

这首作品基底通篇都是标准的4拍子，但声音极其破碎离散、随机性拉满，听起来令人眼花缭乱。堪称混沌与秩序交融的杰作。随着乐曲层层递进，其严整的骨架全貌才逐渐从迷雾中破土而出。

3. 如何打造优秀的变拍子

从这里开始，我们切入实战作曲环节。假如我们怀揣着对变拍子的憧憬，试着做一下拍子的简单加减法： 4拍子加上1拍，变成5拍子了！这就迈入变拍子大师的行列了吗……然而听听看便知，这纯粹是在机械做数学加法，音乐本身的魅力荡然无存。既然敢于触碰变拍子这一高阶创作领域，“散发出一种被变拍子玩弄手忙脚乱的笨拙感，一切就全毁了”。作曲者必须展现出“将狂野节奏彻底驯服驾驭的从容自信”。那么究竟该如何做，才能让变拍子听起来自然高级呢？

用灵魂乐句统领大局

刚才反面教材的另一大败笔，在于通篇只是呆板地按和弦，完全没有一条提纲挈领的核心乐句（Riff）。在构思变拍子时，只要有一条行云流水般完美咬合在该拍子上的标志性乐句在上方领跑，它就会化作强劲无比的指南针。这更能赋予整首作品“正因为是这句绝妙旋律，才必然催生这一拍号”的强大艺术说服力。

这是一段7拍子的范例，合成器的高亢乐句牢牢掌控并统领着全场。即便其他乐器声部轰鸣跌宕，但由于高频区始终回荡着坚定统一的引导乐句，拍子的骨架便获得了坚不可摧的稳固感。

虽然是7拍子，但左侧电吉他的乐句堪称绝妙。通过不断层叠切分音让乐句提前收尾，极其巧妙地淡化了“比常规的4拍子×2少了一拍”的缺口违和感。

前卫摇滚巨匠Yes乐队的传世代表作。前奏由“8拍 + 7拍”构成15拍的宏大循环。0:25起吉他的演奏精妙入微，看似在不断重复完全相同的动机，却通过微妙调整长音延展的时长，不着痕迹地掩盖了拍子的缺失。7:01起的那段神秘变拍子段落更是神乎其技。

这是Yes于1994年创作的超长篇史诗。全曲开头的2分钟通篇处于5拍子之中，器乐乐句宛如向导般引领着5拍子的平稳起伏，尤其在1:29至1:37处的声部编排堪称艺术登峰之作。

4. 打造兼具可听性的通俗化变拍子

敢于涉足变拍子，作品无疑已注定具备激进硬核的气质；但在硬核之余，若希望能兼顾一定的流行可听性（Pop sensibility），就必须施加特殊关照。接下来我们探讨如何帮助普通听众清晰明了地领悟复杂拍子的润滑技巧。

鲜明强化小节强拍头音

最质朴有效的手段，是用极具记忆点的抓耳乐句大力强调小节的“第一拍强拍”。 前文提到的《碟中谍》主题曲之所以老少皆知，正是因为其核心旋律线条永远极具穿透力地精准砸在小节的第一拍强拍上，使整体拍子框架昭然若揭。

这种方式虽然清晰明了，但若处理不慎极易沦为刻意强调的笨重感，因此极其考验审美品味。

善用弱起（Auftakt / Anacrusis）

更为推荐的高明手段，是在旋律线条中精妙融入弱起（Auftakt / 弱起小节）。我们在旋律篇第I章中曾详解过这一概念：即旋律在小节第一拍强拍正式到来之前，抢先提前起跑发声的形态。

例如面对上图所示的5拍子歌曲，通过在弱起处连击两个八分音符，便能在听觉上向大脑抛出‘新小节即将破茧而出！’的预告警报。听众的大脑便能提前预判强拍落点，并在强拍降临时毫无障碍地顺畅接纳。  打开音乐示例 ↗

这首歌曲中不时穿插着7拍子，但“Here it comes”这句歌词永远以弱起姿态冲刺领跑，听众借由“Here it”便能从容预知小节更迭的交界，使得变拍子的突兀感在无形中被彻底化解。

这首歌在尾声切入了7拍子，但每次都会伴随“嗒——嗒——”两记四分音符的重击，小节的分界格外清晰分明；当人声加入后，“I don't”同样充当了弱起跳板，赋予了听众舒适自如把握强拍的指引。

像这样，在人声流行歌曲中若想让变拍子听起来通透亲民，弱起是一张威力绝伦的王牌。切莫单纯满足于拍号数学层面的奇特，更要专注于用优美的乐句引领听众享受律动的起伏翱翔。

总结

  • 除3拍子与4拍子等规整通用拍子之外的拍子，统称为“变拍子（Irregular Time / 非常规拍子）”。
  • 7拍子与5拍子是变拍子家族中的中流砥柱。凭借创造力，我们能够编织出无穷无尽的奇绝节律。
  • 在构建变拍子时，通过重组微观单元、错位挪移重音矩阵，往往能孕育出兼具灵动与高级感的作品。
  • 处心积虑为听众搭设预判小节分界的向导桥梁，能让变拍子作品兼具流行亲和力与艺术深度。
