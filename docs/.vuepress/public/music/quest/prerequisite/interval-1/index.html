度数与音程

在本文中，我们将介绍在正式深入音乐理论时极其关键的核心度量衡——“度数（Degree）”。

1. 什么是度数

突击提问：这里有一组音符“Do 与 Mi”：

当然，世间还存在另一组音符“Do 与 Sol”：

那么请回答：从“Do 到 Mi”，与从“Do 到 Sol”，哪两颗音符之间的音高间距拉得更开、距离更远？

……根本无需多想，用肉耳就能听出必定是“Do 与 Sol”之间的距离更宽。

紧接着是第二个问题：那么“Do”与“Sol”之间，究竟相隔了多远？

看，哪怕是如此简单朴素的一个日常问题，如果不曾建立专属的专业语汇，我们就会卡壳在“无法精准描述”的窘境中。音乐是音符交叠的艺术；为了系统剖析音乐，我们必须拥有专门度量‘音与音之间距离’的度量单位。

测量物理距离可以用“厘米 / 米”，但在声音世界里量度音高，拿米尺显然荒谬，直接报声波振动频率 Hz（赫兹）又显得过于繁琐不直观。人类最终选定了一种最原始、最直观的计量方案——“数经过了几个唱名（Do-Re-Mi...）”。

从“Do 到 Mi”，中间涵盖了 Do、Re、Mi 总共3个唱名音级，因此我们将这段距离表述为“3度”。这里所使用的计量单位正是“度”。而这套衡量音距的单位体系，在乐理中统称为“度数（Degree）”。同理，从“Do 到 Sol”，涵盖了 Do、Re、Mi、Fa、Sol 总共5个音级，因此它们之间的距离便是“5度”。

计算规则的易错陷阱

必须郑重提醒：在数度数时，必须把起点的“Do”和终点的“Sol”同时算进去！初学者极易犯“减法思维”的错误，下意识从下一个音开始数：“从 Do 到 Sol……Re、Mi、Fa、Sol，这不只有4个音吗，所以是4度？！”——这种算错度数的情况屡见不鲜。

计算度数的规则，与日历上计算假期天数的逻辑完全一致：起始日和截止日必须全部算作有效天数。只要牢记这一点，就绝不会出错。

比如公司通知8月8日至8月15日放假，这实际上是整整“8天连休”，而不是 15 - 8 = 7 天。算度数也是完全相同的机制。

顺着这个逻辑推导：如果两个音都是“Do”，即所谓的*“物理距离为零”的完全同音状态*，因为同样包含了一个“Do”音级，因此也被算作“1度”（一度 / 纯一度）！这是新手必须适应的第一个反直觉设定。

为什么距离为零却算作“1度”？

为什么度数的计数不是从0起步，而是从1开始？学术界有一种观点认为：在西方乐理这套度数计量法深入人心普及开来之时，阿拉伯数字中‘0’的概念甚至还没有正式传入欧洲。起初或许略显别扭，但一旦习惯之后便会觉得无比自然。

2. 实际应用场景展示

度数不仅是和弦理论的核心基石，更是贯穿整个音乐世界的通用度量衡。如果你有接触过声乐演唱或流行编曲，大概率听过“唱下方三度和声（三度下和音）”这样的专业术语。

例如上面视频 2:15 处的经典和声织体。所谓“唱下方三度和声”，是指当主唱旋律演唱“Do-Re-Mi”时，和声伴唱在下方以完全精准的3度音程——即对齐演唱“La-Si-Do”来进行声部烘托。

在录制和声伴唱时，“下方三度”堪称整个流行乐坛最经典、最稳健的大路货黄金范式。相对地，如果换成“上方三度和声”，听感则如下所示：

在音阶解构中的应用

在其他应用场景中，例如我们在前面章节讲解过的“关系大小调（平行音阶）”——“组成音完全相同，仅仅将重力中心位移的音阶”。

此前我们用大白话描述为：“将 C 自然大调的中心主音向下方挪动两个音级，即可得到 A 自然小调”。如果换成严谨的“度数”语言，表述就会升级为：“将 C 自然大调的中心主音向下方移动3度，即可获得 A 自然小调”。

再次警惕“算数加法”的思维误区

这种“上方3度 / 下方3度”的日常行业说法，其实相当具有欺骗性。当听到别人说“请弹 Do 的上方3度音”时，人的数学本能往往会下意识去数：“Do 的上面……第1是 Re、第2是 Mi、第3是 Fa，所以是 Fa 吧？！”——这又是大错特错。在音乐约定俗成的习惯中，“Do 的上方3度”指的正是 Mi。

这与纯粹的算术加减法感知是脱节的，请务必格外留心。“Do 的上方3度音”，其严谨本意应当解读为：“在 Do 的上方、与 Do 构成3度音程关系的那个音”[84]。

正因如此，在音乐度数的世界里，现实中基本不存在所谓‘上方1度’或‘下方1度’这种古怪称谓。因为 Do 的上方1度（强行理解的话）依然是 Do 本身，所以大家绝不会用这种令人困惑的说法。

跨越八度的音程度数

当两音距离超过一个八度时，计算方法完全一致。例如“低音 Do 与其高八度之上的那个 Mi”：

此时构成的音程是“10度”。对比原本普通的 Do 到 Mi，由于中间多跨越了一个包含7个自然音级的完整八度，原本的“3度”再加上7，便演变成了“10度”。由此我们可以提炼出一条通用速算公式：“两音每拉开一个八度，其度数数值便递增 7”。

3. 涉及黑键与升降号的情况

哪怕音符带有升降号（如“Mi♭”），基础度数的计算方式依旧保持不变。例如“Mi♭ 到 La”，由于跨越了 Mi、Fa、Sol、La 总共4个音级，因此依然属于“4度”范畴：

然而，从物理键位上看，“Mi♭”与“Re♯”敲响的是同一个物理黑键——这正是前文讲过的“异名同音（等音）”。在实际编曲中，根据调性与前后和声走向，其理论归属会有明确的分野。如果从记谱逻辑上看它此时扮演的是“Re♯”，那么从“Re♯ 到 La”，跨越了 Re、Mi、Fa、Sol、La 总共5个音级，度数性质便立刻跃迁为了“5度”：

初听之下或许会觉得过于学究气，但究竟何时该视为“Mi♭”、何时该视为“Re♯”，随着后续深入学习调性与和弦，其内在脉络自会变得无比清晰。

4. 更高精度的详细度数划分

读到这里，敏锐的朋友大概已经察觉到了当前计数系统的一个巨大破绽：在当前的粗略规则下，“Do 到 Mi”与“Do 到 Mi♭”，竟然全都被笼统地叫作“3度”！

两者在谱面上确实都跨越了 Do、Re、Mi 三个唱名，但听感上一个是明朗的大三度、一个是哀伤的小三度，音响色彩有着云泥之别。如果永远停留在粗略的数字上，在深入讨论和声细节时就会遇到严重阻碍。

因此，为了追求绝对精准，乐理中设计了一整套更为严密的“细分命名法（大度数、小度数、纯/完全度数、增减度数）”……但这套命名规则相对繁琐，向来是劝退新手的另一只拦路虎。老实讲，如果仅仅是讨论单音旋律线条，目前掌握的“纯数字简易度数”已经能够应付大半场面。因此在“预备篇”中，我们点到为止，先不给大脑增加过载负担。

而在后续讨论和弦理论时，精细化的度数划分将是必须直面的核心工具。在自由派音乐理论中，我们将本节掌握的简易数法命名为“简易度数”，而将后续在和弦篇中系统深究的严密命名法称为“详细度数”，以便在不同场景下各取所需。

5. 音程（Interval）与音高（Pitch）的明晰辨析

回顾通篇，我们一直在通俗地使用“音的距离”这一表述。而在严肃的音乐理论中，这两颗音之间相对的音高间距，被正式定义为“音程（Interval）”。

在当下大众口语中，“音程”一词常被严重滥用与误解。比如在 KTV 唱歌跑调时，常有人脱口而出：“哎呀，你这句‘音程’唱偏了 / 音程不准”。然而从严格声学定义来看，这种说法纯属概念混淆——衡量一个音唱得准不准、高还是低，其规范术语叫做“音高（Pitch / 音准）”。在编曲修音软件中我们常说的“Pitch 校准”，校对的正是“音高”；而“音程”，则专门指代“两个不同音符之间的相对高低跨度与间距”。

音程（Interval） : 两颗音符之间相对高低间距的跨度。在音乐中通常使用“度数”作为专属单位来衡量与表达。

音高（Pitch） : 某个具体声音在物理振动上的绝对高低位置。 : 在现代乐理中，通常使用英文字母加八度标号（如“A4”、“B♭1”）来精准指代，在物理声学中则以具体振动频率 Hz 表示。

度数（Degree） : 在度量两音之间的“音程”跨度时所采用的专属计量单位。 : 通过计算两音之间跨越了几个唱名音级来得出。

鉴于现代大众语境下“音程”一词已经被泛化得面目全非，本网站在后续的表述中，将尽可能克制使用容易引发歧义的“音程”，而更多直接使用更为精准干脆的“度数”。音的距离是“音程”，而测量音程的刻度尺便是“度数”——在实际运用中，“分析音程”与“推算度数”在绝大多数语境下本就指代完全同一件事。

核心小结

  • 用音级跨度来度量两个音符之间相对距离的数值，在乐理中统称为度数。
  • 音距的度量，本质上是通过数其间跨越了几个“Do-Re-Mi”自然音级来完成的。在计算时，请务必千万牢记：起始音必须一并计入总数！
