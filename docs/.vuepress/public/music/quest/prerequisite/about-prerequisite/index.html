1. 预备篇的学习内容

在预备篇中，我们将学习进入旋律篇与和弦篇所必需的前置基础知识（阅读节奏篇并不强制要求预备篇的知识）。具体而言，我们将系统梳理诸如“音阶”与“调（Key）”等你在过往音乐课中或许曾有所耳闻的核心概念。

在后续的正文中会出现形形色色的专业术语，但绝不存在“如果不把它们全部倒背如流就寸步难行”的严苛要求。正文中会尽可能提供对应基础知识的跳转链接，正如体例指南中介绍的那样，本站全面内置了即时浮窗帮助系统。只要初次阅读时在逻辑上达到“基本理解”的程度，具体记忆和内化完全可以在日后的实战中慢慢完成。

入门关卡往往最显抽象

事实上，作为起步门阶的这篇“预备篇”，反倒可能是学习过程中最容易让人产生困惑的难关。因为这里是在提前铺设未来所需的知识基石，这些概念唯有在真正进入旋律篇与和弦篇的实战编配之后，才能带给你强烈的实感与恍然大悟的体验。在当下的纯理论阶段，难免会觉得内容有些抽象、甚至略感难以消化。

因此唯独对于预备篇，我们强烈建议抱持着“反正后面还要经常回查”的轻松心态来阅读。即便遇到一时半会儿未能彻底领悟的细节，也完全可以放宽心继续向后推进。待学完旋律篇或和弦篇后再回过头来重温，一切自会豁然开朗。

2. 基础专业常识速查

在正式踏入严肃的音乐理论大门之前，我们先来快速确认几项最基础的音乐常识。

五线谱的基础识读

原则上，我们希望读者能够在日常中通过其他途径逐步掌握识谱技能，但在此我们仍将最精简的核心规范快速复习一遍。

最左侧蜿蜒盘旋的符号是高音谱号（G clef / Treble clef）。当乐谱标记此谱号时，各音符代表的音高如上图所示。第一线上的音符代表 Mi（E），而中央 Do（C）与 Re（D）则以下加线和间悬挂在线谱框体下方。

而形如卷贝般的符号则是低音谱号（F clef / Bass clef），用于记录更低沉的音区。低音谱表上最上方的上加一线“高音 Do”，恰好与高音谱表下加一线的“中央 Do”处于完全相同的实际物理音高。

本网站的绝大多数讲解均以实听示范音频为主干，只要能大体辨识出“音符的相对高低走向”，在阅读过程中便基本不会遇到太大的障碍。

钢琴卷帘（Piano Roll）

在旋律篇中，为了更直观地呈现旋律走势的轮廓曲线，我们有时会采用“钢琴卷帘（Piano Roll）”的展示形式。对于使用编曲宿主软件（DAW）进行电脑音乐制作（DTM）的朋友而言，这是再亲切不过的界面了。

钢琴卷帘的纵轴代表音高，横轴则代表时间的线性流逝。

或许有人会想：“要是全站不用五线谱、全都换成直观的钢琴卷帘该多好啊”。但传统乐谱有着五线谱独有的不可替代的结构性优势——一旦跨越某个进阶门槛，许多精妙的和声与声部逻辑是单靠钢琴卷帘无法深刻阐述的。因此，希望大家能逐步习惯双重视角的对照。

八度（Octave）

在十二平均律音系中，“Do-Re-Mi-Fa-Sol-La-Si”呈周期性无限循环。“某一个 Do 与其上方相邻的下一个 Do”之间，这种恰好跨越一个完整音循环周期的音高间距，被称为八度（Octave）。

和弦（复音）与单音

将多个不同的音符在同一时间同时弹响所构成的音响形态，称为“和弦 / 和音（Chord / Harmonics）”；相对地，一次仅鸣响单独一个音符的状态，称为“单音（Single Tone）”。

“和弦”在英语中正是 Chord。顾名思义，“和弦理论（Chord Theory）”就是专门研究多个音符组合鸣响法则的理论科学。

和弦既可以通过钢琴或吉他等单件多音乐器一手弹奏出来，也可以由铜管组或弦乐四重奏等多件单音乐器协同合奏交织而成。想要编配出和谐高级的和弦织体需要系统的理论加持，因此对于没有任何乐器演奏基础的新手而言，起步阶段先从纯单音旋律创作切入是完全可行且明智的。

贝斯（低音声部）与上位声部（中高音织体）

在现代流行音乐中，承担最低音区律动骨架的声部被称为低音声部（Bass / 贝斯），而负责其上方其余中高音填充与伴奏的声部则统称为上位声部（Upper Parts / ウワモノ）。

承担“贝斯”角色的乐器，在摇滚乐队中自然是电贝斯，在电子音乐中则由合成低音（Synth Bass）担当；而在钢琴弹唱中，伴奏的左手低音区便扮演着贝斯的坚实地基角色。 由于人耳对低频的辨析度不如中高频敏锐，普通大众听众常常忽视贝斯的存在；但对于搭建整首乐曲的声学大厦而言，低音却起着定海神针般的决定性作用。让我们通过实际音频来直观对比感受：
