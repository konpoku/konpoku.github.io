1. 序（Order）

在作曲时，究竟是从旋律写起，还是先做好和弦进行再填上旋律？“以什么为中心构建乐曲”，说得严肃一点就是“设定了怎样的作曲法模型”，在理论构建中是极为关键的一环。 尤其是在深入探讨“旋律理论”时，是从和弦引申出旋律，还是为旋律填充配上和弦，对待旋律的思路也会大相径庭。

传统理论的预设模型

传统的音乐理论有时也被称为“和弦理论”，以和弦为出发点构想旋律是其基本模型。古典体系往往从在既定的低音声部（Bassline）上填音的练习开始；爵士体系也是从区分和弦音（Chord Tone）与引伸音（Tension）、避用音（Avoid Note）展开理论的。不过，在部分领域中也考虑了相反的模式。在爵士理论中，为现有乐曲的旋律重新配置和弦的“重配和声（Reharmonize）”就是其代表。

重配和声的示例

在挑选符合旋律的和弦的同时，和弦进行本身也必须编排得优美流畅。这是一项相当考验技巧的工作，但只有在精通和弦理论之后，才可能做到在不削弱旋律魅力的前提下配上精彩的和弦。

同样，在古典体系的学习过程中，中途也会出现被称为“高音题（Soprano exercise）”的练习，即为既定的旋律配置和弦。

高音题示例

更换和弦被称为“重新配和声（Re-harmonize）”，而从零开始给旋律配上和弦的行为则称为配和声（Harmonize）。

这里是一个古典风格的配和声示例。这同样必须严格遵守苛刻的规则来进行声部填充，相当不容易。在正统爵士与正统古典理论中，正是通过这类练习来掌握“在突显旋律的同时，在下方构建富有魅力的和弦进行”这一技术。

这种作业完全属于旋律优先的作曲模型。虽然这与“在和弦上填旋律”时的思维路径方向完全相反，但传统理论通常不会特意将其用语言明确规范。如果说这是理所当然的事，倒也确实如此。

明确概念语言

然而，为了扎实地构建“旋律理论”，将这一点明确概念化会带来极大的便利。因此，在自由派音乐理论中，我们将“作曲编曲中某一事项的优先级”，取其在该情境下所代表的秩序、序列、等级之意，称之为序（Order）。

借助“序（Order）”这个词，我们可以清晰利落地表达作曲中的优先级。例如：

  • 在和弦进行已经固定、需要在其上加入乐句的即兴演奏合奏（Session）中，和弦的序更高。
  • 在对既有歌曲进行翻唱改编（Cover arrangement）时，和弦可以改变，但旋律基本上不能改动，因此旋律的序更高。
  • 在“先词后曲”的作曲情境下，歌词基本上无法变动，因此相比旋律，歌词的序更高。
  • 对于发声域受限的乐器，相比旋律的自由度，乐器音域的序更高。

虽然每一条看似都是理所当然的事情，但赋予了“序（Order）”这个术语之后，我们便能对自己当前的音乐构建模型保持自觉意识。在讨论“序”时，最具代表性的对象包括旋律、和弦、节奏，但如上所述，“歌词”“音域”等要素，在“存在约束条件且作曲必须顺应之”这一层面上，同样可以被视为一种“序”。

旋律序 / 和弦序

进一步推进一步，在某个作曲场景中，当旋律或和弦占据次序顶峰时，为了简明起见，我们分别称之为“旋律序（Melody-Order）”与“和弦序（Chord-Order）”。

也就是说，像“以旋律优先的思维方式”或“在旋律固定状态下”等繁琐表达，今后都可以用“旋律序”这一表述来替代。 说“优先”似乎暗示着牺牲了其他部分；说“固定”有时又未必真正定死；有时也可能只是“顺手先写出了旋律”。请将“序（Order）”理解为为了包容所有这类多样情况而特意留出弹性的通用术语。

2. 序的变更

在实际的作曲过程中，各要素的序会频繁切换。特别是在旋律序与和弦序之间反复交替推进作曲的情景，想必每个人都深有体会。

旋律序

太棒了，想出了一段极佳的旋律！回去之后马上输进电脑试试

（遇到问题）

咦，这里该配什么和弦好像不太明朗啊……

和弦序

稍微把这里的旋律改一下吧，先想想到底配什么和弦才合适。

和弦序

好，这个和弦进行很顺，就在这上面填旋律吧

旋律序

既然都到这步了，这里进行一次和弦性质转换（Quality Change）会不会更能突显旋律的质感呢？

就是这样的过程。虽然最理想的境界是“在脑海中浮现出一切都无比清晰完整的音乐”，但在抵达那一境界之前，这种反复尝试与探索的过程是必不可少的。

3. 表层与深层

“序”是作曲时要素的序列与秩序。如果把这一概念推向更根本的底层，“调性（Key）”“音阶（Scale）”“拍子（Time Signature）”等同样可以算作一种序。虽然平时未必会特意意识到，但只要没有产生“我要改变它”的念头，你的作曲便始终遵循着它，这正是不折不扣的“秩序”。

这些事项在某种程度上或许比和弦或旋律拥有更高的“优先级”，但若说它们处于序列的“顶点”，听起来又有些不够贴切。反过来说，它们更像是存在于最深底层的根本秩序。打个比方，除了具体表现为演奏的表层序之外，在深层部分同样存在着作为作曲框架基础的深层序。

层次 具象发声的音响本身 旋律、和弦、节奏型、歌词 等
表层 具象发声的音响本身 旋律、和弦、节奏型、歌词 等
深层 抽象形成的认知产物 音阶、调性、拍子、重音律动（Beat）、速度（Tempo） 等

表层的序在实际作曲中可以随时切换以哪个为优先，因此虽然都称为序，但它更接近于“序列、优先级”的含义。而深层的序则是将这些要素凝聚在一起的骨架，宽松地规范着整体的存在形态，因而更贴近于“秩序”的含义。因此，尽管都统括在“序（Order）”这一个词下，但二者在性质上其实有着相当显著的区别。

4. 独立与从属

在作曲中，各个要素正是因为顺应了秩序（Order），音乐才得以成立。如果每个人都弹奏不同的和弦，或者每个人都按照各自不同的节奏节拍演奏，音乐自然会乱成一团糟。然而另一方面，在音乐当中，某个声部在某种形式上“脱离”其他既定秩序的现象也时有发生。在我们以往所学的知识中，就存在这类典型手法。

蓝调音（Blue Note）

例如，在主调为大调、大音阶的世界中引入小音阶风味的“蓝调音”，就是非常典型的代表。

从理论上解读蓝调音时的基本理解模型，便是“在大调和弦群之上叠加小调五声音阶”。蓝调音正是一个从大调这一深层序中脱轨而出的存在。

在这种情况下，我们表述为：蓝调音对调（或音阶）这一序处于独立（Independent）状态。相反，顺从既定序的状态则称为从属（Dependent）（尽管平时不太常特意这样称呼）。

变化的抵消（Cancellation of Alteration）

和弦发生了变音修饰，而旋律却对其置之不理的“变化的抵消”，其本质与蓝调音相同。

当和弦带有临时升降号时，旋律本应使用的音阶也会发生改变。这原本是有秩序的演奏状态。然而，实际中完全可能出现仅有旋律独立于该音阶之序的现象，这种情况便被解释为“变化的抵消”。

持续音（Pedal Point）

低音声部与其他声部保持“独立”、持续弹奏某一单音的“持续音（Pedal Point）”，也是独立的代表示例。

I ♭VII/I ♭VI/I Vm/I

因为低音完全无视了全体声部试图构建的和弦。这就是对和弦这一序的独立。但从更宏观的视角来看，这一场景也可以理解为“当同主音小调和弦（Parallel minor chord）威胁到主调性时，只有低音在拼命守护着原本的调性”。

声部 相对于调性 相对于和弦
上方乐器声部 独立 从属
低音声部 从属 独立

这样审视下来，音乐内部仿佛浮现出了一个微缩的“人类社会”。上方乐器声部是试图脱离原本调性的“反叛者”，而当他们变成多数派时，反而显得低音成了唯一特立独行的异端分子……这着实让人感叹音乐中充满世态炎凉的幽默。

多节奏（Polyrhythm）

当某个声部从拍子中独立出来，便催生了多节奏（Polyrhythm / 多节拍 Polymeter）。

起初底鼓保持着稳定的四四拍律动（Four-on-the-floor），但进行到中途底鼓也独立了出去，最终只剩下开音踩镲（Open Hi-hat）的反拍敲击勉强从属于深层的拍子。

混沌与音乐的信息量

这些技巧通过打破乐曲统一的秩序（Order），引入了一定程度的混沌（Chaos），但正是这种打破常理的处理让音乐变得格外耐人寻味，展现出音乐深邃的魅力。听众在同一瞬间体会到多种运动走向，这种信息量的大幅提升也带来了强烈的听觉刺激。

无论如何，通过定义“序（Order）”这一术语，我们首先对音乐的秩序有了自觉的认知。其结果是，我们在“蓝调音”“变化的抵消”“持续音”“多节奏”等涵盖旋律、和弦、节奏的技巧中，发现了一种普遍相通的本质特性。这让我们又多了一件能够清晰透视音乐的分析利器！

“序”这个词在今后还会频繁登场，大家也会逐渐切身体会到确立这个术语的深远意义。在打好基础准备之后，下一节我们将正式进入旋律篇第V章的概论。

总结

  • 在作编曲的某一场景中，将旋律、和弦、节奏型等要素中以何者为优先考量的序列称为“序（Order）”。
  • 此外，当某一要素居于序列顶端并以此为基准固定推进作编曲时，简称为“⚪︎⚪︎序（⚪︎⚪︎-Order）”。
  • 乐曲中某一特定声部偏离既定序进行演奏的状态，称为脱离该序的“独立（Independent）”。
  • 确立了“序”这一概念后，便能更清晰透彻地讨论因“从和弦到旋律”或“从旋律到和弦”等作曲模型差异所带来的不同理论体系形态。
