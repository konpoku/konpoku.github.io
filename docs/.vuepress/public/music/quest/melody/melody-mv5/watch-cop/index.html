在第V章中，我们的目标是为旋律配置和弦，但除了旋律之外，和弦本身也在向前进行。而主导和弦进行的一大核心要素，便是低音线条（Bassline）的变化。因此，当旋律与低音同时运动时，两者之间的距离如何变化，壳（）又随之如何改变，就成了一个极其关键的焦点。

正因如此，在进入具体的和弦排列（Voicing）之前，我们将首先专门聚焦于旋律与低音的关系，从磨砺对“配壳（Shelling）”的敏锐感知力开始。

1. 当心 COP

作为起点，与之前的 K/S 分析一样，我们首先着眼于和弦切换时的拍头音。同时，本次我们暂且忽略如 M3/m3 这类性质（Quality）上的差异，仅将壳的数量/度数（Quantity，即数字部分）进行可视化。

只有保持这种简明度，才不至于造成信息过载。和弦改变，与此同时旋律也在运动，壳发生变化。我们重点关注这一动态。仔细思考便会发现，旋律与低音的运动方向关系大体可以划分为三种：

① 朝反方向运动

首先是旋律与低音朝相反方向运动的动作。旋律上行而低音下行，两者之间的距离就会大幅拉开；反之则会紧紧靠拢。由于两者距离发生了剧烈变化，这可以说是一种极具动态感的运动。在音乐理论中，两个声部朝相反方向运动称为反行（Contrary Motion）。

② 仅其中一方运动

也有旋律与低音仅有一方在运动的形式。例如旋律保持长音而和弦在变化，或者低音在持续演奏持续音（Pedal Point）时，都是极其典型的例子。这种运动称为斜行（Oblique Motion）。由于有一方保持固定，因此呈现出平静安稳的运动质感。

③ 朝相同方向运动

最后是诸如“同时上行”或“同时下行”这样，两者步调一致朝同一方向运动的形式。这称为平行（Parallel Motion）。平行运动自然会带来强烈的一体感。

反行、斜行、平行——这些概念自古典主义理论时代起便代代相传：

  • 反行 (Contrary Motion) 两个声部朝相反方向运动，具有鲜明的动态感与张力。
  • 斜行 (Oblique Motion) 两个声部中一方保持不动，仅另一方运动，具有稳定内敛的沉静感。
  • 平行 (Parallel Motion) 两个声部朝相同方向运动，具有高度的一体感。

按这个顺序排列，其英文首字母正好是 C、O、P，甚至可以编一句“当心巡警（COP）”的口诀！虽然本次我们主要着眼于旋律与低音，但这一分类适用于任意两个声部之间，比如“长笛与单簧管”或“主唱与和声”之间也是如此。

注意八度区别

关于术语，有两点需要特别注意。首先，高低八度的具体走向是严格加以区分的。在“连接系理论”中，“上行5度”与“就近的下行4度”在本质上被视作同等；但在探讨“反行/斜行/平行”时，两者是必须严格区分的。

因此，本节的内容可以说已经深入到了“编曲（Arrangement）”的领域。我们关注的不再是作为抽象概念的和弦，而是具体在发声运动的乐器旋律线条。

直行与等度平行

另一点是，级进与跳进等音程移动的度数与术语命名无关。比如一听到“平行”，人们可能会误以为音程必须保持完全一致，其实不然。哪怕一方是上行2度而另一方是上行八度，只要方向一致，就统称为“平行”。

但是！“两个声部保持完全相同的度数间隔进行平行移动”与“两个声部移动度数不同的平行”，所带来的听觉印象显然是截然不同的。在英语圈理论中，有的教材仅将前者称为“Parallel”，而将后者区分称为“Similar”或“Direct”。

这里又出现了流派之间的断层……也就是说，当别人提到 Parallel 时，无法直接判断指的是广义还是狭义，这很容易产生沟通误解。 在日本虽然有对应“Direct”的翻译词“直行”，但使用场景较为有限，并未广泛普及。因此本站采取的方针是：平时基本上统称为“平行”，仅在需要严格区分讨论的场合引入“直行”这一术语，并将狭义的平行特别称为等度平行（Pure Parallel），以便与广义的平行明确区分开来。

从最小颗粒度的微观视角来看，任意两件乐器的每一个单音之间都可以进行这种方向分析。分析得有多细致，其难度也会随之改变。在严谨正统的古典理论中，为了让各个声部之间的关系全都优美和谐，细节规则被高度理论化。若非如此，管弦乐团这样的大编制是无法奏出极其精致和谐的声响的。

但在流行音乐中，起步阶段只要先关注旋律与低音、特别是和弦交接过渡处的拍头就足够了。随着水平提升，再逐渐拓展到在旋律与低音之外加入后方背景弦乐的声部走位等等，逐步增加需要关照的声部即可。

2. 观察壳的变化

接下来，我们重点观察在每种运动中，壳（Shell）会发生怎样的变化。

反行的情况

在反行运动中，壳发生改变的情况居多。

虽然有时像后半段那样，移动前后的壳在偶然间保持一致，但大多数情况下壳都会发生改变。可以说，反行不仅使两个声部的距离产生大幅度的开合，壳的关系也会产生丰富多彩的变化，从而为乐曲赋予多样的色彩感。

斜行的情况

斜行的情况也是如此，除非声部进行了八度大跳，否则壳通常都会发生改变。

斜行既有旋律保持不动的情况，也有低音保持不动的情况，这里示例全部采用了旋律固定的形式。

由于壳的变化幅度完全取决于运动的那一方声部，因此相比两方同时运动的反行，斜行给人一种更为简明直接的感觉。斜行在距离变化上较为简单，但在色彩变化上却十分充分，可以这样来概括。

平行的情况

关于平行，如果是等度平行，壳的度数数量（Quantity）就不会改变；如果是单纯的直行，壳则会改变。由于“等度平行”确实是一种特殊的运动形态，我们在处于“等度平行”的地方标注了等号。

当两个声部持续进行等度平行时，相同的壳就会连续出现。往好的方面说这极具统一感，往坏的方面说则可能稍显缺乏色彩变化。本来就色彩鲜明的 3rd Shell 或 7th Shell 连续出现没有任何问题，但如果 Root Shell 或 P5 Shell 持续等度平行，在听觉音响上可能会略显单调乏味[^1]。

上面的三个音频示例采用了相同的和弦进行，因此非常便于对比。对比试听“反行”与“平行”，可以明显感到“平行”给人一种更为直接直率的印象。不过这种影响并非绝对的优劣，有些场合恰恰需要这种朴素单调的质感，因此正如之前关于壳的探讨一样，凡事各有利弊，下文会进一步详述。

3. 实例对比分析

现在让我们通过真实的乐曲实例，看看“C·O·P”所带来的听觉印象差异。

反行实例①

这是松任谷由实（Yuming）的名曲。副歌开头的“次の”部分，旋律是 Do-Re-Mi 的级进上行，而低音是 Do-Si-La 的级进下行，形成了非常优美且清晰的反行。在这种情况下，壳顺畅地经历了 Rt-3-5 这一平稳安定的奇数壳路径。

从根音出发就会形成这样的结构。所发生的音乐现象非常丰富，理论视角也随之更上一层楼。旋律与低音的距离逐渐拉开，壳也在接连变换，听起来格外华丽明亮。

顺便一提，在这首歌紧接着的“欠ける”处，画风一转，连续使用了平行。

通过稳定的 3rd、3rd 走向收敛得稍显沉静，与刚才的反行形成了鲜明的对比。即便是这样微小的细节处，也闪耀着精妙的编曲审美。

反行实例②

由于反行的壳变化较为复杂，我们再来看一个例子。

视频开头的副歌部分。低音沿着从 I 开始顺次下行的经典走向，而旋律则向高处大幅度伸展。

虽然局部包含了斜行，但整体而言属于充分发挥了反行魅力的范例。我们用黑色表示奇数壳，灰色表示偶数壳，这样一看便能发现它极其优美地顺应着奇数壳在演进。而且在 I 与 V 这样强劲有力的骨干和弦上配置了 5th，而在 IV、VIm、VIIø7 这样带着伤感抒情色彩的和弦上则选取了 3rd 或 7th，其壳的配比可谓无可挑剔。

斜行实例

斜行由于只有一方在动，因此分析壳的变化相当轻松。

凭借“And I~~~”乐句而家喻户晓的这首经典名曲。副歌的旋律在主音上保持了极长的延音。在延音期间和弦不断变换，从而在旋律与低音之间形成了斜行运动。

这里低音连续进行 3 度下行，壳也随之以 1-3-5 顺畅地沿着奇数演进。偶数壳在运用上总有诸多苛刻考量，因此与长音旋律搭配时，奇数壳是不二之选。无论是反行还是斜行，在何种运动模式下能够准确契合奇数壳……这类模式规律的研究同样十分耐人寻味。

平行实例

在平行中，我们本次特别聚焦于“等度平行”模式。

这首来自 Spitz 的《非洲菊（Gerbera）》，可以说是将等度平行的听感展现得最纯粹透彻的范例。整段副歌期间，和弦始终是朴素的 4-5-6，而旋律则一步步级进爬升，构成了极具辨识度的独特形态。 首先在第一句“Hello Hello Hello”中，全程保持 3rd Shell。

旋律与低音都在级进上行，形成了壳不发生变化的等度平行。接下来的“よろしくね”处，则变成了 5th。

“纯净无色”的 P5th 带来犹如强力和弦（Power Chord）般的质感，这一段感觉比刚才 3rd Shell 时更添了一份坚实的力量感。从核（Kernel）的视角来看，此时旋律抵达了极具“情感倾诉力”的 Mi 音。

到了第 3 次，则演变成了 7th。

7th 像这样连续三次出现是相当少见的模式。特别是在 V7 处产生的 Fa 旋律音，本应通过下行得到解决，这里却反其道而行之向上突破走向 Sol，这种“打破常规”的处理对歌曲所营造的氛围起到了极好的烘托作用。 刚才我们提到“等度平行略显单调”，但在本曲这种略带幽暗沉郁色彩的意境中，这种单调感反而成了绝佳的加分项。

与“色彩斑斓华丽”的反行运动、“温和典雅”的斜行运动相比，平行可以说具有“直接、纯粹且充满力量”的特质。当然，这也取决于究竟是基于何种壳在进行平行。

最后介绍一首巧妙运用了反行与平行鲜明对比的趣味名曲：

这是电视料理节目中常能听到的童谣《筷子（The Celebrated Chop Waltz）》。此编曲为极简版本，曲名据说源自“只要用手掌在钢琴上做手刀劈砍动作🙅‍♂️就能弹奏”。 正如大家所见，前半部分除开头的斜行外全为反行，而后半部分则全为 3rd Shell 的等度平行。 前半段旋律单纯，便通过反行的开阔感进行烘托；后半段为了不破坏流畅连贯的旋律，转为平行推进。在如此短小的一首乐曲中，张弛对比拿捏得极为讲究，这或许正是它能够享誉全球、长盛不衰的原因之一。

4. 运用于编曲

音与音之间的距离感能够直接转化为“开阔感”“华丽度”“统一感”等听觉印象，这真是一个全新的发现。虽然出于体系编排我们将其归在“旋律篇”中，但这些知识对于“编曲”技术同样有着极大的启发。借此机会，我们稍作拓展，解析一下在编曲中运用 COP 的核心要点。

例如在设计伴奏声部时，若相对于低音多采用反行，声音就会变得更为华丽醒目；若多采用平行，则能营造出更为融合一致的声响包裹感。换句话说，不仅依靠音色，单凭声部线条的乐句构思，我们就能自如掌控该乐器在整体中的凸显程度。

平行倾向的编曲

这是一段由低音（Bass）、领奏（Lead）、垫音（Pad）与打击乐（Percussion）构成的极简 EDM。请重点留意垫音。在这个编曲版本中，垫音始终与低音保持等度平行，牢牢维持在 P5 Shell。由于是“透明无染”的 P5，编曲意图完全是让垫音与低音完全融为一体。

反行倾向的编曲

相比之下，这个版本中的垫音则与低音形成了反行走位。结果垫音将 1、3、5、7 各种壳用了一遍。

对比之下感觉如何？在这个案例中，“平行编曲”显然是更为出色的编配方案。因为此时正值主奏音色独奏带领全场的关键段落。在“反行”版本中，垫音过于抢戏，分散了听众的注意力，造成了所谓的“喧宾夺主”。单听垫音或许层次丰富，但在整个合奏整体中，却让人搞不清究竟想突出领奏还是垫音，使音乐变得杂乱无章。

尤其在结尾处 2-3-4-5 逐步爬升的段落，“平行编曲”中领奏、垫音、低音全体一致平行上行，有力地烘托出一路攀升的气势；而“反行编曲”中垫音却反向走低，这种高昂的情绪被无端抵消了。这便是细微之处的巨大差异。

我们再来看另一个范例。

平行倾向的编曲

这次设想为常见的流行歌曲间奏中电吉他进行 Solo 的场景。我们要对比的是弦乐声部的编曲。上方示例为平行进行。由于和弦是从 I 依次下行的卡农进行，弦乐也顺从其走势一路下行。

反行倾向的编曲

这里则是反行。弦乐从 3rd Shell 起步一路持续攀升，最终抵达了相当高亢的音区。

在这个案例中，“反行编曲”则明显更为出色。“平行”版本虽然开头高昂嘹亮，但随后附着在低音上一路向下走低，导致结尾处的高潮情绪有所匮乏；而“反行”版本在最后的二五进行处冲入了绝妙动人的高音区，情绪演进极为跌宕起伏。

而且，这次领奏吉他选择的是沉稳舒展、起伏不大的乐句，此时由弦乐通过上行来烘托高潮气氛，在合奏平衡上反而更为恰当，这与刚才的 EDM 案例截然相反。再加上弦乐音响在声场上处于靠后位置，即便一路向上攀升，也不会像刚才的合成器垫音那样产生刺眼的“恶性抢戏”。

从根本上说，不同音乐流派有着各自约定俗成的乐句习惯。在广泛运用琶音器（Arpeggiator）、音序器（Sequencer）、和弦断奏（Chord Stab）、五度齐奏等合成器技术的电子音乐中，必然更容易产生平行乐句，而且听众对这种听感也早已习以为常；在偏爱强力和弦（Power chord）、大横按和弦（Barre chord）、八度奏法的摇滚乐中，对平行的接纳度同样非常高。相比之下，古典音乐体系中则存在着比起平行明显更崇尚反行的美学文化。

因此，如果合成器过度优雅地大搞反行，或者弦乐呆板直接地搞平行，难免会让人产生一种“听起来不顺耳”的违和感。这与连接系理论探讨的逻辑如出一辙，听众的听觉记忆与认知经验在很大程度上决定了对音响的接纳程度。

Check Point

熟练掌握 C.O.P. 的运动类型，便能在编曲时精准掌控各声部的凸显程度与听觉呈现方式。何种运动走向更优，很大程度上取决于具体场景。 对于哪种运动听起来更自然，流派之间的差异极大。在某一流派中被视为浑然天成的乐句，在另一个流派中可能格格不入。切忌生搬硬套某一种理论教条，必须准确理解音乐实际的风格形态。

如果你以往在设计伴奏线条时全凭直觉，今后请务必多加留意最高音（Top Note）的壳及其动态演变。只要注入这份意识，声部的说服力必将获得显著跃升。

此外，当低音进行类似 I-V 这样的大跳时，究竟是选择向上跳还是向下跳？这将直接决定整体是走向平行还是反行。以往大家在做低音的八度决策时，大多仅凭低频的饱满度来判断；那固然是第一基准，但在此基础上，不妨再思考一步：是想拓宽还是收窄合奏的音域宽度？ 如果旋律已经定下，相对于旋律究竟是形成平行还是反行？ 希望大家今后能把这些视角也纳入编曲的考量之中。

总结

  • 两个声部之间的运动关系，根据音高的移动方向可以划分为反行·斜行·平行三种。
  • 自由派音乐理论进一步将度数数量（Quantity）不发生改变的平行特别称为“等度平行”。
  • 反行往往呈现出华丽感，斜行呈现出沉稳平和，平行则呈现出高度的一体感。
  • 在编曲时充分意识到 C.O.P.，可以在很大程度上调控特定乐器声部的凸显程度。
  • 不同的音乐流派对于 C.O.P. 的偏好、使用频率以及听众的接纳度存在明显差异。

[^1]: Perricone, Jack. Melody in Songwriting (Berklee Guide) (p.127)
