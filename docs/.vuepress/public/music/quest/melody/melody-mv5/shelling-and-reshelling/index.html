配壳与重配壳

1. 旋律篇的历程

上一篇中我们定义了“序（Order）”这一概念，并确认了在作曲过程中，旋律序与和弦序会频繁发生交替。那么旋律篇在此之前的内容，是在预设何种序的前提下展开构建的呢？我们首先来回顾确认一下。

旋律篇的过往

第II章与第IV章中的“壳（）”理论，其实可以说是和弦序（Chord-Order）形式的理论。因为其构思方法是：和弦进行在先，确定想要使用的壳，进而调整旋律线，使得和弦变换的拍头能够落在对应的壳音上。

在作曲初期阶段，“在和弦进行上填入旋律”确实是很常见的形式，而且在使用循环乐句（Loop）进行作曲时，也只能以和弦序来进行。即便不是这样，从理解壳所具备的共通性质、以及掌握构建优美壳结构时旋律听感体验的角度来看，“从和弦到旋律”的构建练习也是培养旋律感极为关键的过程。

旋律篇的未来

而本章（第V章）将着手强化相当于“重配和声（Reharmonization）”与“高音题（Soprano exercise）”的方法论，也就是以旋律序（Melody-Order）来构建乐曲的能力。我们将活用和弦篇中积累的和弦知识，深入探讨如何灵活变换和弦以最大程度烘托旋律。

上图展示了当想要为Do音（主音）配置和弦时，主要的候选和弦们。这完全是自上而下的相反思维方向，而我们在第IV章中接触过的“通过将小6度壳转化为斜杠和弦来消除其倾性”，其实也可以说是本章内容的先行预热。

我们将全面锤炼这种“自上而下”的构思能力。

2. 重配和声的实例

保持旋律不变，仅更换和弦——这类技能在实际作曲编曲中极为常用。让我们来看几个实例。

这是《魔女宅急便》的主题曲。从0:14处开始进入主旋律部分，虽然相似的旋律线条循环了4遍，但第1、3遍与第2、4遍的和弦进行是不同的。

这可以说是“久石让标志性风格”的和弦进行与壳编排。然而在第2、4遍中，低音声部却转为上行，构建出了色彩缤纷多样的壳！

这种手法高度忠实于古典主义流派对转位和弦（斜杠和弦）的运用规范，和弦进行本身既优美流畅，壳的变化也极为丰富明艳。对于曾经大量练习过“高音题”的人来说，驾驭这种重配和声自然不在话下。

流行歌曲与重配和声

在流行人声歌曲中，这种“重配和声”的技术同样大放异彩。

例如这里，常规副歌（Sabi）与在终极大副歌之前出现的安静副歌（即所谓的“弱化副歌 / 掉落副歌 Ochi-Sabi”）之间采用了不同的和弦进行。常规副歌是朴素的4-5-1-6进行，而在3:28开始的“弱化副歌”中，则通过使用副属和弦III7以及J-Pop中的必杀技——从VIm出发的低音阶下行（Bassline Cliché），极大地增强了情感的冲击力。旋律完全相同，但和弦发生了改变。由此，在保持了J-Pop所必需的通俗易懂的同时，也为表现力拓展出了广阔的层次。

3. 配壳与重配壳

再次明确，从本节开始的核心议题，就是决定为旋律赋予多少度的壳，并为其配上契合的和弦。这与先有和弦、再从中选择一个壳音来构思旋律的方法在序（Order）上是完全相反的。

我们将这种“思考该赋予旋律何种度数的壳，并为其配置合适低音”的行为，称之为配壳（Shelling / 构壳）[1]。

当旋律诞生的瞬间，首先产生了核（Kernel）。在此基础上配置低音，便构建出了壳（Shell）。最后通过内声部的音进行声部填充的过程即为排列配声（Voicing），至此和弦得以完全确定[2]。

旋律序的作曲过程，可以抽象为这三个清晰的步骤。

重配壳（Reshell）

如果在配壳后的和弦排列阶段决定“这里还是做成斜杠和弦吧”，那么壳就会发生改变。或者重新替换低音，壳当然也会随之变化。像这样改变旋律所处的壳属性，我们称之为“重配壳（Reshell）”。

“重配壳”与“重配和声（Reharmonize）”相似，但所指的侧重点略有不同。例如，在乐曲流动中重复同一个乐句、但中途不断替换和弦的行为，也包含在“重配壳”这个词的范畴之内。

VIm IV6 V IIm7

就像这样。重配和声的焦点更多在于让和弦进行本身变得更具趣味性，而重配壳的目的则始终在于改变旋律带给听众的听感质地。此外在某些情况下，即使进行了重配和声，壳却并没有改变。

特别是这种“不改变壳的重配和声”操作，能够在不破坏既有壳关系的前提下改变声音的色彩质感，因而作为一种技术同样极为重要。从明确区分这种细微差别的角度来看，在“重配和声”之外单独确立“重配壳”这一术语也是非常有益的。

前两篇可以说是第V章的导引与铺垫。通过整理“序（Order）”“配壳（Shelling）”“重配壳（Reshelling）”等术语，我们讨论配和声的理论基础已经就绪。从下一节开始，我们将正式进入本章的核心正文。

总结

  • 熟练掌握配和声技术后，便能够为同一段旋律高效配置多种和弦进行，在保持乐句重复结构的同时为乐曲带来丰富的动态展开。
  • 配和声的作业大体可分为两个阶段：配置低音的“配壳（Shelling）”，以及填充内声部的“排列配声（Voicing）”。
  • 对于同一段旋律，改变低音、或者将其改写为斜杠和弦，壳都会发生变化。这种操作称为“重配壳（Reshelling）”。
