配方与调味料

以往介绍音阶的方式，说到底完全是“配方（Recipe）”导向的：

背诵音阶配方的人

给自然大调的 E、A、B 加上降号就会变成自然小调音阶。声音会变暗哦。

将三个音的变化打包在一起，只传授“会变暗”这一现成结论。但实际上在“小调”风味的调制中起最关键决定作用的是 E♭ 音；正因如此，哪怕拿掉 B 的降号，依然能得到具有充分小调质感的“和声小调音阶”。 因此上一节我们所做的工作，可以说正是将配方中的调味佐料逐一单独拆分，细细品味每一种佐料独特的“风味”。这与教会调式如出一辙：通过用自然小调与多利亚调式对比聆听同一首曲子，我们切实确认了特性音的“滋味”。 既然如此，心底便会悄然萌生一种全新的渴望：既然对每个音的脾气已经了如指掌，我们何必局限于死板照搬现成配方，何不尝试亲手调配创造出独一无二的音阶？ 只要懂得了每一种调味料的功效，无需依赖他人的食谱，我们自己也能调制音阶。调配出的风味或许似曾相识，或许前所未闻——无论哪一种，都注定妙趣横生。 因此本讲我们将运用迄今为止积累的音阶知识，抛开“这是在某某音乐中使用的音阶”这种结论先行的死板教条，展开一场以原理解构先行的“自制音阶实验”。这与此前偏重通俗实战的第IV章略有不同，风格更加贴近第III章。

2. 关系调导向与同主音导向

在正式切入正题之前，我们需要先在脑海中完成一次认知的模式切换——那就是*阶名（唱名）*的赋予法则。 以往我们对音阶唱名的习惯是：“大调音阶主音唱哆（Do），小调音阶主音唱拉（La）”。从实践角度及视唱练耳（Solfège）的历史渊源来看，这都是极为正统的法门。 然而这是对比 C 大调与 A 小调的“关系调导向（Relative-oriented）”理论体系；而我们接下来要进行的，则是将 C 大调与 C 小调进行直接对垒的彻底的“同主音导向（Parallel-oriented）”理论体系。

关系调导向是将音阶通过“横向错位”的方式予以串联；而同主音导向则是将音阶以“纵向对齐”的方式叠置对比。在同主音导向下探讨音阶时，如上谱所示，约定“无论面对何种音阶，主音一律唱哆（Do）”，能够最大程度杜绝多余的逻辑混乱。 反之，若在纵向排列音阶时死守传统阶名规则，就会陷入连品尝风味都顾不上的极端混乱状态：

虽然第III章中我们并未采用，但按照传统古典视唱规则，多利亚调式的主音原本理应唱徕（Re）。然而若完全照搬这一套，在不同音阶间频繁“翻新唱名定义”，逻辑势必沦为一团乱麻。 因此仅限本讲，我们**统一采用“主音恒为哆（Do）”的“同主音思维大脑”**来展开推演。切换到一套崭新的思维系统起初可能会让大脑有些负荷，但换个角度，这也意味着我们正在以一种前所未有的全新维度与音乐深度相拥，必将收获崭新的灵感顿悟。

特性音与倾性变化盘点

结合上表，我们将调式中某一音级发生变动时引发的环境剧变——即“特性音的风味”归纳如下：

特性音 代表音阶 倾性变化 大体曲风意境
F♯（升发） Lydian F → E 的下行倾性消失 悬空向上漂浮感
E♭（降咪） Melodic min. （产生 D → E♭ 的微弱倾向[1]） 小调独有的深邃阴暗
B♭（降西） Mixolydian B → C 的导向倾性消失 坚毅刚劲、开朗豪爽
A♭（降拉） Harmonic Maj. 产生 A♭ → G 的强烈下行倾性 凄美哀怨、妖娆神秘
D♭（降徕） Phrygian 产生 D♭ → C 的强烈下行倾性 沉重压迫、黑暗刚烈
G♭（降索） Locrian （产生 F → G♭ 的微弱倾向） 动荡不安、悬疑悚然

在现实中根据和弦进行的搭配可能会浮现出其他色彩，甚至让人联想到特定的民族风情，但大致的性格底色正如上表所示。 将其分解开来后，例如多利亚调式（Dorian），就可以被视作是在“自然大调音阶”这味主料中，同时混入“E♭ 的小调质感”与“B♭ 的刚烈豪迈”这两味调味料所调制的复合酱汁。若抽离 E♭，就变成了“明朗刚毅”的混合利底亚；若抽离 B♭，则变成了“深邃流丽”的旋律小调。

这种“拆解配方、从调味料本质出发构筑音阶”的直觉，想必已经在大家心中生根发芽了。

3. 调配弗里吉亚音阶风味

现在，让我们正式开启音阶的“自主调配”之旅。首先我们要着手开发的，是魅力无穷却在已学音阶中较少深挖的弗里吉亚核心特性音——D♭（降徕）。

基于小调骨架的调配

例如以“自然小调”的配方为基底，同时向“多利亚”方向（保留 A♮）与“弗里吉亚”方向（引入 D♭）展开双重突变与融合，我们可以创造性地将其命名为“多里吉亚调式（Dorigian）”！

沉重黑暗的弗里吉亚撞上轻盈浮空的多利亚，当这两者同时爆发，声音究竟会变成什么样呢……？！😱

多里吉亚调式小曲

听起来正是如此！它兼具弗里吉亚与多利亚的双重遗传密码，比自然小调更为沉郁厚重，同时却又比自然小调更具向上的悬浮感，构筑出了一种不可思议的奇妙音响！ 顺便一提，该音阶在通用乐理中的正式学名叫作“多利亚降二音阶（Dorian ♭2）”。但最珍贵的并非由别人施舍“世上存在一条叫 Dorian ♭2 的音阶”，而是你依靠自身对乐理的深刻洞察，完全能够独立将其创造出来并精准掌控其艺术特质。 在自制音阶之后，若好奇它在人类历史上是否已有现成定名，可以借助类似 Musical Scale Finder Tool 等音阶检索工具进行查证。即便最终发现与某种传统民族调式重合，那也是一次领略世界多元文化的极佳契机。

基于大调骨架的调配

接下来反其道而行之，以自然大调音阶为骨架：保留本位 E♮，给 D 加上降号，同时给 A 也加上降号，尝试将“明亮”、“沉重”与“妖娆”交融在一起。

效果就是这样！从理论解构：因为 E、F、B 保持原貌，能够执行“F → E”与“B → C”等大调经典的半音进行，保留了大调的光辉；而另一方面又融入了神似 IVm 的 A♭ 凄美，以及弗里吉亚的 D♭ 沉郁压迫……全部交织在一起，究竟会激荡出怎样的火花？！😱

令人惊叹，浓郁的中东异域风情扑面而来！事实上，这条音阶正是名震天下的民族特色音阶——被称作阿拉伯音阶（Arabic Scale）、拜占庭音阶（Byzantine Scale）或双和声大调音阶（Double Harmonic Major Scale）。在印度的“拉格（Raga）”体系以及阿拉伯的“木卡姆（Makam）”旋法宝库中均有其赫然在列的崇高地位，是横跨中东直至南欧地中海的宏伟音阶体系。

D♭ 的丝路之旅

从文化地理视角补充：弗里吉亚调式与西班牙弗拉门戈吉他中使用的“西班牙八度音阶（Spanish 8-tone Scale）”具有极强的亲缘关系。

弗拉门戈音乐的诞生，相传深受从印度一路向西迁徙的吉普赛流浪民族的深刻塑造。这抹迷人的“D♭ 风味”，或许正是千百年来流浪旅人们从印度出发、穿过阿拉伯半岛与拜占庭帝国、最终驻足西班牙安达卢西亚大地的沧桑足迹吧。

4. 调配罕见的生疏音级

接下来我们尝试用 D♯ 与 A♯ 等极度罕见的陌生音级来大胆组装音阶。

将 D、F、A 全部升高半音，让它们通通化身为具备向上强烈冲击力的上行倾性音，这是一次极度激进的冒险。整条音阶全都是强倾性音，到底会发生什么……？！😱 我们以保留原貌的大调 1、3、5、7 度为主轴骨架，将 2、4、6 度主要作为半音趋向音的语法来运用，并在低音中适度穿插。

听起来呈现出这样一副奇景。调性感略显空灵稀薄。虽然与刚才的阿拉伯风格同为悠扬的三拍子，但它并不属于地球上的任何现实民族，而是散发着一种宛如置身“爱丽丝仙境”般的超现实魔幻感。正因为在过往的音乐经验中几乎从未与此相遇，大脑才会油然而生“不知置身何方异界的奇幻感”。 这条音阶在通用乐理中通常并没有正式的名字。通过奇妙的组合，我们完全能够创造出超脱一切既有民族标签的未来主义音阶。

引导听觉正确辨识音级

在将 D♯ 或 A♯ 等罕见音级作为音阶常驻成员时，必须细心经营，防止听觉将其误判为等音的 E♭ 或 B♭。

说得极端一点，若像上图那样大跳跃进，任谁听起来都会误以为是一个平平无奇的小七和弦。 为了防止这种误读，必须在旋律中鲜明展示“D♯ → E”、“A♯ → B”的向上半音推进动作，让听者确凿无疑地感知到创作者所意图表达的真正音级。

神秘音阶（Enigmatic Scale）

在人类历史上，这种人工培育自制音阶的先锋尝试层出不穷，其中最具传奇色彩的莫过于著名的神秘音阶（Enigmatic Scale / 谜语调式）。

5. 调式音乐与和弦进行

用此类自创音阶来编写和弦进行往往颇具挑战。与其以传统和弦框架为根基，倒不如通过强化主音中心、让单音旋律线条相互交织来得容易。不过若想从和弦理论的维度展开探索，第III章阐述的和弦分类法将发挥关键作用：

  • 共通和弦 能与常规大/小调环境完全通用，肩负稳定调性核心使命的和弦。
  • 特性和弦 包含特性音且破坏调性中心的风险极低，作为展现调式核心声响中流砥柱的和弦。
  • 变性和弦 因特性音而导致和弦性质极度畸形、或强烈暗示其他调性因而极难驾驭的和弦。
  • 辅助和弦 借由临时记号暂时偏离调式原有声响、向常规西洋传统和声靠拢的和弦。

阿拉伯音阶的 1-4-3-2 进行

就这样，我们成功从一条古老的民族音阶中开掘出了听感稳定协调的和弦进行。 另一方面，我们在第III章中不推荐“变性和弦”，纯粹是出于“在现代流行音乐语境中”难以平衡的考量。若目的是为了淋漓尽致弘扬异域风情，第 V〜VII 级这些奇门异类和弦反倒成了“提供通俗流行音乐所没有的奇异氛围”的宝贵拼图。

阿拉伯音阶的 1-4-6-5 进行

后两个和弦虽然属性极其反常，却反向极大强化了那种“非西方传统”的深邃异域质感。 归根结底：是否弹奏和弦、是否拘泥于三度叠置、是否排除浑浊摩擦……取决于你在多大程度上渴望向“西方传统模式”妥协，由此你可以全权裁决作品中文化质感的微妙天平。

6. 引入现代流行音乐

前面的范例大多使用了具有浓郁民族色彩的乐器，但将它们自如引入现代流行音乐的途径同样千变万化。

引入单和弦（One-Chord）音乐

正如在 Trap 等嘻哈流派中单靠一个主和弦一夯到底便能成立一样，旋法在循环律动中大有可为。我们用自创的三条音阶依次演奏验证：

作为局部的调色点缀

或者效仿同主小调的逻辑，将其作为局部的临时音阶切换，这些自制音阶便能化身为流行歌曲中极具杀伤力的神级香料！

这是极其时髦奢华的都市氛围！第 2 小节正是刚才的“阿拉伯音阶”，但由于编曲音色与旋律走势并不刻意张扬民族风，听起来恰如“对同主小调 IVmΔ7 做了一点精妙微调”般自然得体。 第 4 小节则启用了“神秘音阶”，以第 iv 级的 F♯ 音为低音构筑了张力四溢的声场。相比全音阶，它因保留了部分半音差，乐句甚至更加易于下笔。 谱例中严格标注了和弦记号，看起来极为复杂。但从调性引力论的底层逻辑切入，其实质不过是“不妨试着将这味酱汁与那味佐料调配在一起”的从容灵感。

永葆自由之精神

这种“不妨放手一试”的探索精神至关重要。我们永远拥有使用从未被任何人传授过的独创声音的绝对自由。正如和弦篇第I章所述：在真正的艺术殿堂中，使用连名字都叫不出来的声音是理所应当的特权。

总结

  • 立足于已掌握的音阶法则与倾性理论，创作者完全有能力自主设计并调配崭新的音阶。
  • 调配出的音阶，有的融合了多种音阶的混血特征，有的则会与人类某些古老民族的调式不谋而合。
  • 围绕新音阶搭建和弦进行时，先以三度叠置试探，排查特性音与和弦性质是最扎实的途径。
