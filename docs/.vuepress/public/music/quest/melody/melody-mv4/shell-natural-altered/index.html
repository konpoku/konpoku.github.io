自然外壳音与变化外壳音

2026.09.05旋律论
旋律论调性引力论深化与外壳音进阶

目录

  • 1. 自然外壳音与变化外壳音

  • 3. 变化外壳音与 7th
  • 4. 变化外壳音与 Root

到目前为止，我们似乎已经掌握了从 Root 到 7th 所有外壳音（）的特质。然而，外壳音的真正殿堂才刚刚拉开序幕。因为，此前我们探讨的全部局限在基调和弦的范畴之内。

在“和弦论”中，第I章的属性变换（Quality Change）、第II章的副属和弦与同主小调和弦、第III章的sus4 与 aug等崭新面孔纷至沓来。在本节中，我们将系统探讨在驾驭这些“调外和弦”的外壳音时所需关注的全新准则与核心要点。

1. 自然外壳音与变化外壳音

调外和弦除了 Isus4 或 IV(-5) 等极少数例外之外，绝大多数都伴随着临时升降记号。

和弦构成音附带 ♯/♭，在古典和声理论中被称为“变音（Displacement / Alteration）”。在分析旋律时，旋律究竟是否取用这个“带有临时记号的音”，是一个极具决定性的核心视角。因此我们必须赋予其严谨的学术命名： 当某个外壳音处于带有临时记号的音级位置时，我们称其为变化外壳音（Altered Shell）；反之不带临时记号的，则称为自然外壳音（Natural Shell）。

在 Isus4 中，F 音固然是“由三音替换而来的音”，但由于并未附带 ♯/♭，因此在旋律分析中不称其为“变音”。 简而言之，一条极其简明直观的法则便是：“只要旋律的五线谱上带有临时升降记号，那它就是变化外壳音”。在第III章探讨的蓝调音（Blue Note）、趋向音（Chromatic Approach）、和声小调与旋律小调中所产生的临时记号音，同样广义上归入变化外壳音的范畴[1]。

2. 变化外壳音与 3rd

主旋律取用变化外壳音具有极其重大的艺术意义：它会极其强烈地向听觉宣告伴奏和弦发生了变位。尤其是在小节开头切入处或长音延伸等显眼位置，外壳音的选取至关重要。

最直观的当属通过“属性变换”改动了三音（3rd）的场合。在这些和弦上大张旗鼓地取用变化外壳音（即变位三音），能够极为鲜明地昭告听众“原本是小调色彩现在变明亮啦！”或者“原本是大调色彩现在变凄美啦！”，从而带来极其清晰的音乐情绪表达：

和弦 变位音 呈现的听觉意象范例
II F♯ 充满朝气的明朗欢快
III G♯ 澎湃昂扬的情感高潮
VI C♯ 饱含希望与重生的明亮光辉
IVm A♭ 凄美缠绵的哀愁悱恻
Vm B♭ （难以言喻的玄妙色彩）
Im E♭ 阴郁沉沦的幽暗

尤其是在大三和弦 VI 级，其次是 IVm 与 III7 之上，通过取用 3rd 变化壳音来彰显色彩蜕变的经典案例屡见不鲜。

这是典范之作：在乐曲尾声唱到“くれるよ”的位置，旋律毅然攀上了 VI 级的变化外壳音（即大三度 C♯ 音）。VI 级和弦的核心魅力，正在于原本作为“小调霸主”的 VIm 瞬间蜕变出破晓般的明媚光芒，带来强烈的听觉震撼，用主旋律将其坚决确立正是黄金定式。尤其在前方以 sus4 进行蓄势延宕时，“D → C♯”的级进下行无疑是最自然且极富感染力的旋律笔触。

变音和弦皆因其音符变位而赋予乐曲崭新的性格色彩，而通过取用变化外壳音，创作者能够将这种性格更加昭然若揭地展现给世界。

反过来看，若想含蓄内敛、不露痕迹地低调使用变音和弦，就应当选择自然外壳音。例如在主歌 A 段使用 III7 时选用自然壳音低调掠过，待到副歌重逢 III7 时再祭出变化壳音大放异彩……通过这种精妙配置，变音和弦的情绪烈度便能得到从容自如的精准调节！

让我们通过对比来聆听：究竟由哪一个乐器声部来承载变化外壳音，听觉体验会有何不同？

  • ❶ 主旋律亲自取用变化外壳音：毫无疑问是最为瞩目显眼的最高等级宣告。
  • ❷ 小提琴或合成器主音（Lead）等相对显眼的“单音副旋律”取用变化外壳音：这是一种极具平衡感、恰到好处的高雅呈现。
  • ❸ 钢琴或木吉他等和声乐器在最高音声部取用变化外壳音：因为是和弦整体发声，音色交织相融，不似单音乐器那般刺眼，属于相对克制的中度展现。
  • ❹ 没有任何声部在最高音弹奏，而是将变位音悄悄织入和弦内声部：这是最为低调内敛、不着痕迹的含蓄点缀。
  • ❺ 主旋律与副旋律同时齐声高唱变化外壳音：变位音过分抢戏刺耳，在现实编曲中属于应极力规避的反面典型。

此外，八度音区的高低同样对听觉存在感产生深远影响。外壳音的分配在任何时候都至关重要，面对变音和弦时更需拿出十二分的审慎。 首先在“和弦交替切入点”与“长音保持”处树立自觉意识，最终达成能综合时值长短、音高音区、节拍强弱与动态音量进行微观精微调配的大师级境界。

3. 变化外壳音与 7th

例如在同主小调和弦 IVm 中，在七音叠置 E♭ 就会化为 IVm7。

7th 与 3rd 类似，同样与和弦的本质属性深度捆绑。取用变化 7th 外壳音，意味着将和弦特有的属性风貌坚决推至前台。与 3rd 一样，在编曲与创作时需格外留意究竟分配给哪一个声部承担。

在 B 段中和弦由 IV 顺流至 IVm7，唱到“三角の目をした”处，人声旋律毅然唱响了变化 7th 外壳音 E♭。 氛围瞬间完全倾斜进同主小调的深邃暗流中。低音贝斯虽然死死坚守在 IV 级未曾挪步，音乐却展现出了极其宏大的剧情波澜，堪称神来之笔。可以说整段乐句完全凭借这一记变化外壳音的灵魂一击而屹立不倒。

4. 变化外壳音与 Root

另一方面，在 ♭III、♭VI、♭VII 以及在第III章学到的必杀招式 ♯IVø7 中，和弦的根音（Root）本身就发生了变位。 在这些和弦上，主旋律在小节开头或长音处直接取用变位根音外壳音（Root Shell）的格局，在统计学上是相当罕见的。尤其在 ♯IVø7 之上，旋律直接拿根音唱长音几乎未曾得见。

这在传统理论中并非所谓的违规禁忌，但创作者在追求动人旋律的过程中，直觉上往往会自然而然地将这种用音排除在候选之外。 因为“低音贝斯正在弹奏变音”这一事实本身，就已经足够充分地宣示了变音的存在感；加之 Root Shell 本身极度匮乏和声色彩……这些因素叠加在一起，使得它极少成为首选。

摇滚美学与 Root Shell

不过 ♭III、♭VI、♭VII 和弦天生带有着浓郁的“摇滚属性”。若乐曲本身属于纯正的硬核摇滚风格，“与贝斯齐奏同度（Unison）的直白刚烈 Root Shell 简直帅炸了！”的情境同样存在。在这种音乐语境中，在关键显眼位置取用变位 Root 的实战例便屡见不鲜。

这就是生动的实证：在唱到“リクエストちゅう”处，便轰然爆发了 ♭VI 上的 Root Shell。由于全曲贯彻直白不羁的摇滚美学，既然伴奏用了 ♭VI，旋律索性也跟着大声夯出这个音，那种纯粹粗粝的“直脑筋帅气”正是该曲的灵魂魅力所在。

在决定“让旋律抓取变位根音”之前，必须深刻吃透第II章讲到的 Root Shell 的固有物理性格。

5. 变化外壳音与 5th

五音（5th）的变位分为截然不同的两种类型：

第一种类型如 ♭III 或 ♭VI：由于根音本身位移，导致五音也跟着变成了变化外壳音，但在和弦度数本质上依然是“无色透明”的完全五度（P5）。 此时旋律弹唱的变音与根音相互呼应，既能体验该音级特有的色彩趣味，又不会像 3rd 那样容易“过分抢戏刺眼”，属于非常安全稳妥的常规选项。

第二种类型则是像 Iaug 或 IIIø7 那样，真正通过“升五音（♯5）”或“降五音（♭5）”使音级化为变化外壳音的情况：

此类音响性格极其孤傲乖张、侵略性极强。若要使用，必须深刻领会其锋芒所带来的剧烈冲击。在人声歌唱作品中，通常将其低调隐藏在伴奏背景之中，而让主旋律抓取其他音级，往往能达成更为优雅耐听的平衡。

本讲的内容已然深度跨入了“编曲工程”的崇高殿堂。“外壳音”这一概念的精髓，在于时刻清醒感知音符相对于伴奏和弦处于何种度数方位。虽然它以旋律理论为切入点，但伴奏本质上亦是副旋律的交织，深刻洞察外壳音的规律，正是通向顶级优美编曲艺术的康庄大道。

总结

  • 当旋律落在需要临时升降记号的位置时，称为“变化外壳音（Altered Shell）”。
  • 取用 3rd 或 7th 的变化外壳音，能够强力放大变音和弦所特有的和声色彩与戏剧张力。
  • 取用 Root 的变化外壳音容易导致色彩贫瘠单调，除特定摇滚风格外通常较为罕见。
  • 通过周密分配由哪个声部、以何种姿态演奏变位音，能够精准调控变音色彩在乐曲中的张扬烈度。
