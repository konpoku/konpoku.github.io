同主小调与变化外壳音

2026.09.05旋律论
旋律论调性引力论深化与外壳音进阶

本次我们将深入探讨“同主小调和弦（Parallel Minor Chords）”与变化外壳音（Altered ）之间的交织互动。

在和弦论第II章中，关于细微用音的选择（是否在 E、A、B 上添加降号），我们大体上交由各位的个人直觉，并未做过多微观层面的剖析。如今终于到了对这些细部动手术的时刻。虽然大部分人凭直觉已能妥善处理，但通过语言化理清其底层脉络，思考必定会豁然开朗。

1. E（咪）：明暗度的微调

首先是在 IVm 或 ♭VII 等和弦之上，是否要给 E 音附加上降号的问题。对此在和弦篇中已有提及，保持 E 音的还原（E♮）能够换来两大收益：

  • ❶ 维系主调原本的明媚开朗（削弱临时离调/转调的剧烈程度）
  • ❷ 可以直接沿用类似“咪-发-索-发-咪”这种主调经典的旋律线条

关于 ❷，正是上一讲的核心逻辑。一旦 E 加上了降号，它与 F 之间的吸引关系便荡然无存。如果舍不得这份半音亲密感，保留 E♮ 便成为了极佳的选择。

IVΔ7 IVmΔ7 IIIm7 VIm7

从意图上讲这与“消除变位/变音还原”异曲同工：特意从同主小调借来了黑暗的和弦，却又因为“不想变得太暗”而用 E♮ 主动前去冲淡这份阴郁。 因此，“若想含蓄不着痕迹地借用同主小调就选本位 E♮；若想与主调拉开黑白分明的强烈对比就选 E♭”，这就是最基本的裁决准则。

2. B（西）：和声小调世界

接下来是在 IVm 或 ♭VI 之上对 B 音的取舍。在这里，若选择本位 B♮，“A♭ ↔ B♮”之间的关系便成为了决定全局的关键。

正如你所见，与之前探讨过的“F - G♯”一样，这是一个“增二度（Augmented 2nd）”音程。这是在自然外壳音世界中绝对不会现身的陌生距离。仔细推敲便会发现，这实质上等同于“在 C 大调之中悍然引入了 C 和声小调音阶（Harmonic Minor Scale）”。

同主小调是从小调的借用。而所借用的那个“小调”究竟是“自然小调”还是“和声小调”，决定其核心风貌的正是“A♭ ↔ B♮”这个奇绝的断层台阶。

若选用 B♮，会不可避免地弥漫出一股“诡谲怪诞”或“中东异域”的奇幻气息；若想回避这种异域感，就必须给 B 也加上降号（B♭）。

抹平了“增二度的鸿沟”，旋律线条变得亲切易融。一切皆取决于创作者想要表达的情愫，但在常规流行通俗音乐中，后者显然更具普适性。让我们通过实际乐句来对比聆听：

后者洋溢着浓郁的和声小调“中东风情”。除非有意追求这种独特的异国情调，否则给 B 加上降号往往更容易写出浑然天成的自然旋律。

The Beatles – If I Fell（若我坠入爱河）

这是采用 B♭ 版本的典范实战例。在副歌末尾运用了 IVm，构筑了“A♭ - B♭ - C - D”的旋律线条。最一目了然的是曲末的尾奏吉他乐句（2:10 起），同样奏出了“A♭ - B♭ - C - D - E”。下属小和弦的凄婉动人在此刻饱满流淌。试想若将此处的 B 弹成本位音，整首歌顿时会变成浓郁的阿拉伯风味，“坠入爱河”的浪漫情愫顷刻荡然无存。 音乐中虽无绝对的“禁则”，但此时此地究竟何为“不合时宜的声响”却客观存在。深刻洞察意境并学会精准取舍，是进阶的必由之路。

得与失的权衡

不过上述情况是出于想要与 A♭ 紧密交织的前提。如果旋律是类似“C - B - C”的线条，加上 B♭ 的必要性就微乎其微了。甚至一旦使用了 B♭，就会失去“B ↔ C”之间珍贵的半音亲和力，这实则是一大损失。 因此，若乐句并不纠缠于 A♭，为了利用“B ↔ C”的半音牵引而选择本位 B♮ 是完全合情合理的。

虽然音阶底层潜伏着增二度，但由于未在旋律线条中刻意凸显，听者并不会感到丝毫“中东感”或“不适”。 这看似显而易见，重新审视却耐人寻味：不同的音阶所擅长的旋律走向各不相同，且即便是同一条音阶，用法不同所激发的听觉印象也截然不同。

这是一个极其别致的实践案例：在 IVm7 开端以“G - A - B - C”上行时对 A 和 B 均施加了降号；然而紧接着在“C - B - C”处，B 音却果断还原为本位。在单个和弦之内无缝融合了两种模式。 “C - B - C”这一乐句唤醒了原初大调世界的温馨记忆，使乐曲能够极为丝滑平稳地过渡到随后的明亮大三和弦 V 级。

像这样，对每一个音符究竟是自然外壳音还是变化外壳音都进行深思熟虑，你的音乐表达定能达到前所未有的精准境界。

aiko – 気づかれないように

来看一个实战典范（视频为翻唱版）。在副歌部分沿着 IIIm → IIIm → IVm 推进，在第 4 个和弦踏入同主小调，此时旋律划出了“B → C → A♭ → G”的动人轨迹。

在这短短的小乐句中凝聚着超凡的艺术修养：一方面充分利用了“B → C”与“A♭ → G”两组优美的半音进行；另一方面又刻意规避了从 B 到 A♭ 的增二度突兀跳进。因此丝毫闻不到生硬的“中东味”，且由于充斥着自然外壳音，旋律的起伏动荡显得无比含蓄优雅。这是凭借无可挑剔的“歌唱灵性”完美驾驭和声小调世界的巅峰示范。

3. A（拉）：明暗度的微调

对于 A 音，其基本裁决逻辑与 E 音类似，同样关乎“明暗度的微调”（当然，E♭ 所带来的色彩与 A♭ 呈现的色彩截然不同）。拥有 A 音裁决权的和弦包括 ♭II、IVm、♭VII 等。由于在这些和弦上原则上 B 音附带降号已成定局，因此无论 A 是降号还是还原，都不会面临产生“增二度”的风险。

因此这纯粹是一场音响审美的抉择。若使用 A♭，便会将接近 IVm 或 ♭VI 的深沉色彩引入乐曲；若保留 A♮，则能维系原调本有的明朗气质。

在实际流行乐中，使用 ♭II、IVm、♭VII 等和弦大多并非为了“刻意做暗”，而是为了“增添一抹时髦高级的雅致”。因此选择不给 A 音加降号的情况通常更为普遍。 特别是在 ♭VII 上，若选用 A♭，和弦属性便会变为“属七和弦（Dominant 7th）”，会形成极度动荡且侵略性极强的爵士风骨，非常挑剔应用场景。

4. 平滑的“换乘”艺术

运用同主小调和弦，实质上是在同主小调这个“平行宇宙”之间往返穿梭。此时，旋律必须承担起引导听觉顺畅“换线换乘”的向导使命。

IVΔ7 IVmΔ7 IIIm7 ♭IIIΔ7 IIm9 IIø7 V

在这个和弦进行中，每隔一次就会插入一个同主小调和弦。穿梭频率极高，迫切需要旋律去稳稳锚定世界观……

极其失败的反面教材

这是一个灾难级的惨败例。哪怕听上十遍，恐怕也无法在脑海中记住这条线条。让我们通过乐谱来解剖病因：

如你所见，充斥着增音程与减音程的肆虐狂轰。更致命的是，在进行如此剧烈跳跃的同时，和弦交替的当口旋律突然毫无铺垫地直接抓取变化外壳音，这是产生巨大违和感的罪魁祸首。过于突兀的急转弯让听觉完全无法跟上步伐。旋律被和弦的剧烈变动牵着鼻子走，毫无内在自洽的“旋律本体逻辑”。

包含增减音程的线条并非绝对不可行，但我们的大脑对增减音程的旋律天生极度不敏感。正如在详细度数中所述，在没有任何临时记号的纯净大调世界中，增减音程唯有“F - B”这一对三而已。“听觉上的生疏古怪”是其固有属性，克制节约的使用才是明智之举。

审视平行世界的交叠

在上述败笔中，“E → A♭”的跨越尤为刺耳。让我们进一步解剖这个大跳：

主调与同主小调之间，是“共享 C、D、F、G，而在 E、A、B 上分道扬镳”的两条相互交叠咬合的平行世界轨道。

重新审视这一图景，“E → A♭”之所以荒诞不经便一目了然：从代表大调世界明媚光辉的 E，毫无预兆地猝然跳进到深渊暗黑的 A♭，剧情反转过于剧烈。

这听起来就好像旋律原本打算去往“E → A”，却因为和弦突然变暗，而被迫尴尬生硬地扭头改道冲向“E → A♭”。

当旋律线条由于和弦的挤压而呈现这种机械畸形时，动作就会失去有机生命的律动，沦为僵死冰冷的程序拼凑。听不出创作者究竟意欲何为，最终沦为彻头彻尾“毫无歌唱灵魂的拙劣音块”。

再来看一个充满崇高歌唱灵魂的正面典范：B 段唱到“透明な真珠のように”时，旋律以“E - F - G - A♭”完成了极具呼吸感的顺畅级进上行，无比丝滑地涌入了同主小调的 IVmΔ7。

一目了然：旋律借由大音阶与小音阶共同拥有的 F 与 G 作为通道路桥，行云流水般迈入了同主小调的世界。大调轨道向小调轨道的“换乘”由此浑然天成。在大小调世界间往返穿梭时，经由公共音铺设的级进通道永远是最优解。

本曲作曲家菅野洋子以驾驭复杂和弦闻名于世，但其真正的神力在于：即便在如此错综复杂的进行之上，她依然能赋予旋律无比洗脑抓耳的流行歌唱美感。支撑这一神迹的底层支柱，正是对音阶与旋律交互逻辑的深厚理解。

音高抉择法则汇总

我们将选择 E、A、B 的艺术裁量标准归纳如下：

音级 拥有选择权的和弦 主要裁量标准
E（咪） IIø7, IVm, Vm, ♭VII 是否维系主调明亮度 / 是否保留 E-F 之间的半音吸引
A（拉） Im, ♭III, IVm, ♭VII 是否维系主调明亮度 / 是否渴望使用 A♭-G 之间的半音行进
B（西） Im, IIø7, IVm, ♭VI 是否追求增二度的神秘异域感 / 是否保留 B-C 之间的半音吸引

在 E、A、B 的升降组合中存在 7 种“借用方案”，而在极度讲求音阶分类的理论中，这 7 个“借用源头音阶”各自被冠以了专门的名称。

例如如果仅在 E 和 B 上加降号演奏，便被解读为“从多利亚音阶（Dorian）借用”。不过在现阶段，大家完全无须死记硬背这些音阶名称，通通以“同主小调和弦”来总括便已足够。在和弦论第VI章中，我们将系统学习这些音阶的方方面面。

本文讲解的大部分内容虽然早已沉淀在大家的直觉之中，但通过这样细致入微的审视，思维定然会变得格外明澈透彻。在人声歌唱旋律中，每一个变化外壳音都是重磅的历史事件。如何杜绝盲目的胡乱倾泻，而是满怀意志地轰出正中靶心的致命一击——这正是过去常被轻描淡写地归结为“乐感灵性”的深水区。先以理性精密洞察，再将其融入血液升华为超凡直觉，这正是旋律理论的终极使命。

总结

  • 在同主小调和弦群中，E、A、B 保留着抉择空间，不仅关乎整体声响，更直接重塑着旋律线条的走向。
  • “A♭ ↔ B”所形成的增二度断层性格极其鲜明乖张，运用时需审慎把控。
  • 在进出同主小调时若贸然使用增减音程大幅跳进，极易因剧情反转过激而导致听感生硬失真。
  • 应当综合兼顾和弦音响与所期望构筑的旋律线条，科学微调 E、A、B 的变位处理。
