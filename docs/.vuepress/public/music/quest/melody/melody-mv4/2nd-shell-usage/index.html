二度外壳音（2nd Shell）的用法

2026.09.05旋律论

从本文开始，讲解中将频繁出现“哆来咪”等音节，但在此均作为相对于调性的“阶名（首调唱名）”使用。

从本讲开始，我们将逐一考察 2、4、6 各度数的具体用法。首先我们要掌握最核心的六个基调和弦中各外壳音（）的用法。只要理解了其中的思维方式，就能举一反三地将其应用到调外和弦上。本次我们首先从二度讲起。

1. 确认详细度数

对于偶数壳音，全部以详细度数展开讲解。到了这种高阶层次，绝不能仅凭粗略的简易度数敷衍了事。在六个基调和弦上，顺着音阶旋律取“2度”音时，分布如下：

可以看到，唯独 IIIm 是小二度，即与根音相差。这显然会给声响带来根本性的差异。这正是偶数壳音的难点所在，绝不能像“只要是三度（无论是大三度还是小三度）都是用来强化色彩”那样一概而论。

因此在接下来的探讨中，我们将大二度与小二度分开剖析。对于外壳音，我们同样使用“数量（Quantity）”与“性质（Quality）”这两个概念，表述为“大二度外壳音与小二度外壳音，Quantity 相同，但 Quality 不同”。

2. M2 Shell 的用法

大二度在英文中是 Major 2nd，因此我们简记为“M2 Shell”。在六个基调和弦中，除 IIIm 之外的 5 个和弦在自然大调音阶上构筑常规旋律时，均拥有 M2 Shell。

大二度升高八度便是大九度，因此这一音符排列与和弦篇中介绍“九和弦”时在实质上完全相同。由此催生出的声响特质也如出一辙：锐利、高亢、带有独特的悬浮感。这就是 M2 Shell 的本质。

M2 Shell 的倾性

仅就音程本身而言，M2 在偶数度中属于倾性不太强的一类。因此只要其原本的核心音（Kernel）具有中等或更低的倾性，无论是长音保持还是大跳跃进，旋律线条都相当自如。

I 与 M2 的组合

这是在 I 级上长音保持 M2 的例子。在“Someone whose smile”的部分，由于叙事才刚刚展开，特意不进行解决以营造悬浮感；而在接下来的“makes me feel I’ve been holding back”处，则严谨地遵照基础规则进行了级进下行解决。

解决与不解决所带来的音乐情绪落差，与旋律本身的叙事完美契合，堪称极佳的范例。

这同样是一个看似质朴实则极为有趣的例子。开头的旋律线条与和弦走势带有典型的 J-Pop 小调风格；但在乐句结尾处，唱到“青空のせいじゃない”时，停留在 I 级上的 M2 长音保持而不解决。若是90年代的 J-Pop 理论套路，此处通常会上行解决，但打破常规正是2010年代末期的独特审美。随后的“ずっと見上げてたわけじゃない”处再顺畅地上行解决释怀，平衡感拿捏得恰到好处。

正是通过这种“未解决”的旋律设计，乐曲所描摹的疾驰感、力量感与坚定不屈的内心被刻画得入木三分。

IIm 与 M2 的组合

在“Her heart is breaking”处，旋律落在了 IIm 上的 M2。IIm 的 M2 也就是 E 音。虽然上方半音有 F 音相随，难免会有一丝被吸引的倾向，但由于 E 音本身就是主调的稳定核心音，因此完全可以无视牵引坚守在原地。

即便不解决也丝毫没有刺耳违和之感，反而强烈彰显出力量感与直击人心的锋芒，与歌曲的主题无比契合。

IV 与 M2 的组合

在副歌开头，“いつまでも”的“も”正是 IV 上的 M2，旋律丝毫没有解决的意图，长音保持直接跨入下一个和弦。特意不做规整解决，使 M2 穿透力极强的质感得到了淋漓尽致的发挥。 在 IV 级上的 M2 是 G 音，作为核心音它本身便具备坚实有力的根基与高亢嘹亮的鸣响。当它与 IV 级柔和醇美的和声交融时，碰撞出了极其适宜失恋情歌的热烈情感。这也是一次极具匠心的妙用。

大家想必已经逐渐摸清门道了：在将核心音（Kernel）纳入考量的基础上，再结合叠置其上的外壳音（Shell）最终形成的综合质感，就能深刻洞察和声与旋律情绪的内在关联。

V 与 M2 的组合

实际上，这个组合相当罕见。V 是属功能和弦，本应肩负调动高涨情绪的使命；而叠置其上的 M2 却是“A”音。A 本质上是小调的中心霸主，性格沉稳厚重，在某种程度上反而会冲淡属和弦高昂的推进力。需要这种特殊音乐情绪的场景并不多见，因此使用频率相对较低。

在这首罕见的实例中：从 3:20 的尾奏开始展开了大家熟悉的 IV-V-VIm 进行，而在 3:37 人声歌唱切入的“’Cause you’re a sky”处，出现了不解决的 V 与 M2 的绝妙碰撞。

这首歌探讨的是静谧与激情、黑暗与光明共存的深邃主题。这一组合的降临堪称天衣无缝：在属和弦展现腾空飞跃与心潮澎湃的同时，与之交织的“A”音却在悄然消解这份轻浮，最终营造出了光与影正面较量交融的震撼音响。

VIm 与 M2 的组合

在 VIm 上的 M2 正是“导音（B音）”。此前我们曾多次强调“延长导音是营造成熟优雅都市氛围的绝佳武器”，如“開花する”处的长音延伸，以及最后的“救助して”处。在此便不再赘述。

M2 Shell 与解决

为了体会外壳音的纯粹质感，前面我们主要介绍了“不解决的长音延伸模式”，但在实际运用中最为普遍的依然是通过级进进行来解决。对于 M2 而言，上方与下方皆有稳固的解决归宿，因此上行或下行解决都极其顺畅。

下行解决的目标是根音（Root），因此会带来极其沉稳扎实的力量感；反之上行解决到达的是三音（3rd），“上行”的开扬华美与“三音”的色彩质感交相辉映，会形成格外绚丽夺目的听觉展开。究竟选择哪一种，完全取决于创作者想要表达的情绪。 另外在 VIm 或 IIm 上的 M2，其上方恰为半音差。因此在这些和弦上，上行解决在平滑度上更占优势。

反之若选择下行，则是逆着半音的吸引力走向强有力的根音，因而会彰显出更为强烈的力量感。

综上所述，偶数外壳音的用法可以说正是第I章与第II章核心理念的集大成者；反过来说，其中并没有任何真正凭空诞生的新概念。只要深刻领会了级进跳进、收敛发散、倾性等根本法则，哪怕不逐条倾听讲解也完全能够融会贯通。

3. m2 Shell 的用法

小二度在英文中是 minor 2nd，故在此简称为“m2 Shell”。 在基调和弦中拥有 m2 Shell 的唯有 IIIm。在根音上方半音叠置旋律会产生剧烈的摩擦不协和，因此倾性会极其高涨。其解决的归宿，理所当然首先指向下方半音的根音（Rt）。

关于“在和弦构成音上方半音叠加音符会带来强烈的浑浊”，在和弦论第I章的“七和弦与引伸音”中已做过详尽阐述。因此在运用该外壳音时，在编曲上需要格外审慎考量：

  • m2 Shell 倾性极高，半音下行落至根音（Root）会带来极大的舒畅感。
  • 但根据和弦、核心音以及旋律线条的综合配置，保持长音也是完全可行的。
  • 若 m2 与 Rt 在同一个八度内同时鸣响（即半音紧邻），其过度的浑浊极易引起听觉不适。最好将 m2 拉开音区置于上方。

必须借助周围声部的烘托，让 m2 Shell 听起来“恰到好处地美味”。

与核心音（Kernel）的权衡

从核心音的角度审视：在 IIIm 中，m2 Shell 对应的是“F”音，即大调中倾性最强的音。

因此，在 IIIm 和弦上当旋律取“F”音时，整体处于极度不稳定的悬崖边缘。在这种情况下，老老实实做解决是基本准则。无论是“内部解决”还是“后续解决”，只要赋予其合理的解决通道，就能化不安为极具张力的艺术表现力。

IIIm 上 m2 的内部解决

这是典型的内部解决范例。左侧是模范中的模范：半音下行平稳落入根音。旋律线条固然优美流畅，但由于旋律着陆在根音上，难免会带出一丝坚硬的力量感，这与 IIIm 本身所追求的幽怨悲伤略有抵触。 因此像右侧那样，稍作跳进走向 7th 也是极好的策略。这样既化解了 m2 的刺耳浑浊，又保留了七音所特有的张力。如此一来，IIIm 便能完美履行其作为属功能和弦的角色，让随后向 VI 级的着陆更具爆发力。

IIIm 上 m2 的后续解决

然而既然拥有如此强烈的不稳定张力，保持不解决直接倾泻入主功能的 VI 级，并在那里释怀解决也是极具魅力的做法。这就是上一讲介绍的后续解决。

这种先极度蓄势、在和弦完成交替后再让旋律迟来解决的编配，在情感浓烈的情歌慢板中尤为出彩。即便只是微小的处理差异，从理论上推敲其所带来的音乐后果也极富趣味。试比较上面两组后续解决，左右两端有何不同？

右侧的模式违背了 F 音原本强烈的半音下行欲求。从音程张力来看上方为“七度”，解决感并不显著。因此与自然顺势下行的左侧相比，它呈现出一种压倒性的力量感，宛如在呐喊着“绝不妥协的誓言”，赋予了旋律极具韧性的铮铮铁骨。对于这种性格极为强烈的外壳音，前后声部的脉络语境至关重要。

这是一个罕见的在 IIIm 上密集运用 m2 Shell 的宝贵实战例。在副歌行进中的“ね 決定からの”片段中，声响极度动荡不稳，唯有在摇滚乐的狂躁语境中方能得以成立。

结合具体谱例，相信大家已经对和弦上方二度音的运用形成了清晰立体的把握。剩下的就是不断投身实战：在实际作曲与名篇分析中，将偶然邂逅的“绝妙用法”精心收藏，假以时日，这些积累必将沉淀为敏锐超群的音乐直觉。

总结

  • 2nd Shell 会因大二度或小二度的不同而呈现截然相反的特质，必须予以严格区分。
  • M2 Shell 天生具备锐利、高亢的音响，原则上允许不经解决直接长音保持。
  • 解决 M2 时，下行解决会稳扎稳打落入根音，上行解决则会到达色彩绚烂的三音。
  • m2 Shell 会产生极其强烈的摩擦不协和，因而强烈渴求得到解决。此外需注意避免在同一八度内与根音发生正面碰撞。
  • 刻意拉长类似 m2 的强烈不协和并将其带入后续和弦解决（后续解决），是一项极富戏剧表现力的高阶技法。
