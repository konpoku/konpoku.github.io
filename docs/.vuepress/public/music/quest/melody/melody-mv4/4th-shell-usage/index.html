四度外壳音（4th Shell）的用法

2026.09.05旋律论

在上一讲中，相信大家已经逐渐掌握了外壳音（）的驾驭逻辑，我们趁热打铁继续推进。本次我们要研究的是四度外壳音（4th Shell）。

1. 确认详细度数

本讲依然首先从详细度数的确认起步：

“P4”代表完全四度，“+4”代表。可以看到，本次唯独 IV 级和弦非常特殊，呈现为增四度。因此我们首先将它放在一旁，先来考察其余 5 个完全四度的和弦。

2. P4 Shell 与 sus4

当完全四度（P4）融入和弦时，从总体听感来看，它会非常接近 sus4 和弦。P4 Shell 在本质上会唤起与 sus4 相同的“悬挂吊起、悬浮空中”的心理感受。因此当旋律打出 P4 之后，级进下行解决是最标准的基准形态。若是级进上行解决，则会带来力量感十足的坚硬音响。

这不仅在于上下方向的物理差异，更在于下方是色彩斑斓的三音（3rd），而上方则是无色透明的五音（5th），两者所蕴含的度数性质完全不同。

3. 大三和弦与 P4 Shell

在拥有完全四度外壳音的 5 个和弦中，我们进一步提炼出两个大三和弦先行考察：即 I 与 V。为什么要把这两个单独拿出来呢？因为在这两个大三和弦上，面临着“旋律直接骑在和弦构成音上方”这一极其危险的高戒备模式。

由于这会产生极其强烈的刺耳浑浊，在以和弦为绝对优先的传统乐理体系中，F 音被列为避免音（Avoid note），被定性为“在和声中若长时间长音保持便无法被接受的禁忌音”。实际上，若让 E 与 F 正面狠狠硬碰，究竟会产生多大的不协和呢？让我们通过实验来验证：

旋律在 F 与 E 之间反复徘徊；而伴奏的弦乐与风琴则死死将 E 作为最高音咬住。听起来确实让人抓狂，作为音乐，根本听不出创作者到底想突出哪一种声响，不协和感令人极其不适。

现实往往更加灰色多元

然而回到现实的商业流行音乐世界，在 I 或 V 和弦上若无其事地长音保持 P4 实际上是极度普遍的现象。

在这一段音频中，伴奏的木吉他规规矩矩地扫着常规 C 大三和弦；但吉他毕竟有 6 根琴弦，与刚才的键盘长音相比，E 音并没有那么突兀夺目，而是被淹没在扫弦声中。加之电吉他还在一旁弹奏着完全不同的乐句，整体声场环境变得复杂立体，F 与 E 的碰撞反倒显得无伤大雅。 请时刻铭记：理论终归只是对声音的一种高度形式化、抽象化的模型建模，它根本无法将真实乐器的动态包络、频谱分布特征以及混音工程的远近空间考虑在内。

以旋律优先型思路进行重构

即便在听觉上不那么刺耳，底层潜藏着物理浑浊是客观事实。如果你觉得这种浑浊不够干净，只需对和弦做一点微小的改编即可——这就是“旋律优先型”的创意思维。在这种情况下，只需将伴奏改为不含三音的*“sus4”、“sus2”或“强力和弦（Power Chord）”*即可。

像这样，一旦剔除了大三度（M3），P4 的旋律线条使用起来就会顺手得多。因此在以强力和弦为主轴的摇滚乐中，在 I 或 V 上肆意延长 P4 完全是信手拈来的家常便饭。

在 3:18 起的间奏歌唱部分，旋律走势正是“F → E”，但因为伴奏采用了强力和弦，听者完全感受不到丝毫不协和。也就是说，对待此类不协和冲突，音色选择与编曲处理起着决定性的关键作用。

Check Point

大三和弦上的旋律若取完全四度，旋律音将直接骑在和弦三音上方半音。 此时伴奏应当尽量避免三音过分突出，或者干脆将和弦转为 sus4 等形式，以回避过度的浑浊摩擦。不过浑浊的感知程度很大程度上受音色设计与编曲织体的左右，创作者必须始终依靠自己的耳朵做出终审判断。

虽然“避免音”在许多理论流派中被神化为不可逾越的金科玉律，但在实际作曲中它并不是一个富有建设性的概念。像这样以“旋律优先型”的姿态来审视，我们才能在更加广阔的天地间自由自如地挥洒心中的音乐。接下来我们分别来看 I 与 V 的具体用法。

I 与 P4 Shell

基于前文的阐述大家已经明了：I 级的 P4 是“F”音，属于强倾性音，单单将其鸣响本身就会煽动起强烈的不安感。极度漫长的延伸并不常见，老老实实通过级进进行予以解决才是上策。 敢于在此处反其道而行之坚持不解决，无疑是一场极具勇气的挑战。最极端的实战典范当属东京事变的《新しい文明開化》：

在开篇副歌的末尾，人声毫无顾忌地肆意拉长了“F”音。由于全曲都在渲染一种诙谐乖张的滑稽戏谑氛围，这种离奇走调般的旋律反而成了神来之笔。在编曲上伴奏果断采用了强力和弦，巧妙避开了音响浑浊，构思极其精巧。

再看这一首的副歌部分：歌词唱到“はやく名前を呼んで 呼んで”时，和弦行进至 I 级，同时旋律的音级维持在 P4 保持长音直至乐句结束而不做解决。这一处理同样妙至毫巅：和弦虽然稳稳回到了主和弦，但心中翻涌的情感波澜却迟迟无法平复，编曲精准地用声音将这种微妙的情愫定格。 审视其编曲：一方面以失真吉他的浑厚声场为主，淡化了与主三音的冲突；另一方面极其惊艳的是——弦乐在一旁拉响了“A”音，从三度上方对旋律形成了强有力的声部护航。唯有静心细品方能洞见编曲之妙。

除非是为了表现这种非同寻常的特殊意境，否则在 I 级上的 P4 Shell 原则上都需要妥善解决。

V 与 P4 Shell

反观表面上同为大三和弦的 V 级，情况却截然不同。因为这里的 P4 Shell 对应的是主音“C”，即便存在局部不协和，在听觉心理上也极易被欣然接纳。核心音（Kernel）层面的稳定性，在此刻展现出了压倒外壳音（Shell）摩擦张力的奇妙力量[1]。 当然，若想全力发挥属和弦推进调动高涨情绪的使命，自然应当顺理成章进行解决；但反其道而行之——通过长音延伸主音直接营造稳若磐石的沉着着陆感，同样是极具魅力的路线。

在脍炙人口的优美金曲《You’re Beautiful》中，副歌开篇唱到“You’re Beautiful”的位置，在和弦踏入 V 级的瞬间，旋律却悍然砸向了主音 C，直接彻底粉碎了属和弦应有的期待感。然而正是这种处理，勾勒出了一种挥之不去的阴郁心境。 此时弦乐声部规规矩矩地垫着大三度 B 音，与人声发生了正面冲突。但由于人声旋律转瞬即逝，且弦乐启动发音较为迟缓，两者在空间中实现了完美的共生。

在副歌末尾连续三次重复“Holiday Holiday Holiday”，第 2 次正是 V 与 P4 的结合。旋律非但不去强化属和弦的力量，反而擅自提前解决沉淀，将那种漫无目的、随波逐流的漂泊悬浮感表现得淋漓尽致。

此曲副歌基于经典的 4-5-1 进行，在唱到“2人ぼっちに慣れようか”和弦由 IV 转向 V 的刹那，旋律率先落入 P4，随后在正拍上连夯两记势大力沉的 P4。 伴奏同样是清一色的电吉他强力和弦，丝毫不觉浑浊。抛开和弦羁绊在旋律中纵情放歌主音，传递出一种不容置疑的果敢与力量。

V 级常规的基准角色通常是借助旋律中的导音等元素，向着下一个主和弦蓄势推进；然而“V 与 P4 Shell”的组合却彻底打破了这一教条，擅自提前沉稳着陆，因而会自然流露出一股放荡不羁、我行我素、自由随性的别样气派。

正因如此，在流行乐与摇滚乐中这种组合频繁现身。当然在编曲时，精心微调声部配置以避免 M3 与 P4 发生恶性对撞依然是极为明智的做法。

4. 小三和弦与 P4 Shell

与需要细腻调校的大三和弦相比，小三和弦的处理则轻松自如得多。因为小三度与完全四度相距而非半音，音响浑浊度极低，几乎不会造成困扰。无论是解决还是长音保持，创作者尽可随心所欲。

不过完全四度在本质上带有的并非“甜美色彩”而是“坚硬冷峻”，因此在柔美抒情或温存恬淡的曲风中通常不受待见，它更受摇滚乐、朋克或舞曲音乐的青睐。我们来逐一检视各个和弦带来的独特意境。

VIm 与 P4 的组合

VIm 上的 P4 会为乐曲注入一种音符被凭空悬吊、脚不着地一般的轻浮悬空感。当想要表现某种坐立不安、心神不宁的情绪时最为贴切。

开篇反复高呼“Don’t let it stop”的段落正是建立在 VIm 上的 P4。在乐句末尾唱到“make it to the daylight”时级进上行解决，构筑出了一种“悬浮、悬浮、悬浮、最终落定”的精巧编曲结构。

前奏的吉他连复段（Riff）通过不知疲倦地狂轰单音 D，将“拒绝解决的偶数外壳音”贯彻到底：先是 I 与 M2，紧接着是 VIm 与 P4。那种坐立不安的悬浮感成功渲染出冷峻黑暗的阴霾。而且在 I 与 VIm 上吉他乐句完全原封不动，反倒奠定了一种“本就无须解决”的泰然自若。

IIm 与 P4 的组合

IIm 与 P4 的组合，与上一讲探讨的“IV 与 M2”存在着深刻的同构映射关系：

因为两者的和弦功能同属下属功能，旋律的核心音（Kernel）也同属“属音 G”。因此当创作者渴望获得比“IV 与 M2”更加硬朗锐利、棱角分明的声响时，这一组合便跃升为头号候选。

重温这首经典：副歌首轮开篇唱到“いつまでも”的“も”是 IV 上的 M2；而到了第 2 轮为了打破审美疲劳制造层次反差，和弦由 IV 换成了 IIm。结果在“あなたそのまま”处自然浮现出“IIm 与 P4”。这两轮之间微妙的听觉反差极其关键：它绝非单纯“和弦从小调变成大调所以变暗了”那么肤浅，更在于旋律的外壳音角色发生了蜕变，质地变得更加干脆坚硬。

IIIm 与 P4 的组合

这与刚才讲到的 V 级颇为相似。IIIm 和弦本身是深沉忧郁的属功能小和弦，但若在其上取 P4，对应音恰恰是“A”音——即旋律已经擅自着陆在了小调的主音上。

这无助于激发出 IIIm 和弦本应具备的凄婉动人，在大规模抒情歌中极为罕见。相比垂直和声导向的乐曲，它更多见于横向水平旋律导向的音乐之中。

效果如上。这是将“E-G-A”这种强韧横向乐句蛮横推至前台的表现手法。完全无视 IIIm 的哀婉羁绊，仅凭旋律自身的核心音长驱直入宣布解决，带着一种霸道粗粝的侵略感，恰好与硬核摇滚的铁血气质相得益彰。

在 MONKEY MAJIK 与搞笑艺人 Sandwichman 合作的幽默放克单曲《ウマーベラス》中，开篇副歌两度高唱标题歌词时，和弦沿着 IIm → IIIm 推进，在 IIIm 上便形成了 4th Shell。

从曲风意境来看，若在此处用奇数壳音过度渲染 IIIm 的和弦本色，属功能的戏剧化情绪就会过剩；而借助抹杀和弦本色的 4th Shell，整首歌曲得以保持平顺轻盈、不带沉重包袱的魔性洗脑感。 在摇滚乐或电子舞曲中，与其小心翼翼地侍奉每一次和弦转折，在某种程度上肆意无视和弦色彩反而能展现出洒脱帅气的现代感。

通盘来看，P4 Shell 在本质上都具备扰乱和弦既有本色的反骨特质。因此比起循规蹈矩的垂直和声体系，它在奔放洒脱的水平旋律体系中更能大放异彩。在实际创作中，“出于对横向核心音的追求而偶然触发了 P4 Shell”往往比“处心积虑去构建 P4 Shell”更加符合艺术规律。

5. +4 Shell 的用法

最后来看唯一构成“增四度”关系的 IV 级和弦。增四度拥有强烈的刺耳浑浊早已无需赘言，因此原则上它极度渴望获得解决，长音保持置之不理是极为罕见的。

在解决方向上，毫无疑问“上行”解决更为舒畅通透。因为上方仅隔半音，存在着扑向调式中心的强大向心力；而全音下行解决则属于反向逆流。

在 ABBA 名曲《Dancing Queen》副歌开端，唱到“Dancing queen, young & sweet”处，便是在 IV 级上实现了典范级的增四度上行解决。

在迪士尼经典动画《阿拉丁》的主题歌中，“No one to Tell us no, or where to go”这一片段中，第 1 次下行解决，第 2 次上行解决，形成了极其跌宕起伏的戏剧张力。 向上解决固然有着无可比拟的释怀快感，但第 1 次的向下解决却作为蓄势“延宕”展现出了独特的意境。增四度本就不易歌唱，在习惯性即兴构思中不易随手写出，掌握这类不落窠臼的武器无疑能极大拓宽旋律的维度。

总结

  • P4 Shell 能够带来悬吊起跳、悬浮空中的独特音响。
  • 其音色坚硬刚劲，极易融入摇滚乐或舞曲音乐等现代节奏流派。
  • 在大三和弦上运用 P4 时，因直接与和弦三音发生半音碰撞，编曲与音色处理需审慎考量。
  • +4 Shell 会产生强烈的不协和张力，原则上应通过级进进行果断解决。
