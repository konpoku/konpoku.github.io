六度外壳音（6th Shell）的用法

2026.09.05旋律论

经历过 2nd 与 4th 之后，我们终于迎来了最后一个外壳音——6th。让我们以成为外壳音大师为目标继续前行！

1. 确认详细度数

关于 6th，究竟是大六度还是小六度，性质会有天壤之别，因此我们依然从度数确认开始：

大写“M6”代表大六度，小写“m6”代表小六度。可以看到，本次 IIIm 与 VIm 成了少数派。我们先将这两个和弦置后，先来考察其余 4 个和弦。

2. 大三和弦与 M6 Shell

在大三和弦上的 M6 ，与和弦篇中关于“六和弦（6th Chord）”的内容有极大的共通之处。当旋律与和弦重叠在一起时，其构成音正是六和弦本身。

因此，让我们结合六和弦的知识来温故知新。

IV 与 M6

在上述大三和弦中，M6 Shell 最容易运用的当属 IV 级和弦。正如 IV6 能为乐曲注入适度的忧愁哀婉因而极其好用一样，M6 也能以完全相同的逻辑大放异彩。在 IV 级上的 M6 是“D”音，核心音（Kernel）本身就带有轻盈摇曳的质感，与 IV 级的浮空感完美契合。

松任谷由实的传世名作《春よ、来い》便是极具代表性的典范。副歌起唱处“春よ”的长音延伸，正是 M6 Shell。IV6 散发着一股独特的东方民族式幽怨与哀愁，是极具表现力的艺术瑰宝。

作为2000年代日本摇滚史上的代表作之一，Fujifabric 的名曲《若者のすべて》中唱到“夕がた”的位置便是 M6 Shell。傍晚特有的落寞感通过这一外壳音被刻画得入木三分。且与《春よ、来い》一样，在和弦内部不做解决，进一步加深了那份怅惘。

钟爱 IV × M6 的当然不仅限于日本乐坛。在欧美流行乐中，副歌唱到“Sky perfect form, I love it when she moves like that”时，特意不做板正的解决，正是其魅力所在。在营造这种慵懒随性、若即若离的倦怠厌世氛围（Ennui）时，IV 上的 M6 堪称不二之选。

V 与 M6

当和弦为 V 时，长音延伸还是做解决，走向截然不同。进行解决是标准模式，归宿通常是顺次下行至 5th，或者进一步下探至 3rd。若顺次上行，则会走向煽动不安的七音（7th），若想展现极其强烈的情感波动，这也是极佳的路径。

由于是倾性微弱的稳定音“E”，选择不做解决也是完全可行的。此时，它会起到抵消 V 级原本具备的属功能推进力的效果。这与 4th Shell 的道理如出一辙。因此在调式化（Modal）色彩浓厚、或不希望 V 级过分煽情展现属和弦功能的场景下，这一手法非常奏效。

I 与 M6

I 级和弦肩负着明亮大调主和弦的重任，因此若不加解决地与小调主音“A”长相厮守并不可取。它应当作为“挂留系（Suspend）”来对待，通常以顺次下行解决为基准。

这是多次运用 M6 顺次下行的范例。不同于 P4-3rd 那种感伤脆弱的挂留，这是将本已高亢有力的完全五度（P5）在上方进一步提起悬挂，听起来充满蓬勃充沛的生命能量。

另一个更为通俗亲切的例子：“真っ赤なリンゴをほおばる”处便是 M6。同样通过顺次下行实现了极为清爽的着陆。

反之如果不做解决，就等于默许了小调霸主的常驻，调性势必向小调倾斜，赋予音乐沉重阴郁的底色。其构成音也与 VIm 大幅重合。

VIm V I6 IIm6 IVΔ7 V I6

在幽暗阴郁风格的乐曲中，像这样刻意拉长 A 音能起到极强的艺术渲染作用。

3. IIm 与 M6 Shell

在六个基调和弦中，小三和弦与 M6 的结合唯独发生在 IIm 身上。接下来我们专门审视这一特殊形态。

实际上这是一个极具个性的组合：和弦的三音与旋律之间形成了（三全音）的关系。

这种格局相当罕见。正因如此，整体散发着某种动荡不安、飘摇未定的气质。由于核心音本身是“导音”，在此处规规矩矩地通过级进进行予以解决是基本准则。

若上行，从核心音来看便优美地向主音（Tonic）实现终止；若下行，阴暗与忧郁的色彩则会格外凸显。

IIm × M6 的独特音响

IIm 上的 M6 Shell 是一个带有着某种演歌式、传统民谣式幽深情绪的独特存在。

这是完全仅用偶数外壳音构筑的旋律短句示例。与第II章讲过的奇数外壳音相比，声音的复杂层次呈指数级提升，仿佛笼罩着一层朦胧的薄雾。尤其是在开头的 IIm 处，散发着难以言喻的东方民族风韵，魅力非凡。将其纳入武器库必将成为强大的灵感源泉。

在实际商业作品中的实战例：副歌开头“手を繋いでいて”处，便是在 IIm 上构筑了 M6 Shell。传统民族情绪与剑拔弩张的紧张感被拿捏得恰到好处。这首歌在其他片段中对偶数壳音的延宕与解决同样处理得极为工整平衡，堪称教科书级范本。

再看一首作品，请关注 3:11 起的 C 段：在“がくせいがいのこの店に ふたりでよく来たけれど”处，正是 IIm 与 M6 的组合。 这充盈着浓浓的“昭和民谣”复古深情，面对这种古典质朴的叙事，IIm 的 M6 堪称绝配。

此外这两首作品都不约而同地选择了顺次下行解决。若想原汁原味发挥这份哀愁与余韵，下行解决显然比上行更富深意。

4. m6 Shell 的用法

另一方面，在 IIIm 与 VIm 上则会构成小六度（m6）。

因为这是直接叠置在和弦构成音上方的形态，倾性被极度放大，强烈催生出解决的欲望。在使用时，原则上首先应当将和弦五音适当弱化甚至抽离以避免过度浑浊，并在此基础上果断予以解决。

这是仅保持半拍随后顺次下行解决的音频范例。恰好被收敛在“情绪轻微泛起涟漪”的适度区间，听感极为舒适。对于 m6 Shell 而言，其下方正隔半音，因此下行解决在顺滑度上具有压倒性优势。

以旋律优先型思路进行重构

然而在实际创作中，当创作者在 IIIm 上渴望将 C 音“拉长”，或者“即便拉长也没有感到强烈的解决欲望”时，请以旋律为基准重新审视：这里最契合的和弦，很可能并非 IIIm，而是斜线和弦 I/III。

若将和弦重构为 I/III，C 音立刻摇身变为沉稳端庄的“根音 / 六度壳音”。在和弦优先的传统乐理中，因为和弦进行不可动摇，往往武断判定“C 音不可延长”；但在实际作曲中，灵活切换至旋律优先思维，反向微调和弦配置往往才是通达的坦途[1]。

对这种“倾性”与“浑浊”保持高度敏锐，并将其精准转化为自己内心所追求的音响，正是我们此刻修行的核心意义。

将 m6 壳音用于后续解决

不过，在使用不经解决的 m6 壳音时，有时并不将其视作斜线和弦，而是直接将其作为极具刺激性的 m6 来看待反而更为自然。在采用后续解决的场合，这完全能够顺理成章地发生。

和弦按 IVΔ7 → V7 → VIm → I 推进。m6 Shell 的动荡不安被刻意放任维持片刻，直至和弦着陆在 I 级的瞬间同步实现释然解决。虽然带有不稳定，但因为听者能够感知到创作者的意图，反复倾听反而会对这种特质产生深深的迷恋[2]。

“后续解决”作为强行延长常规认知中“不可延长”之音的手段，展现出了极强的实用价值。在追求独特音乐情绪时是一柄不可多得的利刃。

刻意保持 m6 壳音不解决

虽然手法相当先锋激进，但在实际音乐中同样存在完全放任 VIm 上的 m6 壳音悬空不解决的实战例。

这首歌曲在幽森阴诡的氛围中苍茫地反复交替着 VIm 与 IVΔ7 等和弦。请关注 2:35 起右声道加入的旋律：作为独立于主旋律之外、宛如耳语般重复“first, and children…”的副声部线条，它不知疲倦地单调反复着 F 音。 在此前的段落中尚有回到 VIm 稳定落地的瞬间，但在此处因为 F 音的长存而彻底失去了解决的可能，由此极大地强化了诡谲异样的超现实氛围。这正是反向榨取 m6 Shell 不稳定性为己所用的极致艺术范例。

正因如此，6th Shell 各自具备鲜明的性格标签，运用逻辑也错综复杂。但驾驭好这些高难度外壳音的技艺，是成为顶尖旋律大师的必修课。

至此，通过这三讲的学习，“偶数外壳音”的系统讲解便告一段落。相信构筑旋律殿堂的底层逻辑已经更加清晰地呈现在大家眼前。 在第II章阶段，首要任务是感知 1、3、5、7 度“奇数外壳音”之间的细微差异；而今后的课题，则是不断内化各个偶数外壳音的独特质地，并亲身领悟将其向不同维度解决时所激荡出的万千情绪气象。

外壳音的修行没有捷径。用耳朵细心聆听，一步一个脚印地去融会贯通吧！

总结

  • 6th Shell 在所有偶数外壳音中拥有最为多姿多彩的用法变体。
  • 在 IV 级上最容易从容拉长；而在 V 与 I 级上则会产生轻微的“挂留感”，若放任不解决则会促使整体曲风向小调色彩靠拢。
  • 在 IIm 级上会与三音构成增四度关系，能够催生出极其独特浓烈的民族哀愁。
  • 在 IIIm 与 VIm 级上形成 m6，由于是强倾性音，原则上强烈渴求顺次级进解决。
  • 在创作中若渴望在 IIIm 或 VIm 上延长 m6 却不愿解决，将其重新审视并改写为斜线和弦通常更为自然浑厚。
