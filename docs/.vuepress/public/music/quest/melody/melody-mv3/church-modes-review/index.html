到目前为止，我们已经相继探讨了多利亚（Dorian）、混合利底亚（Mixolydian）与弗里吉亚（Phrygian）三大调式。七大教会调式中仅剩下“利底亚调式（Lydian）”与“洛克里亚调式（Locrian）”尚未登场……然而，这两者的声响极其特殊偏锋，在现代流行音乐中的实战运用空间相比前三者狭窄许多，因此我们在本节中将其一并归纳解析。

1. 利底亚调式（Lydian Mode）

利底亚调式属于大调系统（Major 系列）的明朗调式。首先，我们来确认将其与自然大调区分开来的“特性音（Characteristic Note）”。

将自然大调音阶的第 Ⅳ 音升高（♯4），便诞生了利底亚音阶。就“强倾向音的消解”这一点而言，它与多利亚调式有着异曲同工之妙：Fa 向 Mi 的半音下行解决线条不复存在，带来了一种飘飘欲仙、若隐若现的浮游悬浮感。

然而，音阶中增加了一个升号，创作时就必须打起十二分精神，誓死捍卫调性中心，严防听觉被拐带至多出一个升号的邻调去。例如在 C 利底亚调式中，极易被听众大脑误判为已经转入了 G 大调。

利底亚调式的构建困境

利底亚调式最棘手之处在于：当试图同时满足调式音乐的两大核心支柱——“强调主音中心”与“强调特性音”时，Do 与 Fa♯ 之间不可避免地会筑起一道尖锐的三（Tritone）！

“Do-Fa♯”是极其危险的。在西方经典和声思维定式中，这种三全音具有根深蒂固的双向半音反向解决本能——即向内收缩解决为“Ti-Sol”： 一旦这样解决，音乐瞬间就会彻底落入 G 大调的引力怀抱。即使旋律没有如此露骨地解决，Do-Fa♯ 的摩擦也无时无刻不在散发着“属和弦功能（Dominant）”的诱惑气味。因此，相比前述调式，利底亚调式的写作自始至终都伴随着主调感被篡夺颠覆的高危风险。 例如若沿用之前的套路：低音牢牢锚定在 C 上，伴奏充斥包含 Fa♯ 的“特性和弦”（例如 D 大三和弦）来构筑 D/C……

C D/C の繰り返し

即便做到这一步，听众的耳朵依然极易将 C 和弦误当成 IV 级下属和弦、而非真正的 I 级主和弦。这既是因为形成 Do-Fa♯ 的 D/C 自带属和弦色彩，也是因为现代人的耳朵早已对流行乐中不解决回主和弦、无休止循环 IV — V 的套路习以为常。

要让习惯了现代流行乐耳感的人们纯正地感受到“利底亚之所以为利底亚”的超然美感，单靠和弦进行远远不够，旋律写作必须施以极其细腻高超的技巧护航。

驾驭利底亚调式的绝妙秘籍

任天堂经典游戏《耀西故事》（Yoshi's Story）第 1-1 关的 BGM《耀西之歌》（ヨッシーのうた）开篇，堪称将利底亚调式驾驭得炉火纯青的传世神笔。其织体结构毫无赘笔：低音贝斯首先以“Do-Sol”的极简反复牢牢向听觉灌输 Do 的中心统治地位；而旋律一开篇便毫不避讳地唱响 Fa♯。就在所有人担心“低音与旋律形成的 Do-Fa♯ 会不会崩盘”的瞬间，旋律立刻顺流直下迈向 Mi，以此向听觉昭告：这里的 Fa♯ 绝非奔向 Sol 的导音！ 这招妙到毫巅：它巧妙模拟了自然大调中人尽皆知的“Fa → Mi”解决线条，给听众心理暗示这只是该解决形态的变体“Fa♯ → Mi”。 若依常规倾向性法则，Fa♯ 本应顺滑迈向仅半音之隔的 Sol，但那样做只会助长 Sol 篡位成为中心。刻意向内跌落至 Mi，反而牢牢树立了“Mi 是稳定音”的信念，从而更加巩固了中心是 Do 而非 Sol 的认知。 正因为需要如此严密小心的呵护才能立足，若想全曲从头到尾纯靠利底亚展开篇幅极其艰难。因此这首作品在后半段果断过渡至混合利底亚调式或常规大调，巧妙完成了乐段的生动推进。

2. 洛克里亚调式（Locrian Mode）

最后一位成员洛克里亚调式，归属于小调系统（Minor 系列）。由于它具有与弗里吉亚调式一脉相承的压抑重浊，我们不妨将两者横向对比：

显而易见：自然小调调暗一度便化身弗里吉亚，在此基础上再暗一度便是洛克里亚。相比弗里吉亚，它的第 5 音进一步被降下半音（♭5）。这个 ♭5 音，正是洛克里亚调式的特性音。

洛克里亚调式的致命困境

由于音阶中最神圣不可侵犯的第 5 音遭到了变音降下，在洛克里亚调式中，以主音为根音以“三度叠置”构筑三和弦时，根本无法获得正常的稳定小三和弦，而是会演变成一个小三降五和弦（减三和弦，m(♭5)）！

因此，其他所有调式通用的“只要狂轰主和弦就能宣誓中心地位”的黄金法则在此彻底失效！无论你怎么演奏主和弦，听觉上都无法建立起安如磐石的稳定调性感。正因如此，洛克里亚调式在七大调式中是最为偏锋诡谲、极难驯服的存在。

驾驭洛克里亚调式的实战法则

若想用洛克里亚调式独立撑起乐段，通常必须抛弃传统古典那套依赖三度叠置和弦进行的陈旧体系，转而依托旋律动机的单音多重叠置与机械反复来建立骨架：

像这样执着地围绕调式主音（Modal Tonic）循环叠置单音短句，便能在听众脑海中强行烙下中心印象。这能营造出比弗里吉亚更为阴冷晦涩、甚至带有邪魅宗教仪轨感的奇诡声响。其声响与某些古老音阶颇有神似之处，极具苍凉异质之美。

在构建旋律时，秘诀在于：善用与自然小调共享、且极易融入旋律骨架的第 3、4、7 音：

将这三个稳定友善的音与调式主和弦巧妙咬合，便能让听众真切认可该主音正是真正的调性中心。

上面是 EDM 中巧用洛克里亚调式的实战范例。将本难驾驭的减五度音（♭5），升华为类似“布鲁斯音符”那般桀骜狂拽、阴郁邪魅的听觉利器。

在 BLACKPINK 的现象级爆曲《Kill This Love》中，开篇前奏与 Drop 部分轰鸣的铜管乐句，便展现了纯正的 D 洛克里亚调式风貌。乐句精准提炼了 D、E♭、G、A♭ 四个核心音，在全曲小调的基底上猛烈灌入 E♭ 与 A♭，构筑了纯正的洛克里亚式黑暗神殿。相比弗里吉亚，正是减五度 A♭ 的介入赋予了其无与伦比的深渊压迫感。

在重金属（Metal）领域同样有其身影。吉他 Solo 虽然大多游弋在常规小调中，但在侧翼负责弹奏重型 Riff 的强力和弦（Power Chord）却坚定采纳了洛克里亚调式。主音与特性音构成的三全音在历史上被称为“音乐中的恶魔（Diabolus in Musica）”，这种恶魔般的毁灭声响与重金属气质堪称天作之合。

至此，全部七大教会调式已悉数登场。然而，多利亚、混合利底亚与弗里吉亚这三大主力调式，各自还隐藏着尚未揭晓的另一副面孔。接下来，我们将通过总复习，一举解锁它们在流行音乐中的深层隐藏用法！

3. 多利亚调式（Dorian）深度复盘

首先回顾应用疆土最为辽阔的多利亚调式：

调式档案 属性详情
英文名 Dorian Mode
系统归属 小调系统（Minor 系列）
特性音 升高半音的第 Ⅵ 音（♯6 / 自然大六度）
艺术意象 苍茫异域、凯尔特民谣、幻想史诗

因恰好与古老凯尔特民族音阶暗合，多利亚调式自带一种苍茫悠远的异域风情。 它能举重若轻地唤起“民族史诗感”，且不会像阿拉伯音阶那样将听众瞬间窄化至特定地域联想，因而成为游戏原声配乐（Game BGM）的宠儿。

多利亚调式与和弦体系

复习其核心和弦骨架：

需牢记：即便同属“共有和弦”，实战使用频次仍有差异。在多利亚调式中，IIIm 的出场率相对稀薄。V 和弦打上括号，是因为当叠加至七和弦（V7）时会产生原调没有的大七度声响；但作为纯粹的三和弦使用时，极为自然且出场率极高。

摇滚与爵士中的隐藏杀招

多利亚调式的魅力远不止于民族风情，在摇滚与爵士乐的先锋即兴演奏（Improvisation）中，它更是核心台柱！在此情境下，编曲往往仅仅依靠单一的 VIm 和弦铺底，随后乐手便在其上尽情挥洒多利亚即兴线条： 由于原调中从半音上方压迫 La-Do-Mi 和弦音的 Fa 音被升华为 Fa♯，旋律极大地避免了对伴奏和弦内音的粗暴撞击，这是乐手们在即兴 Solo 中对多利亚情有独钟的深层声学根源。经典名作如迈尔斯·戴维斯（Miles Davis）的《So What》、前卫摇滚名团 Yes 的《Close to the Edge》皆深谙此道。

教会调式在被现代流行音乐吸收咀嚼的过程中，蜕变出了与古代完全迥异的现代生命力，这正是乐理演进中最迷人的篇章。

4. 混合利底亚调式（Mixolydian）深度复盘

接下来重温混合利底亚调式：

调式档案 属性详情
英文名 Mixolydian Mode
系统归属 大调系统（Major 系列）
特性音 降低半音的第 Ⅶ 音（♭7 / 自然小七度）
艺术意象 豪放不羁、爽朗干脆、大地狂野

调内原本最核心的强倾向音“导音”被降下半音，使其与调性中心的距离被拉开为全音。半音级进的甜腻感烟消云散，换来了无可比拟的豪放与毫无矫饰的爽朗阳光。视旋律与节奏编排而定，它既可极度 Pop，亦可无比硬核摇滚： 强调“Ti♭ — Do — Re — Mi”全音四连击会显得诙谐俏皮，而以“Fa — Sol — Ti♭ — Do”为核心则瞬间化身美式硬摇滚风范。

混合利底亚调式与和弦体系

IIm 与 VIm 色彩偏暗，实战中选用较克制。若过度堆叠副属性和弦，听觉会迅速被拽向小调深渊，因此拿捏分寸至关重要。

布鲁斯中的天然基因

混合利底亚尚未提及的隐藏主战场，正是布鲁斯音乐（Blues）！ 布鲁斯以用属七和弦（C7）替代主三和弦（C）而闻名。当在 C7 和弦上挥洒吉他或管乐 Solo 时，指尖流淌出的音阶天然就是混合利底亚音阶：

布鲁斯音乐那份骨子里的醇厚狂野，正是源自“导音消失”所带来的奇妙解放。Ti 的降号化与前述的“布鲁斯音符”在底层逻辑上息息相通。

5. 弗里吉亚调式（Phrygian）深度复盘

最后回顾贴地重浊的弗里吉亚调式：

调式档案 属性详情
英文名 Phrygian Mode
系统归属 小调系统（Minor 系列）
特性音 降低半音的第 Ⅱ 音（♭2 / 小二度）
艺术意象 泥泞沉重、压抑深渊、大地重力

原本理应向上扬升的第 2 音被降下半音，使其向下俯冲的重力引力呈指数级暴增，催生出“宛如深陷泥淖般的大地重力感”。由于调性中心极难确立，和弦进行必须尽可能保持极度简朴利落： 在慢速钢琴曲中，它散发出无与伦比的压抑死寂；而这股庞大的下潜能量，在现代 EDM 的凶猛 Drop 中化作了开山裂石的核武器：

弗里吉亚调式与和弦体系

实战中仅需依靠 VIm 与 ♭VII 两个和弦来回咬合便已足够，画蛇添足往往导致调性感彻底瓦解崩塌。

以“沉重压抑”著称的弗里吉亚，若将 VIm 与 ♭VII 的交替推进以极快的速度扫弦狂飙，听感会发生什么质变？

某种令人血脉贲张的异国风光瞬间扑面而来……

没错！这正是热烈狂放的西班牙舞曲与弗拉门戈（Flamenco）的标志性神韵！在此和弦之上弹奏即兴 Solo，弗里吉亚音阶完美契合，但其散发出的氛围却与先前的阴暗截然相反，蜕变为了炽热滚烫的狂放吉普赛之火：

吉他的狂野扫弦与疾风骤雨般的律动，将原本的阴郁彻底升华为了喷薄而出的炽热生命力。

西班牙八音阶（Spanish 8-Note Scale）

顺带一提，弗里吉亚音阶与正统西班牙音乐音阶极为同源。只需在弗里吉亚音阶中额外融入一个音符，便诞生了享誉乐坛的“西班牙音阶”：

由于在一个八度内使用了 8 个音符，它属于正统的“八声音阶”，正式学名为**“西班牙八音阶（Spanish 8-Note Scale）”**。构建 E 小调的 G 音与构建 E 大调的 G♯ 音奇迹般地并存共处，造就了跨越大调与小调维度的奇幻魔力：

异域民族音乐的渊深博大，在此展露无遗。

6. 教会调式之间的深层拓扑关系

审视第 III 章所学的各大教会调式，与其机械按照音名死记硬背，不如从“音级构成的明暗渐变”来宏观俯瞰其全貌。以调性中心音为基准，按照**“由明亮至阴暗”**的顺序纵向排开，一张震撼人心的宏伟图景跃然纸上：

惊人的规律显现了：沿着明暗阶梯每下行一步，恰好只有一个音级降下半音，不多不少！

明暗顺位 调式名称 核心调式特征 相对明暗属性
1 利底亚（Lydian） 拥有 ♯4，飘逸空灵超凡脱俗 最明亮（极明）
2 爱奥尼亚（Ionian / 自然大调） 标准大调，没有任何升降偏离 明朗（正大）
3 混合利底亚（Mixolydian） 导音降为 ♭7，豪放爽朗不羁 微暗大调
4 多利亚（Dorian） 三音降为 ♭3，升入小调阵营，保留 ♯6 苍茫开阔 微明小调
5 爱奥利亚（Aeolian / 自然小调） 标准小调（♭3, ♭6, ♭7），伤感清冷 阴郁（正小）
6 弗里吉亚（Phrygian） 二音降为 ♭2，大地泥泞重浊压抑 深沉幽暗
7 洛克里亚（Locrian） 五音降为 ♭5，失去纯五度锚定，地狱深渊 最阴暗（极暗）

包含大三度与纯五度的是明亮大调阵营的三位成员；三音下沉降为小三度后，正式迈入小调阵营；而当纯五度也失守沦陷为减五度时，便坠入了极不稳定的洛克里亚。这种基于同一主音并置对比的视角，被称为同主音并联视角（Parallel Aspect）。如同漫游在由七重彼此微调的平行宇宙之中。

关系调视角（Relative Aspect）

除并联视角外，若将调式按大调与小调大类归纳，基于熟悉的“关系调视角（Relative Aspect）”同样豁然开朗：

将最为偏激的洛克里亚暂且剥离，其余四位成员（多利亚、利底亚、弗里吉亚、混合利底亚）相比于常规大调/小调，均仅仅发生了一个音级的改变，且变动的音符必定是 Fa 或 Ti 两者之一！

正如自然大调与自然小调互为起点位移的关系调一样，利底亚与多利亚、混合利底亚与弗里吉亚，在本质上亦是同根同源的互逆镜像[2]。

广义的关系调（Relative）

自然大调与自然小调构成音完全相同、仅中心音不同，传统上称为“关系调（Relative）”。而全部七大教会调式，本质上亦是“一套物理白键构型，轮换七个不同主音”，因此七大教会调式全员皆为互为广义关系调的至亲手足。

自然音阶（Diatonic Scale）的真正内涵

七大调式皆由“全全半全全全半”的音程序列环形位移演化而来。在尚未钦定任何主音的纯粹抽象形态下，这个原始音程链条被冠以崇高的学术命名——自然音阶（Diatonic Scale）[3]。

十二平均律全员集结的音阶被称为半音阶（Chromatic Scale），与自然音阶构成了对偶的理论两极。以自然音阶体系为骨干构建的音乐被定义为“自然音体系的（Diatonic）”，而充斥变音摩擦的则被称为“半音体系的（Chromatic）”。

从预备篇的自然大调与自然小调起跑，历经第 I 章的“四七拔、四拔、二六拔”五声音阶，到第 III 章前半程的“布鲁斯音阶”、“和声小调”、“旋律小调”、“全音阶”，再到下半程的五大教会调式与“西班牙八音阶”……至此，你的旋律武器库已完成了质的飞跃，稳步跨入高阶音乐人的殿堂！

总结

  • 利底亚（Lydian）与洛克里亚（Locrian）因其内部包含三全音或缺乏纯五度支持，在构建独立调性中心时面临极高挑战，需要极其精湛的声部护理。
  • 各大教会调式横跨古典、现代爵士、重金属、EDM 与拉丁弗拉门戈等多重流派，展现出百变神韵。
  • 从同主音并联视角审视，教会调式严格遵循由利底亚至洛克里亚“每步暗淡一个半音”的阶梯规律，深刻掌握这一谱系将为旋律色彩调配提供无尽源泉。
