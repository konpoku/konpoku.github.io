进入第II章后，基调和弦以外的新和弦——即“基调外和弦”大量涌现。本篇文章将详细解析如何对这些基调外和弦运用连接系理论。

1. 连接系的复习确认

我们再次重温各个连接系统的特征如下：

系统 含义 特征
2▲2▼ 上/下行二度 平和而平顺、色彩丰富
5▲ 上行五度 明快的推进力、富有个性
5▼ 下行五度 明快的推进力，且顺耳自然
3▲ 上行三度 音色变化小，具有独特的上浮感
3▼ 下行三度 音色变化小，极具安定感

将这一套分类与分析方法套用到基调外和弦上，正是本讲的核心主旨。

2. 基调外和弦的连接系

对于基调外和弦，我们的审视视角依然相同：关键在于作为“控制因子（Control Factor）”的和弦性质（Quality）与根音（Root）如何变化，以及由此产生了多少共同音。让我们来看几个范例。

II → IV 的连接

例如 $II \to IV$ 属于 3▲ 连接，它同样拥有与 $II_m \to IV$ 相似的那种轻盈飘忽的浮升感。虽然少了“由小三和弦转为大三和弦的豁然明朗”这一剧情反差，但另一方面由于共同音减少到了1个，从这个角度看其音响质感的变化反而略微增大了。

IVm → V 的连接

$IV_m \to V$ 与 $IV \to V$ 同属 2▲ 连接，但由于和弦性质从“小”转向“大”，能让人清晰感受到情绪的转折变迁，从而营造出更具戏剧性的展开。

因此，当觉得单纯的 $IV \to V$ 能量感不足时，将其替换为 $IV_m$ 会非常奏效——正是可以得出这样的推论。

降号系根音（♭系根音）的连接

即便面对拥有全新根音的 ♭VI 或 ♭VII，原理也没有太大区别。

  • ♭VI → V 属于 2▼ 连接。由于两者同为大三和弦没有大/小性质的转变，且根音呈关系下行，因此动向极为顺畅。
  • ♭VII → V 属于 3▼ 连接。实际聆听会发现，它确实具备与基调和弦内 3▼ 连接相似的稳健沉着展开感。不过由于Si带上了降号，共同音缩减为仅剩1个，因此在听觉色彩的转变幅度上略微偏大。

尤其值得一提的是，降号系根音往往都存在半音下行以实现极致顺畅进行的模式。半音的运动在二度进行中具备更高层次的平滑连贯度，而在基调和弦内部，以往仅存在于 $III_m \rightleftarrows IV$ 之间。如今有了基调外和弦，这类半音平滑连接一口气增加了3种之多。

和弦性质的变化、根音的变化，以及由此带来的共同音多寡——由于这些要素全都是脱离调性（Key）而独立存在的信息，因此哪怕是脱离了调内的基调外和弦，我们依然能够一如既往地分析其连接关系。

斜线和弦/转位和弦与连接系

对于分子与分母分别承载不同内容的“斜线和弦（Slash Chord）”，该如何判定往往也让人感到困惑。理想的做法是分别观察分子（上方和弦结构）与分母（低音声部）各自形成的连接，因此推荐在记录连接系时同样使用斜线并列书写两个系统。

这样一来，我们便能更加精密地洞察音响现象的本质——例如“整体声响印象上具有 5▼ 那种明快且稳定的推进力，但其过强的冲击性能量却通过低音线条的 2▲ 级进得以收敛与克制”。

3. 连接系的拓展应用

相较于基调和弦之间连接的自由洒脱，像升五度（$\sharp 5$）或降五度（$\flat 5$）这类特殊和弦的进行，其奏效的用法不可避免地会相对受限。通常我们只能将其作为经典模式逐一熟记。

但在某些情况下，我们也可以依托“控制因子”来反向构筑和弦进行，这是一种极佳的应用思路。例如……

dim7 彼此之间的连接

想连续使用减七和弦（$\text{dim}7$）创作恐怖惊悚的BGM，但不知道和弦应该按照怎样的轨迹运动才好……

想要连续使用以诡异阴森声响著称的减七和弦来打造进行——面对这种流行乐教科书上绝无仅有的非典型创作咨询：

各种各样的减七和弦究竟该如何连接？让我们以连接系理论为指南针来尝试构筑和弦进行。

① 借助连续 3▼ 连接构建

“o7（$\text{°7}$）”是减七和弦（$\text{dim}7$）的简写记号。这里的例子根音按照 C - A - F♯ - E♭ 的轨迹进行。减七和弦的特征在于“所有和弦音彼此皆呈小三度间隔”，因此在这种进行形态下正如你所见，其构成音成员完全没有任何变化[33]。

从连接系理论的角度来看，该进行的特征表现为“连续的 3▼ 带来安稳感”，且“由于构成音毫无改变，音乐的行进展开感极其微弱”，可以说是一种高度偏向稳定停滞的和弦进行。

② 借助 2▲、2▼、5▼ 连接构建

另一方面，这里采用了 2▲ – 5▼ – 2▼ 的连接方式。当 $\text{dim}7$ 进行二度连接时，4个构成音全员大换血，因而会带来音响色彩上的巨大突变。在此例中，它恰到好处地营造出了一种“紧张感层层加码递增”的悬疑效果。此外，5▼ 连接本就拥有轮廓清晰的推进力，因此在这里同样带来了一种宛如向前迈进一步的情绪推移。

将两者对比试听便会发现，前一个示例停滞在原地的感受极强，听起来情节毫无发展推进；而本例则充满了动态。因此同为“恐怖惊悚BGM”，第①种模式非常契合“屏息静气躲藏在某处不敢动弹的场景”，而第②种模式则更契合“在幽暗阴森的回廊中缓慢摸索前行的场景”……我们完全可以像这样，从理论层面去有理有据地设计音乐形象与氛围。

基调外和弦与三度连接

在爵士乐和流行乐中，人们偏好轮廓分明、起承转合清晰的进行；但在某些流派中则不然。事实上在Techno或舞曲音乐中，起伏较小的三度进行更受欢迎；而在电影配乐（Cinematic Music）的世界里，通过三度进行连接基调外和弦早已成为经典定式之一。

像这样，交替连接 C 和 E。有趣之处在于，这里的E并非基调和弦中的 $E_m$，而是直接使用大三和弦 $E$ 甚至是 $E_m^{\Delta 7}$。尽管手法极其质朴简练，却营造出了相当宏大开阔的电影原声质感。

如果在 C 之后接 E，接下来往往会顺理成章走向 $A_m$，这是流行乐的经典套路；但若做出那种情感充沛的推进，在此类BGM中未免过于抢戏与喧宾夺主。3▲ 与 3▼ 构筑的从容舒缓动势，赋予了音乐一种宛如置身浩瀚宇宙般的深邃辽阔感。

我们进一步增加七和弦的比重，使其更加复杂化。虽然以 C 和弦开篇，但第三个和弦却插入了同主音小调（Parallel Minor）中性格极其独特的“硬茬”——$C_m^{\Delta 7}$。最后的 $A^\flat_m$ 若放在 C 大调的世界观下来看也是极其异质的存在。像这类“带有变音记号的 III、VI 系和弦”，统称为半音中音和弦 / 色彩中音和弦（Chromatic Mediant）。

在构思此类和弦进行时，“共同音越多，音响层面的突变越小，衔接越平滑自然”这一连接系理论的基本原则依然普遍适用。即便引入了带有变音记号的和弦或复杂的七和弦，该法则依然颠扑不破。例如从 $E^{\Delta 7}$ 走向 $C_m^{\Delta 7}$，乍看之下似乎突兀离奇，但实际上 B 与 D♯（即 E♭）这两个音原封不动地被保持作为共同音。上方的范例正是利用了这一点，使两者实现了天衣无缝的平滑衔接。因此在某种意义上可以说，正是在这种包含基调外和弦的特殊进行中，连接系理论的思维模式才能发挥出最大的威力。

形式千变万化

面对“减七和弦4连击”或是“肆无忌惮地狂用基调外和弦”这类操作，可能有人在此之前压根连想都没想过。但在第I~II章中所学的以基调和弦为主干的体系，本质上不过是“便于写出大众顺耳流行乐的既定轨道”；一旦你想打造不同风味的作品，随时都可以果断驶离这条轨道。人在掌握更多知识之后，难免会容易固步自封地在已知知识的框架内打转，因此希望大家时刻不要忘记在框架之外还延展着广袤无垠的“未开垦荒野”。

4. 三全音连接（TT连接）

顺带一提，对音程度数敏感的读者在刚才看到分类时或许已经敏锐地察觉到了：随着和弦储备的丰富，诞生了一种全新的根音运动轨迹——那就是以三跳进进行移动的连接法。

根音以三全音跳进进行的范例

在基调和弦的世界中虽有 5▲ 和 5▼，但它们全都属于“纯五度（或纯四度）”的连接。三全音（Tritone）——即减五度/——是一种极具鲜明个性的音程，因此将其单独划分为独立系统更为适宜。针对这种连接，我们直截了当地将其命名为“三全音连接（Tritone Nexus）”，并简记为 TT。

5. TT连接的用法

接下来，我们将阐述 TT 连接的独特韵味与魅力。

所谓的“三全音移动”，是在十二平均律世界中所能实现的“距离最遥远的跨越”。 可能会有人觉得“上行纯五度不是更远吗？”，但换个视角看它本质上等同于“下行纯四度”，因此其实并不遥远。唯有无论从上方还是下方度量都是最远距离的音程，才是彼此相距最极端的三全音。

正因跨越距离过于遥远，它在基调听感上基本会产生一种音乐语流骤然断裂的断层感。反过来说，这同样意味着它是戏剧性颠覆音乐流向的绝佳契机。

加之 TT 是在纯基调和弦世界中绝无可能发生的连接方式，综合这些因素，它堪称最具震撼力与冲击感的一种和弦连接法。

善用其震撼的冲击力

结合这一背景可以推断：在运用 TT 连接时，将目的地设定为基调外和弦往往能收获更佳的乘数效应。相反，如果终点依然落回基调和弦，就容易陷入“起跳姿态极为震撼，落地的和弦却平平无奇”的尴尬境地，反而有让人大失所望（虎头蛇尾）的风险。

因此在本讲中，我们将重点介绍实用价值极高的、通向基调外和弦的各类 TT 连接模式。

IV - VII 的连接

不久前我们介绍了半减七和弦——$VII^{{\oslash}7}$。在常规理论中，它基本被视作只能导向 III 系和弦的过渡性角色。然而由于该和弦本身自带浓厚的浪漫伤感气质，一旦通过 TT 跳进突入该和弦，便能激发出极其强烈的剧情展开感。

I IV VIIø7 III7 VIm

正是这种感觉。先从容沉稳地通过 $I \to IV$ 铺垫好“起”与“承”，随后以迅雷不及掩耳之势突入 $VII^{{\oslash}7} \to III_7$ 掀起“转”的戏剧高潮，最终平稳落脚于 $VI_m$ 完成“合”。这是一套结构精妙的和弦进行。除抒情慢歌（Ballad）外，在爵士乐中该手法同样被广泛采纳。

♭VII - III 的连接

从以“漂浮感”著称的 $\flat VII$，一跃连接至以“强烈的焦虑不安与阴沉感”著称的 $III_7$。这同样极具戏剧张力，若将其纳入口袋法宝库，实战中会是非常实用的利器。

IIm7 IΔ7 ♭VIIΔ7 III7sus4 III7

这是对在“同主音和弦（Parallel Minor Chords）”一讲中介绍过的音源进行的重新编曲。刚在 $\flat VII$ 营造的轻柔微醺中飘飘欲仙，紧接着瞬间被拽入极端不稳定的 $III_7$ 深渊！加之根音是以三全音跳进完成的，真正称得上是急转直下。在浩瀚的和弦进行库中，这堪称戏剧张力首屈一指的顶级连接。

II - ♭VI 的连接

导向 $\flat VI$ 的 TT 连接同样帅气非凡，特别是在摇滚风格的编曲中尤为契合契合。

VIm7 IIm7 ♭VI IΔ7

$II_m$ 在本质上是一个蓄力充能（“蓄势”）的和弦，接下来极易引发重大动作；而 $\flat VI$ 则自带一抹“妖艳诡谲”的色彩，能使音乐氛围发生翻天覆地的转变。因此从 $II_m \to \flat VI$ 的动向，在驱动音乐剧情展开方面可以说是非常合情合理的模式；加之根音以三全音跨越，其戏剧冲击更是不言而喻。

I - ♯IV 的连接

利用此前刚刚学到的 $\sharp IV^{{\oslash}7}$ 同样可以实现 TT 连接——直接从安心感拉满的 $I$ 飞跃跳出。

IIm7 V6 IΔ7 ♯IVø7

这无疑是一段极其富于戏剧张力的展开。仔细探究便会发现，$\sharp IV^{{\oslash}7}$ 的构成音在暗地里与 $VI_m$ 有诸多神似之处，正因如此，亦有理论流派将其视为具有主和弦功能（Tonic）的和弦。切莫因为其声响奇特而敬而远之，大胆尝试运用会发现它别有一番意趣。

VI - ♭III 的连接

从 $VI_m$ 连接至 $\flat III$，听感上几乎会产生一种近乎失控的错乱感——漂浮感过强导致调性飘摇不定。因此在常规乐曲中较难驾驭，但如果你的目的恰恰是营造出怪诞陆离的失重漂浮感，它便大有用武之地。

VIm ♭IIIΔ7 VIm ♭IIIΔ7 VIm ♭IIIΔ7 IIm7 Im7

TT 连接若连续执行两次，根音便会精确返回原点。此例正是利用了这一特性，将相隔三全音的两个和弦构成了往复循环。在舞曲音乐（Dance Music）中，这种出人意料的离奇进行完全能够大放异彩。

作为王牌“王炸 / 鬼牌（Joker）”储备在手

由于每种连接呈现出的曲风差异极大，此番介绍可能略显发散。但它们全都是 TT 这一单一连接类型，并且无一例外在“意图打造夸张戏剧性展开时的强力武器”这一点上达成了高度共识。

尤其是最后这三组，如果不特意推介并鼓励大家“大胆去用！”，恐怕很多人平时根本不敢轻易尝试这类奇门怪招。然而事实正是如此——唯有它们才能勾勒出独一无二的奇特意境，每一种和弦进行都有其不可替代的存在意义。

正是如此，从“根音移动”与“和弦性质变化”，以及相伴相生的“构成音交替变化”出发去剖析与构思和弦进行的意境构图，这一思路在基调外和弦上同样高度适用。虽然本讲涉及了诸多平日里难以想象的奇特异质和弦进行，但我们首先应当牢记在心的根本准则，是音乐本就享有至高无上的自由。

以基调和弦为主体的音乐，归根结底只是因为易于听众接受，才成为了流行音乐的基础范式模板；而我们完全拥有毫无理由地打破常规、迈步出圈的权利。只是如果毫无章法与目的性地盲目越界，往往难以创作出优秀的音乐。而借助连接系理论来推敲设计音乐情境与动向，我们便能实现真正“精妙且高明的出格”与创新。

总结

  • 面对基调外和弦，连接系理论的应用分析法则依然完全适用。
  • 根音以三全音跳进移动的 TT 连接，通过将目的地导向基调外和弦，能够激发出极具冲击力与震撼感的戏剧性展开。
