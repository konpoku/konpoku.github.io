在上一讲中，我们概述了关于和弦“连接”的宏观构想。两两和弦连接所带来的音乐情绪，在 T、D、S 功能论的基础上，若结合“根音位移”与“品质转变”这两大“控制要素”展开剖析，脉络便会变得无比明晰。 关于和弦品质，通过第I章的“品质改变”等内容大家想必已经驾轻就熟；然而对于根音的行进轨迹，此前我们却甚少系统涉及。 “根音的移动轨迹”在现代音乐学中通称为根音行进（Root Motion）。接下来我们将揭示：透彻理解根音行进对于和声编配究竟有多么至关重要。

1. 基于根音行进的体系分类

接下来我们将对30种连接模式逐一展开解剖。在组织逻辑上，我们并非按照“V级之后容易接什么……”这类孤立线索，而是以“根音移动2度的连接”、“根音移动3度的连接”等形式，将根音的位移跨度作为第一基准分类：

以此类推，我们将所有二度移动的模式归拢为一篇、三度移动归拢为一篇…… 以根音行进为纲领对和弦进行展开分类，是严肃的古典与爵士理论著作中所遵循的经典治学方法。在这些传统音乐体系中，存在着备受偏爱的根音行进与被冷落排斥的根音行进；即便在缺乏明文成典的摇滚乐与电子舞曲中，各流派同样存在着鲜明的风格偏好。 因此，以根音行进为基准进行归纳拆解，能够帮助我们精准洞悉各门流派的审美偏好，并在作曲实操中自如调控“某一风格独有的纯正血统”与“跳脱陈套的反叛风骨”。

2. 预设前提与符号约定

在展开具体实战剖析之前，我们先统一确立一套高效凝练的专业语言与记谱符号。

上行与下行的符号简写

在接下来的文章中，“二度上行”、“三度下行”等术语将以极高频率出现。为了避免版面冗长繁琐，我们采用“2▲”、“3▼”等直观符号进行简写：

这与将“A小和弦”简洁记作“Am”是完全同源的思路。口头读法可根据个人习惯自由选择，例如“5▲”既可读作“五度上行”，亦可简称为“5上”或“Five Up”。

忽略八度音区差异

以 V→I 连接为例，低音贝斯的实际弹法既可能是“上行纯四度”，也可能是“下行纯五度”：

然而在讨论连接系理论的抽象本质时，这种八度音区的物理高低并不构成功能差异，因此将二者完全同一视之。如此一来，6个自然基础和弦之间的所有两两连接，在距离上必然归结为 2度、3度、5度 三大类之一：

至于为什么唯独选择标记较大的“五度”而非“四度”，一方面源于音乐理论界深厚的历史传统，另一方面在统筹记忆时也更为系统便捷[26]。 从数学审美来看，2、3、5恰恰构成了“最小的三个质数”，比起2、3、4反而自有一番和谐严密的纯粹美感。 综合上述逻辑，自然基础和弦的30种连接模式最终被规整收敛为以下6大家族：

根音行动 简记符号 经典连接范例
二度上行 2▲ I→IIm, IV→V
二度下行 2▼ VIm→V, V→IV
三度上行 3▲ I→IIIm, IIm→IV
三度下行 3▼ VIm→IV, V→IIIm
五度上行 5▲ I→V, IV→I
五度下行 5▼ V→I, IIIm→VIm

关于旧日禁则的标记法则

在当代流行音乐中，和弦进行早已没有任何教条禁则。然而，了解哪些模式“曾经被古典视作禁忌”却极具战略意义：守规矩能让你的作品温文尔雅、古意盎然，破规矩则能让你的作品充满先锋锐气与反叛张力——它能让你成为一名有意识精准调控音乐‘古典度与前卫感’的高维创作者！ 因此，对于这类“曾经的禁则”，本站采用不同颜色的虚线进行醒目标识：

V→IIm 正是『曾经的禁则』

传统理论著作对这些禁则往往讳莫如深、避而不谈；自由派音乐理论则致力于结合浩瀚的现代实战案例展开深剖，填补这一巨大的学术断层。 接下来，我们先全局总览各个连接家族的核心声学性格。

3. 各大连接家族的核心性格

二度连接（2▲ / 2▼）

2▲与2▼是指向紧邻相邻和弦的步进移动，带给听众极其温和平顺、如履平地的听觉印象。虽然在2▼中躺着两个旧日禁则，但得益于二度级进天生的丝滑粘合力，在现代创作中早已脱敏。大体上可以将其统领记忆为：行进极其顺滑自然，擅长营造温润和缓的音乐意境。

五度连接（5▲ / 5▼）

跳过三度优先审视五度。与二度截然相反，五度因其根音跨度宏大，听起来格外充沛刚健。审视上行与下行：5▲包含一个旧日禁则，而5▼则全员清白、没有任何禁则！这与二度连接展现出了显著的分水岭。

统治传统体系的 5▼

爵士乐向来对五度下行（5▼）展现出极度狂热的偏爱，以至于部分权威专著甚至断言“爵士和声运动的绝大部分都是由五度下行构筑而成的”[27]。

2-5-1-4-2-5-3-6

上面这段几乎全盘由5▼贯穿的示范，散发着无比醇正地道的爵士气韵。在古典和声中，5▼同样被奉为主干基石，在通向主和弦I的路径中，V→I享有绝对凌驾于IV→I之上的霸权。 由此可见，古典与爵士这两大西方正统理论学派，均旗帜鲜明地将5▼置于高高在上的核心地位。

秉持反骨叛逆的摇滚与电音

逆向思维随之而来：只要刻意规避5▼，便能瞬间撕下古典与爵士的刻板烙印，塑造出反叛前卫的现代质感！ 在现代摇滚乐与EDM中，大量诞生了以5▲为核心骨架的招牌神级进行。

例如Rob Thomas的名作《Her Diamonds》，副歌完全由“1-5-2-4”的死循环构筑——换言之，进行的大半全数是5▲！

而且中途连续两次公然违背古典禁则！该曲纯正硬核的摇滚风骨，除开配器与唱腔，本质上正是根植于这种反古典、反爵士的先锋和弦连接。诸多现代和声著作亦明确指出摇滚乐对五度上行/四度下行的强烈偏好[28]。懂得在5▲与5▼之间抉择，正是驾驭音乐流派血统的决胜分水岭。

形象化记忆指南

5▲与5▼虽共享五度跨度，性格却南辕北辙。在脑海中建立生动联想：“顺势下行如同顺水推舟，自然省力；逆势上扬则如逆水行舟，需要更强烈的动能与桀骜反骨！”

古典理论文献中甚至将连续上演5▼的进行诗意地唤作“五度飞瀑（5th Cascade）”，深信“自上而下如瀑布倾泻方合自然天道”的哲学观念早已深入骨髓[29]。

三度连接（3▲ / 3▼）

相较于前两大家族，三度连接在地位上更偏向于辅佐补充。因为在正三和弦I、IV、V彼此之间，或是副三和弦VIm、IIm、IIIm彼此之间，是绝不可能产生三度连接的。

搭建大调与小调基本框架的核心进行从不涉及三度。因此三度连接最天然的历史使命，正是充当大调和弦与小调和弦之间横渡的立交桥梁（如I⇄VIm、IV⇄IIm、V⇄IIIm）。

在自然和弦体系中，一旦发生三度连接，和弦的大/小品质必然发生彻底翻转！

形象化总结

三度上下行同样可以套用这套直观认知：“下行如同自然滑落顺理成章，上扬则带有异样的飘移反常”。 宏观归纳便是：“二度平稳级进万物皆可，三度五度以下行为天道坦途，上行则各具鲜明先锋脾性”。古典爵士深耕下行坦途，现代流行借力上行反骨——由此，我们在 T、D、S 之外正式解锁了第二套极为强悍的和声透视标尺。

4. 共同音与听觉质感的变化规律

在和弦发生连接时，前后两和弦之间共享的相同音符被称为共同音（Common Tone）。 在自然基础和弦体系中，由几度连接直接决定了共同音的具体数量：

二度：0 个共同音

二度连接是迈向隔壁和弦的动作，内部成员必然全盘大换血：

因此2▲与2▼呈现出迷人的二重性：虽然根音位移极其微小，但在声学色彩上却经历了最彻底的剧烈刷新，极擅长带来丰富多姿的和声“色彩斑斓感”[30]。

五度：1 个共同音

五度连接必定精准保留1个共同音，其余2个音发生更迭：

兼顾了根音大步跨越的动能与两音更迭的新鲜感，是向前强劲推进的主力引擎。

三度：2 个共同音

三度连接是共同音最多的形态，3个音中有2个保持完全不变：

因此三度进行虽然根音位移大于二度，但在全盘宏观听觉上，却往往比全盘大换血的二度显得更为平坦内敛、展开感较弱。若要论及大刀阔斧推动音乐奔腾向前，唯有五度连接能担此重任。

从根音行进的全新维度审视，和弦连接的微观基因展露无遗。发现不同音乐流派竟然对根音运动有着如此深厚的偏好分野，想必令大家耳目一新。 在后续各篇文章中，我们将带大家逐一解锁各大连接家族的实战精髓。

总结

  • 两两和弦连接，以根音位移的物理跨度作为第一基准展开体系分类。
  • 依据根音行进分类，不仅能洞悉声学情绪走向，更能精准把握各大音乐门派的深层审美基因。
  • 根音行进的跨度直接锁定了共同音的数量，共同音的多寡是衡量展开动能的重要参照标尺。
