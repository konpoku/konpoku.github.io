连接系理论 ❺ 五度上行的用法

2026.09.05和弦论
和弦论和弦连接系理论

上一讲我们剖析了五度“下行”连接，本讲我们将探索与之方向相反的五度“上行”（5▲）连接家族。

在其中，唯独 V→IIm 这一进行在传统古典理论中曾被打入禁则冷宫，后文我们将对其做专项专题剖析。

1. 五度上行的声学特征

正如前文所阐述的，五度进行因其根音跨度宏大、构成音发生两音更迭，天然具备孔武有力的强健动能。在此基础上审视5▼与5▲的分野，最根本的差异在于：T、S、D 的功能流转方向是彻底逆转的！

5▼连接顺应 T→S→D→T 的自然正向圆环，而5▲则激荡着 T→D、D→S、S→T 这一充满强烈冲突特质的逆向流动。因此在现代通俗音乐中，各流派对其偏好呈现出鲜明的分化；其中最具代表性的极端矛盾，正是古典体系将 V→IIm 斥为禁忌。

让我们先通过经典和弦进行的实际音频来感受其魅力！

6-3-4-1 进行

6-3-4-1 是一组极富戏剧张力、直击听众灵魂的情绪抒情慢歌（Ballad）王道进行。它与上一讲的“6-2-5-1”或“6-4-5-1”虽然构成相近，但骨子里的情感动线截然不同： “6-2-5-1”系列遵循标准的“起承转合”，高潮爆发点坐落在第3个和弦V级上；而“6-3-4-1”在进入第2个和弦IIIm的瞬间便骤然攀上情绪顶峰，随后在第3、4小节中逐步沉淀、抚平释怀。

在像Aimer的《蝴蝶结（蝶々結び）》或鬼束千寻的《月光》这类节奏舒缓却暗流澎湃的激情慢歌中，该进行的艺术表达力堪称绝配。而在电音《Emoji》的蓄势（Build-up）与爆发（Drop）段落中采用该进行，亦呈现出了罕见的惊艳质感。

（注：《SUNRISE》与《Desperado》在第二段循环中对和弦进行了巧妙置换，并非机械单调的单纯循环。）

由于6-3-4-1本身的情绪烈度极强，在第二遍循环中施加细腻变奏、使其更趋温润是极高明的编配手法：

例如将IIIm置换为V，整段便转化为了连续二度级进的温润平缓连接；若觉得IV→I收尾力道稍显欠缺，将末尾紧凑压缩为“IV—V”，即可瞬间找回 S–D–T 的磅礴着陆冲劲（《月光》与GReeeeN的名曲《奇迹（キセキ）》均运用了该绝技）；若将收尾的I替换为V，原本的“着陆归宿”便瞬间反转为“昂扬悬念”，为全曲带来截然不同的戏剧张力。

6-4-1-5 进行

这是连续两度上演五度上行（5▲）的极富阳刚活力的摇滚王道神级进行——“6-4-1-5”。跨度宏大的根音跳跃带来了无与伦比的开阔动能，在热血澎湃的摇滚乐中具有霸主级的统治力：

与上一讲介绍的王道“6-4-5-1”相比，它仅仅是将末尾的5与1颠倒了位置。然而这一颠倒却引发了翻天覆地的听觉变革：原本V→I刻板的古典属解决彻底瓦解，代之以IV→I的教会式变格终止，激发出纯正脱俗的现代反叛风骨；同时末尾以V级高调收官，为无缝回扣下一循环蓄满了澎湃的推力。

由此可见，5▲不仅能通过 I→V、VIm→IIIm 等 T–D 跃迁掀起情绪的高歌猛进，亦能借助 IV→I、IIm→VIm 等 S–T 转换营造出大度从容的安详归宿。

最后，我们来聚焦五度上行家族中最富争议的成员——V→IIm。

2. V→IIm 的逆向用法

在所有的5▲连接中，唯一被传统和声理论判定为禁则的正是 V→IIm。其被封杀的理由与 V→IV 如出一辙：古典和声信条认为“V级属和弦已是紧张蓄势的最高峰，后续理应顺理成章迈向主功能（T）获得释放，开倒车退回下属功能（S）在逻辑上是极其违和的大逆不道”。

若说 V→IV 与 IIIm→IIm 还只是根音挪动二度的温和逆行，那么 V→IIm 则是根音轰然大跳五度的剧烈逆向激流，在驾驭难度上确实高出一筹。

加之 V→IV 早在布鲁斯与摇滚乐中确立了根深蒂固的法统，而 V→IIm 却缺乏如此久远的门派支撑，直到近年来才在现代另类摇滚与EDM电音中呈现出蓬勃绽放的势头。

然而换个视角来看：这恰恰赋予了它刻画纯正现代先锋审美风尚的无上特权！让我们通过经典作品深入体悟其精髓。

V→IIm 的实战破局神作

将 V→IIm 的戏剧性冲撞发挥得淋漓尽致的全球现象级爆款，当属迪士尼2013年动画巨作《冰雪奇缘》全球主题曲《Let It Go》的前奏！

伊迪娜·门泽尔（Idina Menzel）– 《Let It Go》

我们截取其标志性乐段深入解剖：

在上面重新编配的同名骨架音频中可以清晰听到：这段和弦进行正是将上一讲经典的6-4-5-1王道进行在收尾瞬间实施了惊天调包！它在最后一刻拒绝平稳着陆主和弦，反而悍然掀起了一场 D–S 的强劲逆向狂澜！通过无情剥夺起承转合的圆满收场，将异乎寻常的冷冽危机感与惶恐不安的心境刻画得令人心碎。

正是由于在此处毅然启用了 V→IIm，“女主角艾莎抛弃王冠、仓皇逃入风雪冰封的极北深渊”那份孤独与苍凉才被烘托得直击灵魂。这堪称当代流行音乐敢于踢碎古典陈腐教条、拓展人类艺术维度的丰碑式杰作。

作为对照实验，我们试着将其驯化收口、换回温顺平庸的王道6-4-5-1听听看：

听起来确实顺理成章、合乎规矩了。但这又有什么意义呢？皑皑雪山的凄绝死寂、背井离乡的孤绝悲怆、前途未卜的命运阴霾……所有摄人心魄的艺术神采在这一瞬间被荡涤一空，沦为了一首索然无味的普通口水歌！就“音乐表达是否精准契合艺术立意”而言，这无疑是彻底的艺术败笔。 在传统保守理论看来，V→IIm 确实不够中规中矩；但中规中矩的教条绝不等于艺术的至尊真理。唯有不守常规的先锋进行，才能在最不同凡响的史诗画卷中绽放出无可替代的艺术光芒。

ASIAN KUNG-FU GENERATION – 《Rewrite（リライト）》

在日本摇滚史上，以完全相同的手法运用“6-4-5-2”大获成功的代表作，正是亚细亚功夫世代（AKG）的传世名曲《Rewrite》：

开篇在架子鼓杀入之前，纯电吉他Riff扫出的正是冷冽的6-4-5-2！妙不可言的是：待到鼓声雷动进入全奏后，和弦悄悄回切成了传统的6-4-5-1。在乐团全员尚未集结的前奏蓄力期，通过拒绝解决至I级，制造出一种令人窒息的刀锋紧绷感，将“暴风雨即将来临”的压迫感拉满。 而在整曲尾声3:35处，这组6-4-5-2吉他Riff再次凯旋归来，全曲竟然最终悬停在II级和弦上傲然收尾！在2004年的东方乐坛，这无疑是极具先锋反叛精神的大胆神笔。

乌龟乐队（Ulfuls）– 《万岁（バンザイ）》

我们再看一个跳脱出6-4-5-2格局的生动案例：

该曲副歌的核心进行为：I—V—IIm—IIIm—IV—V。在唱到“好きでよかった（能喜欢上你真是太好了）”的节骨眼上，和声拒绝过早妥协着陆，而是迂回逃逸至IIm，直到下一句高呼“バンザイ（万岁）”时才大快人心地奔向主和弦I。这是一次极其高明的故意推迟解决与曲折迂回。

若依循教条的通俗套路，1-5之后往往理所当然倒向VIm：

哪怕强行套用卡农进行（1-5-6-3-4-1-4-5），主旋律同样能唱得顺嘴；但如此一来，原作中流淌的那股质朴、憨厚、充满泥土芳香的赤诚真情将被瞬间洗刷殆尽。 摇滚乐与电子舞曲之所以由衷钟情于这类反叛连接，正是为了从过于温驯规整的古典陈设中突围，找回音乐最原始野性的生命张力。

世间并无禁则

我们再次重申：在旧式理论书中被冠以“禁则”、“软弱”、“逆行”、“反常”的所有和弦进行，在现代通俗音乐的广阔舞台上，全数可以化作独一无二的艺术锋刃被创作者反客为主！

与众不同从不是罪过，它是艺术个性的鲜明源泉。在你的调色盘上是否解封这些“曾经的禁则”，唯一的决定权只属于你的艺术审美与灵感初衷。

总结

  • 5▲连接跨度宏大，能够对TDS功能实施逆向推演，戏剧张力与宏大动能是其最核心的魅力。
  • V– IIm 在传统学说中属于逆行禁则，但巧妙借用其打破心理预期的“背叛反差感”，能够开拓出常规格局难以企及的深邃艺术意境。
