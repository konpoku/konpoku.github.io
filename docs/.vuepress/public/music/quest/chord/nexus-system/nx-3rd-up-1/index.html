连接系理论 ❼ 三度上行的用法

我们终于迎来了最后一项核心连接系统——三度上行（3▲）连接。

三度上行拥有一种奇妙、略带悬浮飘移的独特悬念感，常被理论家形容为“带来极其柔和轻盈的听觉效果（Soft Effect）”[3]。 在古典和声学中，除 I– IIIm 之外其余三度上行几乎全遭排斥封杀；在爵士理论中亦常被评为“推动力偏弱的进行”。在这类连接中躺着多达3个“曾经的古典禁则”。本讲我们将展开全盘解析。

1. I → IIIm 的连接

首先，I→IIIm 具有极为从容安详的听觉亲和力，在流行歌曲的主歌A段中极高频使用，是三度上行中唯一从古典主义时期便获正名并广泛流传的经典存在[4]。 从声学特质来看，相较于同为 T→D 推进的 I→V，它的根音位移更为内敛，且目标落入小和弦，从而自然流淌出一种淡淡的青涩感伤与哀愁。

The Beatles（披头士）名作《Help!》的主歌开头（“When I was younger so much~”）正是典型的 I→IIIm。那抹轻巧上扬的浮游感正是3▲的灵魂烙印。

在这首偶像歌曲中，副歌与A段开篇双双采用了 I→IIIm。当觉得 I→V 过于明朗阳光、冲劲过猛，难以传递出“初恋的青涩揪心”时，该进行是最理想的替代良方。

这种恰到好处的幽微感伤在K-Pop中同样备受青睐。韩国多国籍女子天团TWICE的单曲中，A段与副歌的开篇同样由 I→IIIm 领航。这种“克制内敛的微苦忧伤”是IIIm独有的情绪魅力，与流行歌曲的相性堪称天作之合。若施加品质改变升级为大和弦III，味道同样极为醇厚。

2. IV → VIm 的连接

IV→VIm 虽然在传统J-Pop中相对少见，但在EDM电音、Techno以及现代R&B中却是极为普遍的常规武器。尤其是电子音乐天然具有充当派对BGM的属性，若和弦进行过于大开大阖、情感宣泄过浓，反而显得聒噪抢戏；此时共同音充沛、行进平稳克制的三度上行便可大放异彩。 例如“IV—VIm—V—V”这一进行，在EDM领域便频繁露面：

我们可以将其形象地理解为：从经典的 IV—V—VIm 王道链条中刻意将中途的V抽离，从而有力平抑了过度喧嚣的情绪亢奋。

在很多高级编曲中，直白的4-5-6难免显得过于通俗煽情。而4-6-5这种“率先轻盈滑落着陆于VIm、随后将V级作为悠长余韵自然流淌”的收敛感，反而散发出成熟高级的克制之美。当渴望表达内敛从容的都市质感或欲哭无泪的幽微神态时，3▲往往更为契合。

在这些曲目中运用了“4-6-2-1”进行。在传统流行曲中极其罕见，用它来营造干练、时髦且充满律动的Funk格调堪称神来之笔。整段完全摒弃了属和弦V，也是赋予其淡雅冷静听感的核心关键。 宇多田光的歌曲时而极具纯正J-Pop底色、时而又充满纯正欧美风韵，造成这种分化的核心深层推手之一正是和弦连接模式的取舍差异。在其充满前卫国际质感的曲目中，便大量交织着这类打破传统东方教条的先锋连接。

在自赏摇滚（Shoegaze）、另类摇滚（Alternative）及嘻哈音乐中，甚至不乏仅凭IV与VIm两个和弦来回荡漾支撑起整整一个大乐段的优秀范例：

驱动音乐向前发展的绝不仅仅只有和弦。节奏律动的骨架、音色质感的起伏均是强大的引擎。在很多艺术语境中，波澜不惊、低抑扬顿挫的和弦织体恰恰拥有最不可替代的统治力。 更重要的是：正因为在古典与爵士中罕见，它们听起来才格外具有颠覆性的当代新鲜感！ 传统乐理书上没有记载，绝不代表它们是错误的畸形产物，那只是代表着一个全新的音乐纪元正在我们眼前破土而出。

3. “曾经的禁则”的共有特质

接下来我们审视被古典列入禁则的剩下3种连接。它们背后蕴含着一个极其显著的共同特征：TDS功能在跃迁中完全没有发生改变！

在原本就共同音充沛、平缓平稳的三度上行中，这三位成员更是在功能属性上原地踏步。 然而，变化幅度小绝不等于劣质！昔日被打入冷宫，无非是源于古人刻板固化的审美教条。正因如此，迈入21世纪以来，这些前沿进行在新锐音乐人手中呈现出井喷之势，赢得了无数年轻世代的狂热拥趸。让我们结合真实案例逐一拆解。

4. VIm → I 的连接

VIm→I 与经典的 I→VIm 类似，属于主功能（T）内部平稳游移的舒缓走向。然而由于首发由VIm小调和弦领跑，整体更偏向暗黑色调，相较于纯通俗流行曲，在摇滚与现代电音中更具话语权。

上面精选的这些经典作品，极为契合地全盘摒弃了传统属和弦，纯粹凭借3▲连接构筑起整曲骨干。VIm→I 的连接极其旗帜鲜明地展示了**“由暗转明”的心理蜕变**，对于抒发绝处逢生、拨云见日的昂扬积极意境堪称绝配（Perfume的名作《STAR TRAIN》便是这一特质的完美绽放）。 而在像《Sexy Bitch》或《RGTO》这类硬核电子作品中，它在维持大调与小调引力平衡、防止全曲过度倒向单一情绪上发挥着卓越的制衡作用。

6-1-5-4 范式

若将属和弦V引入循环，由此衍生的“6-1-5-4 进行”在当代欧美主流流行乐（尤其是舞曲领域）中早已成为横扫一切的霸榜招牌：

极其有趣的是：该进行同时触犯了“VIm→I”与“V→IV”两个古典禁则！在现代欧美流行乐坛，昔日的陈规戒律不仅被彻底撕碎，更蜕变为了不可或缺的流行日常。

在此类进行中，VIm→I 扮演着大调与小调之间精准的避震平衡木。开篇以略显深沉的VIm蓄力起步，但创作者并不希望整曲沉沦在压抑的阴霾中，而能够瞬间驱散阴郁迷雾的最强大存在，正是大调王牌中心音——主和弦I！ 此外，将其中的IV替换为同属下属功能的IIm，便衍生出了“6-1-5-2 进行”：

V→IIm 是一记动能极其霸道的长距离跨越，且1-5-2连接中连续上演了两次五度上行（5▲），属于名副其实直冲云霄的“情绪狂飙推进”。在某些曲目中甚至将IIm施加品质改变换成明艳的大和弦II级。当既渴望低音大跨度奔腾、又厌弃小调的萎靡压抑时，这无疑是杀伤力拉满的神级选择。 传统爵士推崇五度下行主导的“2-5-1-6”，而现代舞曲的“6-1-5-2”在骨架上恰恰将爵士路线彻底反向逆转！这再次生动证明：流派一换，真理与常识立刻天翻地覆。

5. IIm → IV 的连接

IIm→IV 则是以“连续沉浸在下属功能（S）”为核心魅力的温婉连接。在自然和弦体系中，IIm通常扮演着“蓄力跳板”的职责，最直白的经典展开是顺理成章跃向V级以掀起高潮（古典理论亦严苛限定了这唯一的合法通道）。 然而，若出其不意地顺势倒向下属大和弦IV，音乐性格骤然为之一新：2个共同音、TDS功能零切换、在波澜不惊的静止池水中，唯独经历了一次从小三和弦向大三和弦的悄然明暗翻转！ 相较于 IIm→V 那种直白外露的慷慨激昂，IIm→IV 流淌出的是一种极为含蓄内敛、在静默角落悄然绽放希望的幽微美感。

2-4-6- 范式

Daft Punk在第56届格莱美狂揽5项大奖的神作《Get Lucky》，全曲贯彻着“IIm—IV—VIm—V”这一接连挥洒3▲连接的标志性格局。不屑于喧嚣浮夸的张扬，勾勒出一抹极具高雅格调的成熟复古舞曲神韵。

AKLO与JAY'ED合作的《Different Man》同样以 IIm—IV—VIm—V 作为底层循环。充满冷冽舒适（Chill）的慢摇迪斯科氛围，与3▲那柔美轻灵的克制质感达到了水乳交融的契合。

日本新生代歌姬Ado现象级爆款《新时代》，副歌核心循环同样是惊世骇俗的“IIm—IV—VIm”。在VIm处长久悬留，全曲拒绝使用任何属和弦V。在最为高潮的副歌中彻底封印传统属和弦，这副名副其实昭示着“新时代”降临的破局框架，与作品立意浑然天成。

2-4-1- 范式

Coldplay的名作《Paradise（乐园）》正如歌名所示，描绘着“逃避残酷现实、遁入虚幻遐想乐园”的心灵自白。配合这一极具空灵梦幻色彩的主题，全曲展开了“IIm—IV—I—V”的大胆循环：

在整段进程中，它彻底摒弃了一切能够构筑稳固终止感的传统连接（2▲、2▼、3▼、5▼），在幽闭克制的 IIm→IV 之后紧接着两次五度上行（5▲）的空灵大跳，勾勒出极富异质感的梦幻回路。正是这种“摒弃现实前行、选择遁世漂浮”的和弦运动，与歌曲的超脱主题达成了神级互文！若强行逆转为爵士标准的2-5-1-4，作品那抹令人心碎的虚幻美感将被瞬间涤荡殆尽。 在2010年代以后的欧美主流乐坛中，从Eminem、Taylor Swift到Katy Perry，均能频繁捕捉到2-4-1-5那独特的灵动身影：

6. IIIm → V 的连接

最后剩下的 IIIm→V 因个性极其鲜明，使用频次相对较窄，却具备无可替代的独特趣味。 IIIm在自然调式中本就属于暧昧摇摆的半被动和弦，此时猝不及防地猛然杀向果决刚健的属和弦V，整段声响犹如从犹疑抽泣瞬间蜕变为斩钉截铁的坚定宣誓。

在这首纽约独立流行乐队的佳作中，主歌A段正是采用了“VIm—IV—IIIm—V”进行，从朦胧踟蹰的IIIm跨入昂扬挺拔的V级之质感展现得淋漓尽致。

在英国传奇摇滚乐队Radiohead（电台司令）的殿堂级名作《Karma Police》中，从主歌过渡到副歌的连接处轻巧使用了 IIIm→V；而在2:35处的桥段乐段，更是以极其罕见的“IIIm→V→I”开篇破局。 在“I lost myself（我迷失了自己）”的迷惘吟唱中，朦胧混沌的失序感被推向高潮。IIIm向V的行进动作虽然反常规，却与此等迷离神性实现了至臻契合。

每一个和弦进行，都有其不可替代的灵魂意义

至此，30种全套和弦连接系统宣告全部梳理完毕！世间绝无所谓的“禁则”，有的只是通过挑选不同的连接系统，自由定义属于你的音乐流派、时代烙印与艺术风骨！将这些鲜活的现代实践贬斥为违规冷门的教条理论，不过是画地为牢的保守主义罢了：

若音乐世界真存在唯一的“正确性”标尺，那唯有你的音乐表达是否与你内心深处渴望倾诉的情感内核达成了最深层的共鸣。理论永远只是用来辅佐你做出智慧抉择的指南针。

总结

  • 三度上行（3▲）与三度下行互为镜像，具有轻盈悬浮的上浮感，虽牺牲了一部分绝对稳定，却赋予音乐极大的柔和与空灵（Soft Effect）。
  • 舞曲电音偏爱 IV-VIm，流行声乐偏爱 I-IIIm；其中 I-IIIm 从古典时代起便享有正统地位。
  • IIm→IV、VIm→I、IIIm→V 这三位昔日禁则在传统西方和声中极少露面；但在21世纪的摇滚与现代流行音乐中，它们作为打破常规陈套的先锋语汇正散发出无可比拟的光芒。
