1. 什么是复合和弦

复合和弦（Polychord）顾名思义，是在和弦之上再叠置和弦的技法。可以说它是斜线和弦的进化形态。 以往的斜线和弦只不过是“贝斯弹奏根音以外的单音”，而复合和弦则是真真正正地在和弦上再弹奏一个和弦。

为了与斜线和弦区分，它不像斜线和弦那样使用倾斜的斜杠（/），而是用水平横线分隔上下两个和弦标记。因此即便是复合和弦，也是以一上一下划分音区进行叠置为前提的；而在完全相同的音高音区同时弹奏两个不同的和弦，则是更加高难度且疯狂的操作。本文介绍的同样仅限于在上下音区切分开的模式。

复合和弦在大众音乐中极少出现，主要用于爵士乐、前卫摇滚（Prog Rock）、20世纪古典现代音乐以及电影配乐等领域。我们来看看如何让同时鸣响两个和弦这一行为成立。

2. 引伸音和弦的分解

从简单的思路入手，堆叠了大量引伸音的和弦，其实质已经拥有了相当于两个和弦的音数。

如果将其一分为二，不就变成了“和弦上叠置和弦（Chord-on-chord）”的状态了吗！

像这样，一直堆叠至 13th 的七和弦可以分割为四和弦＋三和弦。上下的和弦分别称为上部结构（Upper Structure）与下部结构（Lower Structure）。这倒不是什么高深术语，英文原意就是指“上方结构”与“下方结构”。

典型的做法是用下部结构确保 3rd 与 7th 构筑和弦的骨架根基，上部结构则使用三和弦，或者与下部结构共用一个音也构成七和弦。这样沿着平时认知的延长线，就能轻松制造出复合和弦。

与引伸音和弦的区别

但如果只是普通地弹出来，它与引伸音和弦又有何区别呢？关键在于：必须在演奏中通过编曲构思，让上部与下部在听觉上明确分离开来。

例如让上部结构与下部结构由不同的乐器分别演奏，或者由钢琴的左右手分别负责；在更微观的层面上，编写乐句时在时间先后上错开演奏上部与下部等等。

这是将 2-5-1 上下切分的原始复合和弦实现方式：贝斯与电钢琴左手负责下部结构，电钢琴右手负责上部结构。通过这种方式，上部的三和弦完全由原本的 9th、11th、13th 构成，对比两者的根音，像 Em/Dm7 那样，上部和弦的根音均高出。

由于上部仅弹奏相当于原和弦引伸音的部分，虽然与下部保持着隐约的联系，却呈现出一种轻盈浮起般的漂浮感。

上部是否包含避免音

理论书中基本会告诫：“如果从整体引伸音和弦的角度看属于避免音（Avoid note），把这种音放进上部结构当然会浑浊，所以不行”。然而由于上下声部分离的存在，实际上哪怕上部结构中坐落着避免音，也完全可能成立。

在上面的示例中，V7 上出现了通常被告诫“不可添加”的 C 音。左手弹 B、右手弹 C 表面上看非常危险（OUT），但实际音响听起来完全可以接受。这正是声部具有强烈分裂感的复合和弦才能做到的事。

另一方面，在 IΔ7 时上部结构包含 F 音由于其强倾性音的特质依然不建议使用，因此上例中将其改为 F♯ 以回避浑浊。

上部结构三和弦（UST）

由于上部结构构建怎样的三和弦是核心关键，这类技法本身常被统称为上部结构三和弦（Upper Structure Triad, UST）。

原本“上部结构三和弦”指的是将引伸音和弦拆分成复合和弦时位于上方的三和弦，但在实践中也常被直接当作动词或手法来使用，如“UST 的用法”、“把这里的属和弦换成 UST”等等。

变体模式

在小七和弦与大七和弦中，由于引伸音的选择空间并不多，能制作的 UST 模式也相对有限。而当面对**属七和弦（Dominant 7th）**时，可能性呈几何级数拓展。因为传统和弦理论允许在属七和弦上运用极其丰富的引伸音，所以 UST 的组合变体非常广泛。

3. 迈出常识之外

不过，“分解引伸音和弦”只是复合和弦制作方法的一种，绝非仅此而已。而且“只允许在属七和弦上施展”也只是爵士理论的一种框架，实际上完全可以把下部结构设计为属七以外的和弦，同时让上部结构更加激进。

虽然在等音改写后看起来可能稍微规整一些，但如果缺乏复合和弦的构想，是绝对难以诞生这种音响的。对于只听流行歌曲的人来说可能难以接受，但在20世纪的近现代古典音乐中，遭遇这种程度的和弦屡见不鲜。

构建复合和弦的诀窍

从总和来看复合和弦具有极强的浑浊度，但关键在于：只要在上下声部之间营造出足够的独立与分离感，听觉对浑浊的排斥感就会大大减轻。

要让复合和弦听起来不是一团糟乱而是具有有机性，最好让上部结构与下部结构各自拥有独立的叙事线条，通过确保横向线条的连贯性，促使上下声部分离。

仅上方声部

仅下方声部

在绝大多数位置上，上方下行时下方上行，赋予线条走向对称性。这样做的意图在于尽量不让上方与下方融合成模糊的一团，促使听者能清晰辨识出两条平行的线条。

此外，将最高音限定在 f、e♭、b♭、a♭ 这 4 个音以保持某种调式感，为下方和弦保留些许流行的进行逻辑，并用耳朵细致微调上下结构的咬合度。

虽然通过换名改写并非不能将其勉强记录为单个和弦，但这种“事后解释”并不重要。复合和弦的最大意义在于作为创作者的实战工具，能够凭借这种思路极其简便地生成常规思维难以产生的奇妙和弦。

切换理论系统

上述例子在第IV章介绍的常规引伸音/避免音理论看来近乎离经叛道，你可能会想“上下声部用不同的音阶到底是在搞什么”。但此时，引言中关于流派的探讨再次显现出意义：任何理论，都不过是针对特定音乐范围所构建的基础框架而已。

由极度浑浊的声音构成的音乐，绝非“错误的音乐”或“胡来的音乐”，它仅仅是“脱离了大众通俗的手法与框架”。创作者随时拥有跳出常规框架自由探索的权利。 固然在创作流行金曲时这种激进技法并不合适，但上面展示的“含蓄克制的复合和弦”，在流行音乐中显然大有用武之地。

掌握的理论越多，往往越难将这些装备“卸下”。因为脑海中装满了现成的知识抽屉，难免会形成总在抽屉内部寻觅的惯性。请永远牢记：在理论所能捕获的范围之外，始终延展着辽阔无垠的自由天空。

总结

  • 在和弦之上再叠置和弦的技法称为“复合和弦（Polychord）”。
  • 通过拆分引伸音和弦，可以简便地制作复合和弦。
  • 刻意叠置无法归纳为单一和弦的组合，能够创造出非同凡响的独特音响。
