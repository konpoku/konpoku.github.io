音簇（Tone Cluster）

和弦论现代和声结构、四度叠置与复合和弦

目录

在第IV章中我们掌握了形形色色的和声技法，而从这里开始，我们将向着更深邃的领域进发。第V章的内容主要施展于爵士乐、前卫摇滚（Prog Rock）、游戏音乐、电影配乐等领域，在普通大众流行乐中的使用场景相对较为有限。

1. 什么是音簇

首先我们要介绍的是名为**音簇（Tone Cluster）**的技法。音簇是指以差、差或更小的微音程密集铺满音符的技法的总称。百闻不如一见，让我们先来观看实际的演奏。

这是作曲家泽纳基斯（Xenakis）的作品。管弦乐队的各乐器以极度密集的音高进行演奏，音符凝聚成巨大的声块铺天盖地般席卷而来。这正是典型的音簇。某种意义上，音簇是一次试图抹平由乐器奏出的乐音与类似电视雪花白噪声之间界限的大胆探索。

这是现代音乐家施托克豪森（Stockhausen）的作品。虽然是一首钢琴独奏曲……但演奏者竟然用整条前臂重重砸在琴键上！这仿佛在带着现代艺术特有的尖锐质问固有观念：“你从什么时候开始认定钢琴只能用指尖去弹奏的——？”此外，全曲整体上也随处可见用半音密集堆砌挤压出的破碎撕裂音响。

这一首是现代音乐大师利盖蒂（Ligeti）的作品。这是一首从头至尾几乎完全由音簇构筑而成的作品。然而当音簇被推至这种极致，听者感受到的已不再仅仅是“浑浊”，而是超越浑浊彼岸所散发出的神圣与深邃……

此前我们在“引伸音和弦”中体会过浑浊能够带来色彩，而音簇可以说是这一逻辑的终极形态。它是一项主要活跃于20世纪之后近现代先锋音乐中的技法。

2. 音簇声部配置（Cluster Voicing）

话虽如此，纯粹的音簇毕竟过于激进，很难直接引入流行音乐之中。最具代表性的流行乐名例，大概也只有披头士乐队的《A Day In The Life》了吧。

因此，一种与此类似但具备更强实用性与通用性的构想便是音簇声部配置（Cluster Voicing）。 “声部配置（Voicing）”是指和弦构成音如何具体排列分布。在常规和弦的“排列分布”中融入音簇元素，便构成了音簇声部配置。

这是尚未加入音簇的原始音频。和声走向固然优美规整，但若想营造雄浑庄严、令人窒息的宏大气场，总觉得略显单薄。此时，音簇配置登场了！

原本甜美平整的和声被剥离，取而代之的是弥漫开来的非比寻常的肃杀之气。散发着宛如来自深渊呼号一般的狰狞魔性。尤其是最后一个和弦带有着相当激烈的浑浊，极大强化了恐怖与悬疑的气氛。在钢琴卷帘（Piano roll）中确认其音符排列如下：

关于填充音符的间距：如果全音较多，不协和度尚在可控范围内；反之，半音间隔越多，氛围就越发阴森诡异。这里与引伸音和弦的知识深度交织——若达到传统和弦理论绝对禁止的“同时鸣响 -9th 与 9th、11th 与 ♯11th”，或者“同时鸣响小七度与大七度”，音响将极尽凶残狰狞。从这个角度来看，上面的谱例还算是相当克制温和的级别。

最重要的是：正因为我们脚踏实地掌握了“常规的乐理与声音”，如今才能如此坦荡自信地施展这般反常规的操作。如果缺乏理论武装，创作者很难凭空想到将音符如此紧密地挤压堆砌在一起。音簇正是“因懂得理论而获得更大自由”的生动例证。

总结

  • 将音符以半音差或全音差密集堆叠的和弦，称为“音簇（Tone Cluster）”。
  • 在和弦声部配置中局部采用音簇排列的手法，称为“音簇排列（Cluster Voicing）”。
  • 音簇配置最适合用于渲染庄严宏大、阴森压抑或非同寻常的肃穆氛围。
