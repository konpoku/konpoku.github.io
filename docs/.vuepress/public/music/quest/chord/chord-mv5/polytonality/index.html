多调性与多调式

2026.09.05和弦论
和弦论现代和声结构、四度叠置与复合和弦

1. 什么是多调性

在“复合和弦”中，我们似乎已经大幅解除了音乐的各种限制，而其最终的延伸方向之一，便是多调性（Polytonality）。多调性是指在一首乐曲中让两个或两个以上的调同时并行共存的手法。当同时存在的调为两个时，也称为双调性（Bitonality）。百闻不如一听，让我们先来聆听一段音乐。

这是20世纪近代古典音乐作曲家巴托克的钢琴小品集《小宇宙（Mikrokosmos）》中的一首。这是一首大约1分30秒的短曲，观察开头会发现：左手完全只弹白键，右手完全只弹黑键，两手的调性完全不一致！(・-・´) 即便单独审视各个声部，其调性感也是模糊的，但大致可以说：仅用白键的左手属于 C 大调范畴，仅用黑键的右手则属于 F♯ 大调范畴。在上正好处于正对面、相隔三的两个调同时鸣响。这样的乐曲便被称为具有“多调性（Polytonal）”。

初次聆听可能会让人感到吃惊错愕，但随着听觉适应，人们会逐渐被这个不可思议的声音世界所深深吸引。正如序论中所述，20世纪古典音乐打破了既有框架进行了形形色色的先锋尝试，多调性正是其中极具代表性的一种。

这样一看，在 a、b、c、d、e、f、g 所有音级上，总有某个乐器声部带有升号或降号，整体始终处于音符碰撞的潜在风险之中。重温乐谱，在第 5 小节双簧管切入时，还原的 e 音与降号的 e 音发生了一瞬间的碰撞。但由于双簧管的 e♭ 音并未拉长，这或许是有意不让冲突过于直白外露，而是作为一瞬间的异样感来“惊鸿一瞥”。此外在第 8 小节中提琴加入时，长笛演奏 a 音，双簧管演奏 g 音，各自选取了能够保持本位还原的音级，以免干扰中提琴的登场。

因此这部作品与巴托克那种粗暴享受音符正面硬碰的类型略有不同，它更像是在享受让本应不协和的三个调性在悬崖边缘惊险共存的悬疑与刺激。

仅从这两首作品就足以看出，借助多调性这一构想，我们能够发掘传统调性音乐中无法企及的惊险音响，其间蕴藏着巨大的艺术潜力。

2. 基于同主音调的双调性

像上面的例子那样将截然不同的调相互咬合需要极为严密的工程设计，但也有相对能够轻松尝试的模式。其中之一就是：将拥有相同主音的同主音（Parallel）关系的调结合在一起。主音相同意味着：哪些音是奇数度、哪些音是偶数度、各音的功能逻辑等在很大程度上是通用的。因此在把握整体宏观结构的同时进行编曲装配会容易得多。需要关心的仅仅是相冲突的音级究竟如何碰撞。

这里调换了大小调性质，和弦进行变为了 Cm7 → B♭m7。 现在，让我们将这两者同时播放！C 大调与 C 小调，当它们交融在一起时会发生什么呢？

尽管做了如此荒诞出格的操作，听起来却仅仅止步于“略带诡异”的克制程度。甚至莫名散发着一种令人不由自主深陷其中的迷人“剧毒”！独特的不协和感起初可能让人感到压力，但一旦习惯，这种闻所未闻的奇异声响便会显露出独特的魅力。

在大调与自然小调之间，相互竞争的是 iii、vi、vii 度的音级。通过控制它们的碰撞程度，便能随心调配“毒性”的强弱。在本次示例中，为了不让决定和弦性质的核心要素 3rd 与 7th 发生正面直击冲突，在时间先后上错开了弹奏时机。不过由于加入了延迟效果（Delay），部分位置听起来像小大七和弦（mΔ7），或者某些地方 3rd 与 7th 的残响交织碰撞，形成了那份独特的幽暗怪诞之美。

仅仅是纯粹的大调与小调，简单叠加在一起便能营造出丝毫不逊于变化属和弦的神秘氛围。像这样，双调性只要构思巧妙，便是一项蕴含着打破既有和弦壁垒无限潜力的强大技法。

3. 基于同音阶关系的双调性

这是指在共享同一套音阶材料的平行（同音阶）关系音阶之间构筑复调性。

这两首钢琴短曲，上方为 D 多利亚调式（D Dorian），下方为 A 小调（A Minor）。这两者的主音中心（Tonal Center）不同，但音阶本身的构成音完全一致。现在把这两者合为一体，制作成一首多调性乐曲！

效果就是这样。由于音阶层面不产生剧烈的不协和，整体作为一首乐曲相当自然协调地融合在了一起。当然，相应地其戏剧性冲突也没有那么强烈。不过它宛如视错觉画一般：侧耳倾听左声道会感受到 D 多利亚调式的韵味，侧耳倾听右声道则会感受到 A 小调的色彩，趣味盎然。这类似于所谓的“鸡尾酒会效应”，在专注于一侧的同时，另一侧的信息就会作为背景悄然流淌。这正是因为两者的音阶构成音完全一致才会产生的现象。

多调式（Polymodality）

“调”这个概念属于西洋音乐理论体系，说到调通常指大调或小调。一般很少有人说“多利亚调”吧，通常会说“多利亚调式的乐曲”，称其为“旋法/调式（Mode）”。正因如此，在这类具有调式特征的音乐中，有时不称其为“多调性”，而是称作多调式（Polymodality）。

不过，“调性音乐”与“调式音乐”本身就很难划定泾渭分明的界限，“调性”一词在广义与狭义上也存在理解偏差，因此这两种称谓之间难免保留着某种模糊性。比如开头巴托克的例子，开篇“G-C-F-A-D-E”这一乐句究竟能否被明确界定为 C 大调本就十分微妙，若将其称为多调式也完全讲得通。在过于死板的学究定义上纠缠并无太大意义，大家根据语境与个人喜好灵活选用即可。

4. 流行音乐与多调式

上面举了多利亚调式的例子，以此类推，如果将弗里吉亚（Phrygian）、混合利底亚（Mixolydian）甚至民族特色音阶都纳入视野，组合方案可谓数不胜数。

特别是同主音关系下的多调式，在近年来的商业流行音乐中用例意外地逐渐增多，这里也为大家做一番引介。

在 XG 的《GRL GVNG》中，开头的配器乐句以 B♭ 弗里吉亚调式展开，而随后切入的人声歌唱部分则采用了 B♭ 自然小调。伴奏部分给 c 音加上了降号（C♭），但人声旋律却结结实实地唱出了 c♮，形成了极为直接的正面冲突。

弗里吉亚调式特有的沉重黑暗压迫感，搭配通俗亲切的小调旋律，两者兼收并蓄，最终自然催生出了一首多调式作品。这种自如随性的制作构思清晰可见。

请关注 BLACKPINK 的《Pink Venom》在 0:34 起的 B 段部分。伴奏乐句采用了将 E 弗里吉亚的第 3 音大调化后的中东风音阶（弗里吉亚属调式/Phrygian Dominant），而与此同时人声歌唱旋律却按部就班地使用着标准的 E 大调音阶。

这也是让伴奏承担中东风情异域色彩的表达，而主旋律依然保持传统流行洗脑抓耳构思的结果，最终导致了两种音阶的共存。尤其在这种案例中，主音色乐句是单音线条，歌唱旋律也是单音线条横向行进，音级的直面冲突并不刺耳。某种意义上，这与前文看到的霍尔斯特三重奏手法异曲同工。

自巴托克等先驱的探索至今已过去约100年。虽然形式相对精简初级，但多调式音乐就这样悄然无声地开始渗透进主流商业音乐中，这无疑是一种极为有趣的现象。

复合和弦因为是和弦之上叠置和弦，不可避免地会形成 6 音或 7 音的厚重声响。相比之下，多调性与多调式根据音数的多寡可以呈现出非常精简通透的质感，而且还可以自由决定是否让音符发生冲突，在应用场景上展现出了极广的适应度，完全可以写得非常抓耳流行。大家不妨从在歌曲的细微片段中悄悄让两条音阶发生交织碰撞开始尝试。

总结

  • 多个调同时存在的状态称为“多调性（Polytonality）”。
  • 通过决定让冲突的构成音正面碰撞还是巧妙规避，可以自由把控不协和感的程度。
  • 在同主音关系的多个音阶之间叠加旋律的手法极易成立，在现代流行音乐中也屡见不鲜。
