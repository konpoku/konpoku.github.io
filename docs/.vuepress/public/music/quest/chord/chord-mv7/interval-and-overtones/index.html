音程与泛音列

1. 走入古典理论的世界

那么，从这里开始我们将正式步入古典派理论的核心正题。在传统的古典和声著作中，开篇通常会极其详尽地讲解“音程度数”。在深入学习和声学时，深刻理解和声音响的物理与心理原理至关重要。 在此我们遵从这一传统惯例，首先对音程展开透彻探讨。从基础的复习起步，进而切入此前未曾深入剖析的科学声学维度。

2. 音程度数与听觉质感

此前我们在和弦篇与旋律篇中，虽然已经探讨过渡数与音响质感之间的关联，但在此我们不妨重新梳理确认：

  • 1度（纯一度）：不言而喻，与根音完全协和融为一体。
  • 3度：主宰和弦大、小性质（明暗色彩）的关键度数。
  • 5度（纯五度）：与根音高度协和，强化并支撑根音的骨架音响。
  • 7度：相对于根音产生恰到好处的色彩浑浊与倾向张力。
  • 2度：与根音发生剧烈碰撞，产生强烈的不协和感。
  • 4度（纯四度）：与5度同属构成“完程（纯音程）”的度数，但其协和稳定性不如5度。
  • 6度：与3度类似，是深刻影响大小调明暗属性的度数。

这些概念在调性引力论的“外壳（）”章节中也曾稍微亮相过。当然，此外还存在“增、减”音程，在此暂且按下不表。

和声音程的转位

虽然是老生常谈的常识确认：将3度音程颠倒倒置（转位）就会变成6度，4度颠倒会变成5度，2度颠倒则会变成7度。同时还存在着大音程与小音程属性必然相互对调的固有法则。

而完全音程（纯音程）在颠倒转位之后，依然保持为完全音程。 如果说“颠倒”有些抽象，换成“将其中一个音向上或向下移动一个八度”，或许会更加直观。例如将“上方三度和音”向下移动一个八度，就可以转换为“下方六度和音”。

因此在音程之间，存在着清晰的“度数配对映射关系”：

  • 充当色彩描绘角色的 3度 与 6度
  • 充当骨架强化角色的 4度 与 5度
  • 充当摩擦浑浊角色的 2度 与 7度

虽然这是我们第一次明确将其整理成公式，但想必许多人此前在直觉上就已经隐隐有所体会了吧？像这样把音符的高低上下关系颠倒的行为，在音乐学中被称为转位（Inversion）。

运用能够赋予大小调明暗性格的3度与6度来叠加声部，能够极大地丰富乐曲的声音色彩。在歌曲副歌的人声和音中3度叠置之所以最受欢迎，正是因为它可以为听众的耳朵带来格外明媚生动的旋律色彩。

反之，5度虽然缺乏明暗色彩的倾向，但它拥有强化声音力量感与刚性支撑的作用——这一点大家在摇滚乐“强力和弦”的运用中想必已经深有体会。

在《新和声》一书中，将3度形容为“柔和的音响”，将纯5度形容为“硬质的音响”。请务必铭记这种声音的柔软与坚硬、以及声音的色彩饱和度的触感。在更严谨的声部写作与和声织体构建中，这种辨析力将发挥决定性的作用。

话虽如此，仅仅用“柔软”或“坚硬”这种感性词汇一笔带过，难免让人觉得不够过瘾，缺乏理性的说服力。我们更渴望获得严谨的科学剖析。因此，虽然稍微偏离一点纯理论的主线，在此我们不妨稍稍涉足一下音响学（Acoustics）的殿堂。

3. 频率与音高

声音，本质上是空气的机械振动。而音高的高低，取决于该振动的速率（即振动频率）——这一点大家在中学物理课上应该都已经学过。

这是频率为 220Hz 的纯音。自然界中有着形形色色丰富多彩的声音，而这里鸣响的是宇宙中最单纯朴素的声波——“正弦波（Sine Wave）”。

由于这种呈现出平滑波纹形态的波形可以通过三角函数 $\sin(x)$ 来精确描述，因而被称为正弦波。

220赫兹，意味着空气在每秒钟之内发生220次往复振动。在音高命名体系中，220Hz 对应的是“La”音，国际上通常将这个特定的音高音区标记为“A3”。而且大家在物理课上应该也接触过一条铁律：当振动频率翻倍时，音高恰好会升高一个纯八度、达到高八度的A。

这就是 440Hz 的声音，在数字标记上增加了一级，被称为“A4”。那么，如果将初始频率放大到3倍，会发生什么呢？难道又会变成更高八度的A吗？

这就是3倍频率的 660Hz——它鸣响的居然是“E4”！不是A，而是变成了E音。仔细一想这也完全理所当然：既然“频率每翻一番（2倍）才升高一个八度”，那么要想鸣响 440Hz 的高八度音，就必须将其乘以2，即达到 880Hz。

这就是 880Hz，即“A5”[1]。那么接下来的悬念就是：如果将 220Hz 乘以5倍，达到 1100Hz 的声音，又会对应哪个音呢？

这又是一个全新的独立音高——它是 C♯（升C）！也就是“C♯5”。将迄今为止的声学实验汇总如下表：

频率 倍率 音高
220Hz ×1 A3
440Hz ×2 A4
660Hz ×3 E4
880Hz ×4 A5
1100Hz ×5 C♯5

科学声学实验到此告一段落。我们试图通过这组实验确证的核心真理究竟是什么？ 正是这一点：将基准频率倍增向上延伸时，在八度之外最先破土而出的全新音高，正是从基准音算起的“纯五度”音程！ 物理学公认一条听觉声学规律：频率整数比率越简单，当它们叠置构成和弦时，人耳在心理听觉上感知到的融合度与单纯明朗感也就越极致。

我们再次聆听这段将 220Hz、440Hz、660Hz 同时鸣响的和弦。正弦波彼此之间高度融合，甚至可能会被错听为一个单一的声音，但仔细辨听就会发现，其中确实同时鸣响着多个纯粹的物理音高。 用更通俗直观的话来表述：这就是低音、其高八度音、以及再往上的纯五度音的组合。

不言而喻，这完全就是摇滚乐中的“强力和弦模型”，散发着极其质朴刚健的原始冲力。脱胎于这种物理频率的内在简单性，人们用略带诗意的语言将其称之为“硬质的音响”。 紧随纯五度之后跃然而出的全新度数，正是“大三度”。而由这三个音（根音、纯五度、大三度）凝聚而成的实体，正是大三和弦！

其振动频率的比率为极其精炼的 4:5:6。这是人类用三度叠置构筑三和弦所能达到的最简洁优美的整数频率比！ 沿着这一物理轨迹继续延伸——6倍、7倍、8倍……具有浑浊摩擦与强烈倾向张力的七度与九度音程才会依次显现。归根结底，“硬质”与“柔和”的字眼虽带有主观审美色彩，但这种数理比例的单纯与复杂，构成了所有和声音响美学颠扑不破的底层物理逻辑。

4. 泛音与泛音列

像这样，以某个频率为基准，把该频率乘以整数倍所得到的更高音，就被称为“泛音（Overtone）”。其中把频率乘以2倍的那个叫“第2泛音”，乘以3倍的叫“第3泛音”，依此类推。

而那个被反复倍增的原始频率本身，则被称为基音（Fundamental）。

频率倍率音高名称
220Hz×1A3基音
440Hz×2A4第2泛音
660Hz×3E4第3泛音
880Hz×4A5第4泛音
1110Hz×5C♯5第5泛音

而这些“泛音”按顺序一字排开所组成的序列，就称为泛音列（Overtone Series）。

以 C 为基音、一直排列到第21泛音的乐谱（与十二平均律频率误差较大的音用实心黑音符标出）

可以说，这个“泛音列”是科学地思考音乐时极为重要的一把钥匙，同时也是唯一的依据所在。

留意误差

不过需要提醒你注意一点：对绝大多数音而言，实际出现的音高都带有误差。例如把 440Hz（A 音）乘以7倍，得到的是 3080Hz。若把它塞进十二音键盘里对照，名义上算是“G”音……可严格说来，在被称为“十二平均律”的现代通用调律体系中，那个 G 音的频率其实是 3135Hz。

这误差可不算小。因此，当你用钢琴、吉他这类现代乐器、沿用通用调律去弹一个 C 大三和弦时，那三个音的频率比实际上并没有构成简洁的整数比。

这个误差的话题表面上不起眼，其实相当重要：究竟应当优先让某些和弦严丝合缝地吻合整数比，还是应当优先保证十二个音之间的等间距性——音乐史上围绕这一点展开过各式各样的争论。有关调律的技术与理论，已经成为音乐理论中一个名为“调律（Tuning）”的重要门类。当然，这类讨论远在计算器尚未问世的年代就已经展开，因此调律理论的发展中，也有温琴佐·伽利莱（Vincenzo Galilei）、梅森（Marin Mersenne）等物理学与数学领域学者的贡献。

5. 泛音与音色

基音与泛音不仅对和弦理论至关重要，实际上在论述音色时，它们更是极其根基性的知识。这一点也请容我说明一下。

这里又是刚才那 220Hz、440Hz、660Hz 同时鸣响的声音，可它听上去果然还是绝对像一个单音——“音色稍稍变厚了的单音”。然而用频率分析仪一看，那里确确实实耸立着三座山峰。

明明有三座山峰，听感上却只有一个音。这其实是音色世界中每时每刻都在发生的事情。

正弦波叠加与音色的关系

以作为基音的正弦波为基础，把频率为整数倍的正弦波泛音们以更小的音量混合进去，我们耳朵听到的就不再是“和弦”，而是“音色改变了的、厚实的一团声音”。究竟含有几倍频的成分、各含多少——这种频率成分的配比，是决定音色的相当主要的一个要素。

这是混入到第17泛音为止的一个例子。虽说足足混进了17个成分，听上去依然只是一个音。倒不如说，正因为混进了17个，各个音高之间才彼此碰撞、相互共鸣、产生嗡鸣，最终融化成了一种音色。

混到第64泛音，声音终于变成了合成器里常听到的那种味道。220Hz 的64倍是 14080Hz，恰好相当于混进了镲片之类乐器上格外突出的尖锐高频成分，于是必然显得闪闪发亮、亮得刺耳。

若把它拿去调音表上测，调音表大概只会说“这个音是 220Hz”。但那只是在说作为基础的基音是 220Hz；其中实际上鸣响着许许多多“隐藏的音”，正是它们在决定“音色”。

其实这并不限于电子音响合成的领域，所有乐器身上都同样成立。也就是说——除了调音表告诉你的主音高（基音）之外，还有大量整数倍于它的泛音在同时鸣响，而它们的配比决定了音色。

只不过，自然界中的泛音结构远比合成器造出的音色复杂得多。这是大提琴的声音——你能清楚看到，泛音混入得极为细密，而且声音发出的方式本身也在摇曳起伏。

即便在计算机技术如此发达的今天，要模拟如此复杂的泛音构成依然困难；正因如此，用计算机运算来再现乐器音色的软件，至今在市场上仍然寥寥无几。

顺带一提，一旦混入非整数倍的频率，声音就会越来越向噪声靠拢。

这是白噪声的频率分析。它像云一样在整个频段上均匀铺开，因而完全不存在音高感。没有音高的声音，就成了噪声。打击乐器的声音往往也含有与此类似、不具备基音／泛音整齐排列的频率成分；即便是刚才那把大提琴，弓弦摩擦的沙沙声本身就是噪声，而正是它带来了音色的丰富层次。

可见，“泛音”这一概念，无论对音色理论还是对和声理论，都是举足轻重的存在。

泛音的话题一不留神就拖得这么长。不过，在真正深入学习音乐理论的过程中，你迟早必定会撞上“泛音”这个东西，所以我估摸着也是时候介绍它了，就在这里让它登场。现在把它忘掉也没关系。今后在某个地方聊到科学话题时，你能想起这段内容就足够了。

总而言之，正是因为几百年前的人们这样不辞辛劳地钻研了那些繁琐的科学部分，我们才受惠于由此发展起来的理论。接下来，请带着“每个度数都有各自的色彩与质感差异”这份更自觉的意识，继续往前走下去吧。

小结

  • 两音构成的和音会因度数而大不相同，八度的同音齐奏与纯5度都极为直截了当地协和。
  • 5度、8度音响的单纯性，即便从科学角度看也多少具有说服力。
  • 以某个音为“基音”，把它的频率乘以整数倍所得的各个音，称为“泛音”。
  • “泛音”是科学地考据种种音乐理论时的立论依据。
