拿坡里六和弦与拿坡里和弦

本篇是一次拓展补充，我们将介绍在古典音乐中约定俗成使用的一类特殊和弦。这类和弦极少被直接移植到其他音乐流派中，因此也是营造纯正“古典艺术风味”的绝佳利器。

1. 什么是拿坡里六和弦

这里有一段大家熟知的小调古典和声汇聚（Kadenz）：

小调中的II级和弦是一个个性极强的和弦。作为减三和弦，它内部天生包含着紧张的三。像上面这样将其置于“第一转位”虽然能在一定程度上缓和其生硬感，但听起来依然带有明显的尖锐棱角。那么，如果干脆将它的根音降低，会发生什么呢？

奇迹发生了！三全音彻底消散，根音悄然依偎在主音上方半音的位置，孕育出了一种极其独特高贵的音响。这个“Fa - 降La - 降Re”的特殊和弦，在古典音乐界被称为拿坡里六和弦（那不勒斯六和弦 / Neapolitan Sixth）。

顺便提一句，在大三和弦的第一转位中上方声部重复了三音（Fa），但在拿坡里六和弦中，这种排列被作为特许例外完全认可。重复Fa音正是最标准、最典雅的配置形态。

名称的由来与和弦记号

“拿坡里六和弦”得名于18世纪在欧洲歌剧界独领风骚的“拿坡里乐派（那不勒斯乐派）”，因为该乐派的大师们极其偏爱使用这一和弦。而“六和弦”在法国古典和声传统中正是代表“第一转位”的专有名词。因此只要说出“拿坡里六”，其词义本身就已经内含了“第一转位”的属性[1]。

对于该和弦赋予何种标记，不同学派专著各有不同：在国际通用体系中，通常标记为“N6”；而在本章所参考的《岛冈和声》中，将其命名为“拿坡里的II级”，采用“-II¹”这一记号。由于根音被降低，因此附加负号“-”。在本文中我们沿用这一思路。

双重语境的解读视角

对于“Fa - 降La - 降Re”这一组构成音，其实完全可以赋予另一种视角来解读——即**“将IV级和弦的五音升高半音”**。

拿坡里乐派之所以压倒性地偏爱以“Fa - 降La - 降Re”这种第一转位的阵型来使用该和弦，一个重要原因就在于它的外形轮廓与IV级和弦高度相似，能够极其顺畅自然地嵌入到传统的终止式声部线条之中。

同时，这也能合理解释为什么可以重复三音Fa——因为“这个Fa本身也可以被视作原和弦的根音”[2]。

直达V级和弦的行进模式

像前述谱例那样连接到“I级第二转位（终止四六和弦）”，能够让降Re在声部上平滑级进半音解决，堪称模范正解；但除此以外，直接连接到V级和弦也是非常经典的用法。

此时在降Re与Re之间虽然跨声部发生了“对斜”（虚线所示），但在此处作为特例被完全宽免豁免；同时高音声部从降Re到还原Si发生了“减三度”跳进，在声部规范中也完全不被视为问题[3]。

像这样，由“拿坡里六”推进至V或I²→V再最终解决至I的一整套终止式，在早期古典和声文献中常被赋予一个极具浪漫色彩的名字——悲怆终止（Pathetic Cadence）[4]。

在大调中使用拿坡里六和弦

虽然拿坡里六和弦原则上诞生并深植于小调，但在大调的音乐语境中，它同样可以作为“来自同主音小调的借用和弦”强势切入[5]。

（在《岛冈和声》的记谱中，来自同主音小调的借用和弦会加注圆圈○标记。）

如果不谙此道，这绝对是一个极难在编曲构思中自发浮现的高难度和弦。直接借用“Fa - 降La - 降Re”，等于一口气从调外强力引入了降La与降Re这两个异质色彩极浓的变音，具有颠覆全曲氛围的震撼表现力。

与弗里吉亚调式的血脉渊源

由于活用了“紧贴主音上方半音的♭ii级音”，这首“拿坡里六和弦”与弗里吉亚调式（Phrygian Mode）（以及西班牙弗拉门戈音阶、阿拉伯音阶等包含小二度的特色音阶）有着血脉相连的深层联系[6]。

领会了这一点，就能对拿坡里六和弦在现代多流派音乐中的定位与审美边界拥有更加精准的掌控力。

2. 拿坡里和弦家族（各类拿坡里和弦）

由于拿坡里乐派的大师们压倒性地以“第一转位”来运用它，因此才确立了“拿坡里六”的美名。然而由此引发灵感，“如果把它放在原位、或者第二转位上来使用，会不会碰撞出更有意思的火花？”这种探索在后世作曲家、尤其是浪漫主义时期的作品中屡见不鲜。

然而“拿坡里六”这一称谓，严格专属于第一转位形态。因此这类扩展形态，被统括称为拿坡里和弦（那不勒斯和弦 / Neapolitan Chords）。

也就是说，“拿坡里和弦”是一个涵盖范围更宽泛的上位概念，而其中唯独第一转位形态被专称为“拿坡里六”。

拿坡里和弦（Neapolitan Chord） : 以♭II级音为根音的大三和弦的总称。

拿坡里六和弦（Neapolitan Sixth） : 在“拿坡里和弦”中处于第一转位形态、亦可被解读为“IV级和弦五音变音”的核心和弦。是拿坡里和弦家族中使用最为高频、最具代表性的形态。 : 在更广义的语境下，扩展叠置为大七和弦时同样被统称为“拿坡里和弦”。在历史上，“拿坡里六”的名称率先确立流传；随着非第一转位用法的逐步丰富，才衍生出了能够统摄全局的“拿坡里和弦”这一概括性术语。

用习惯的流行和弦级数对照确认

虽然本第Ⅶ章从头到尾严格遵循古典和声的级数体系，但我们自由派最熟悉的原生态记谱，是“以VIm为小调核心”的调性一元论级数体系。如果用平时习惯的标记法来对照，呈现如下：

小调中的拿坡里和弦相当于 ♭VII；若是“拿坡里六”，则相当于 ♭VII/II。另一方面，大调中的拿坡里和弦作为“同主音小调借用”，则相当于 ♭II。

平时轻巧便捷的“一元论级数标记法”，在面对这种以同主音调对称关系为核心的古典和声体系时，反倒显得解释起来有些繁冗杂乱。可见不同的记谱符号系统确实各有千秋。

通过我们熟悉的级数视角审视，可以清晰领悟：小调中的拿坡里和弦确实与弗里吉亚调式有着极高的重合度；而大调中的拿坡里和弦，则与爵士乐中的*三全音替代（Tritone Substitution）*有着异曲同工之妙。然而无论如何，**“以第一转位作为绝对的经典标准来使用”**这一点，构成了拿坡里和弦独一无二的非凡灵魂。
