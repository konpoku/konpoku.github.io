1. 隐伏八度与隐伏五度的禁则

紧随“平行（连续）”之后被列入黑名单的，是“隐伏（直达 / 並達）”的五度与八度。所谓“隐伏”究竟是指什么？我们首先来看乐谱：

这里并没有出现连续两次八度。然而，两声部向着“同一方向（同向平行）”运动，最终“达到并落入”了纯八度，因此被命名为隐伏八度（Hidden Octave / 直行八度 / 並達8度）。 到达该音程之前两声部的音程度数是什么并不重要，核心要害在于“同向运动直接到达纯八度”。在日本理论界也称“直行”或“隐伏”。

这究竟有何不妥呢？相比于刚才讲的“平行八度”，这里前一个和弦是三度音程，音响色彩富于变化，看似毫无问题……让我们先听一听实际音频：

大家可能会想：“这听起来完全没毛病啊……”，但对于追求极致纯净声部平衡的和声学而言，这依然是无法妥协的。因为相较于反行或斜行，同向运动天然带有极强的声部一体化趋向；理论家们认为：即便不是直接的连续八度，一旦“以同向运动直接撞进纯八度，在心理声学上所造成的声部吞噬感与平行八度并没有本质区别！”真可谓是对极致美感的近乎偏执的追求。 我们尝试对中音与次中音声部施加低通滤波让其退居幕后，单独凸显高音与低音声部来听一听：

仔细体味，确实隐约带有一种接近平行八度的“刚硬感与空洞感”……

因此，和声学将“两声部同向行进并最终达到纯八度音程”的现象称为“隐伏八度”，并将其列为禁则。纯一度的情况亦是如此；而同向行进达到纯五度的情况，则被称为隐伏五度（Hidden Fifth / 直行五度 / 並達5度）。

极为关键的赦免条件

然而，如果这条禁令全盘无条件贯彻，未免苛刻得有些反人类了，作曲家们将寸步难行。因此对于“隐伏禁则”，和声学追加了极为重要的限定与豁免条件：

  • (1) 仅在外声部（高音声部与低音声部）之间发生时才构成禁则（内声部之间完全无须顾忌）
  • (2) 即便发生在外声部之间，只要高音声部（Soprano）是级进进行的，就完全合法合规！

也就是说，只需要紧盯最外围的“高音与低音”两极即可。而“高音声部级进即视为许可”这条特许，其恩惠是极其巨大的！如果没有这条赦免，下面这种最经典的模式就全被一棍子打死了：

和弦是极其经典的 V → I 终止式，低音演奏根音跳进，高音也是最经典的导音解决到主音（级进二度）。这堪称全人类音乐中最自然顺畅的声音运动之一！如果连这都被宣判为死刑，那音乐理论简直成了不可理喻的笑话。因此在这种情况下，是绝对合规合法的。

隐伏一度的禁则

当然，除了八度之外，完全重合的“纯一度”，以同向运动直接到达也是不被允许的（隐伏一度）。不过在实际写作中，同向撞进同度的场景本身就极其罕见。此外，下谱所示的收束形态属于特许特例：

另外请务必牢记：该禁则的核心在于“同向到达”才受罚，若是“反向到达纯五度或纯八度”，则是完全合法且受到鼓励的！这是它与“连续/平行五度与八度”截然不同的一大关键区别。

2. II → V 的声部连接规则

至此，关于核心禁则的探讨就告一段落了。最后我们来看一个在实际作品中出现频率极高的连接—— II → V 的声部连接。

《和声》指出：在使用II级和弦时，极易形成如上谱左侧所示的声部排列。而仔细观察其走向V级和弦的过程，你是否察觉到它违背了某一条此前讲过的原则？

没错：“Re”这个音在前后两个和弦中都是共同音，但它却没有被原位保留！高音声部擅自跳下走向了导音Si。 乍看之下似乎违背了常规，但在《和声》中，这种连接反而被判定为优秀，甚至受到大力推荐！这完全是出于纯粹的听觉美学考量：与其在中规中矩地把“Re”死板保留在高音声部，不如让高音声部华丽鸣响清澈高亢的导音Si，听起来要优美动人得多！也就是说，在此处为了追求极致音响，音乐家们优先选择了“外声反行原则”，而主动覆写了“最短路径原则（保留共同音）”。

当然，上谱右侧的连接方式也是完全可行的，这里严谨地保留了共同音“Re”。

小调中的“二到五”进行

然而一旦进入小调，上谱右侧那种连接方式就立刻彻底瘫痪了！我们在其平行小调A小调中来验证其症结所在：

在古典小调体系中，第V级和弦必须强制改造成大三和弦（升高导音）。如此一来正如谱面所示：次中音声部被迫从F跳到了G♯，直接撞上了我们在前文讲过的**“不自然音程度数的禁则”——形成了刺耳怪异的“增二度跳进”**！

虽然以我们现代人的听觉审美，右侧那种略带诡谲阴郁的线条也别有一番异域风情；但从古典严谨美学的基准来看，这种生硬的线条被判定为“不够纯正优美”。因此在小调中，必须坚决采用左侧的方案。

至此，核心的“原则”、“规则”、“禁则”与“特例”的逻辑脉络就已经清晰展现在大家面前。需要再次提醒的是，在完整的和声学体系中，还存在若干本文未及穷尽的细小“特许例外”。 本文的核心目的，是希望带大家沿着“美学哲学 → 基本原则 → 细致规则 → 严厉禁则 → 人性特例”这一严谨梯次，真正领会和声学底层大厦的构筑哲学，因此适度略去了一些过于偏狭琐碎的细则。如果你对更深层的细节产生了浓厚探究兴趣，非常推荐进一步查阅专业教材深入研习。

总结

  • 外声部同向行进、且高音声部以跳进方式落入纯一度、纯五度或纯八度音程的现象称为“隐伏八度（直行八度）”或“隐伏五度（直行五度）”，原则上属于禁则。
  • 归根结底，在听觉上呈现出最平衡纯净的音响，才是和声学衡量声部配置的最高准绳；而在复杂多变的音乐情境下，最佳方案往往具有多维的灵活性。
