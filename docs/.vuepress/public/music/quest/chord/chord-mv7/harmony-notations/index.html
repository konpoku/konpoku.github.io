和声：转位形态与记谱法

漫长的古典派风格样式的探讨终于快要接近尾声了！我们已经掌握了古典基本和弦样式，学习了“声部排列”与“声部职责分工”，以及“优美连接”的原则。光是这些知识，就已经相当具有专业深度了。接下来我们要讲解的，是“转位形态（Inversion）”的用法。

1. 什么是转位形态

“转位”已经无需过多解释，它指的就是将根音以外的和弦音置于低音声部演奏的声部配置。在第IV章中我们已经对其做过初步介绍。

正如本章开头所阐述的，古典派音乐在和弦的选择上极为克制节俭，大调基本上绝大部分都由大三和弦构建。在这样严苛的语境下，能够为音响带来丰富色彩变化的转位形态，自然显得弥足珍贵。

不过，它的具体用法自然伴随着严格的规范与戒律，这正是本篇要重点梳理的内容。

2. 关于记谱标记法

说到现代斜线和弦的标记，通常是用斜线隔开或者加上“on”。然而在《岛冈和声》中，这里也引入了一套独特的标记法，如下所示：

中间的被称为“第一转位”，右侧的被称为“第二转位”。在中文和日文教学中也常简称为【一转】、【二转】。在习惯之前可能会觉得有些眼花缭乱。请注意：七音和九音标在右下角，而转位次数则标在右上角。

这种标记法在19世纪末至20世纪的美英和声教科书中偶有出现，《和声》的作者岛冈让先生大概正是参考了其中的某一部。虽然初学时需要一点适应过程，但这套标记其实非常实用便利。

例如若采用传统的 IV/VI 这种斜线标记，大脑在瞬间需要做一番心算：“6与4相差三度，所以这是以IV级和弦的三音作为低音的形态”；而如果直接写成 IV¹，一眼就能直观明确它是一转形态。一旦习惯了这种记号，反倒会觉得平时的斜线标记显得格外冗长繁杂。

数字低音（Figured Bass）

另一方面，从巴洛克时期一脉相承的古典正统记谱体系则截然不同——**数字低音（Figured Bass / 通奏低音数字）**是全球范围内流传最广、最标准的正统记谱法。

其中第一转位被称为“六和弦（Sixth Chord / 6和弦）”，第二转位被称为“四六和弦（Six-Four Chord / 4/6和弦）”。“6”和“4”这些数字究竟源于何处？正是来自“上方声部距离低音的音程度数”。

虽然法国古典乐界极其顽固地坚持这一套标记体系，但这绝非法国局部的专属记谱法。在德国、英国、美国的经典和声学著作中，这也是最普遍映入眼帘的标准记法；培养出比才、萨蒂、德彪西、拉威尔等无数音乐大师的巴黎国立高等音乐舞蹈学院（CNSMDP）同样采用这一体系。可以说，数字低音是国际音乐学界公认最主流、最坚固的标准标记法。

数字低音的底层核心，在于“首先确立低音，然后根据其上方如何堆叠音程来构筑整体音响”的根本音乐哲学。 当然，各种标记法各有优劣。在本文中，我们主要采用岛冈和声的上标数字记法，不过稍作字体倾斜处理，以便与平时的 7th 或 6th 附加音清晰区分开来。
