古典派转调技法基础

2026.09.05和弦论
和弦论古典和声学专论与禁则详解

到上一篇为止，我们已经大致梳理了基础和弦的连接方式。按理说接下来该讲解大七和弦、小七和弦的连接，或者小调中的精细连接规则等等，但作为“古典派理论体验之旅”的本章，这些过于细琐的部分我们就略过了。

为了实现本章“能够写出具有古典派风味的乐曲”这一目标，更为关键的是关于**转调（Modulation）**的技法。在第IV章中我们学习了流行音乐中的转调技法，但那是非常针对流行乐的解释，而古典音乐中的转调风格则截然不同。再怎么说，古典乐里绝不可能出现“在最后一段副歌时升调来推向高潮”这种手法。

因此，虽然只是简明扼要的介绍，我们将把焦点放在与流行音乐不同的部分，提炼出关键要点，以便大家能够写出“具有古典派韵味的优雅转调”。

1. 使用属七和弦的转调

在古典派理论中，充当转调第一大原动力的和弦，就是属七和弦（Dominant Seventh Chord）。关于这一点，与第VI章中介绍的爵士乐理论有着相通之处。

属七和弦是每个调所独有的存在。例如C大三和弦，不仅在C大调中，在F大调或G大调中也是自然音阶和弦的一员，并非C大调所独占。相较之下，G7除了C大调之外不属于任何其他大调。G7应当回归的家园，（除了同主音小调C小调这个“镜中世界”之外）就只有C大调。可以说，属七和弦就像是一个指明前进道路的指南针。

特别是在古典音乐中，经常利用副属和弦（Secondary Dominant）进行调号±1的转调：利用I7转往下属调，利用II7（重属和弦）转往属调。

运用转位进行的转调

话虽如此，如果仅仅机械地按照 C → C7 → F 这样直接进行，未免显得有些缺乏技巧。

因此大显身手的正是转位（Inversion）。通过运用和弦转位，在将低音线条控制在级进进行的同时完成转调，仅仅这一点就能立刻呈现出极富古典特色的优雅运动轨迹。

通过活用我们在上一篇文章中刚学到的“第三转位”，就能完成极其流畅优美的转调！

并且，C7同时也是通往“幽暗世界”——F小调的大门，因此究竟解决到大调还是小调完全可以自由选择。

听起来非常具有古典派的味道吧。此前我们之所以对转位形态的使用如此讲究，目的之一正是为了能够如此优美地实现转调。

同样的手法也可以用于向属调的转调中。

转位的方式绝不仅限于第三转位。无论如何，关键在于通过熟练运用转位形态，可以在保持低音声部级进平稳移动的同时，营造出极其丰富多彩的音乐表情。

实际范例

贝多芬 钢琴奏鸣曲第8号“悲怆” Op.13 第一乐章

这是选自《悲怆》第一乐章再现部的一段选段。虽然速度极快，但应该隐约能感受到低音正在一步一步稳健级进下行，同时发生了调性转换。

由于篇幅过长，乐谱只截取了开头部分。但光是这里就极具趣味：虽然以C小调开始，但随后立即切入D♭音，眨眼之间就转入了F小调。这就是“属九和弦・第三转位・省略根音”。虽然每种技法单拆开来都很简单，但将三者结合在一起就构成了极富意趣的和弦。“通过简单构思的巧妙组合创造出引人入胜的效果”，在这一点上，其实与爵士乐理论有着异曲同工之妙。

2. 使用减七和弦的转调

掌控古典风转调的另一大关键钥匙，是减七和弦（Diminished Seventh Chord）。

从第一要义来说，减七和弦被视作“小调中省略根音的属九和弦”。以C小调为例，叠置到九音得到“G-B(♮)-D-F-A♭”，抽掉根音G就构成了dim7。在大调中，也可以通过“同主音调借用”引入它。 正因这一出身，其原则上的进行方向是半音上方的小和弦或大和弦。如果是Bdim7，其解决目标就是Cm或C。

并且，由于“所有音均以等距的小三度间隔排列”的特性，它具有一个极其重要的特质：无论如何转位，和弦的外形始终保持为dim7不变。不过正如上谱所示，等音记谱的书写方式会有所不同。这一特质真正至关重要，因为正如前文所述，古典风转调的奥秘就在于转位。

用减七和弦进行三全音远关系转调

例如将C小调的固有dim7和弦“B-D-F-A♭”做成“第三转位”，把F置于低音[1]。这当然可以直接看作C小调的dim7，但如果转换等音记谱的视角，它也可以说是F♯小调的dim7。

视其为何种和弦，其目标进行方向就会截然不同。

通过这种方式，就可以自然地实现从C小调到F♯小调这种相隔三的远关系转调。像这样利用等音关系的转调，名副其实地被称为等音转调（Enharmonic Modulation）。这种转调的魅力在于，通过将降号改读为升号、或升号改读为降号，能够瞬间跨越到调号截然不同的全新调性中。

用延音线连接等音

在等音转调的演进过程中，自然也会出现一种非常有趣的形态：在音符保持延长的同时暗中偷换等音记谱。

在乐谱上就会呈现出像这样“用延音线连接A♭与G♯”的奇特形态。从结果来看虽然只是转往小三度下方调，并不罕见，但转调的美学正蕴含在这一过程之中。

在这个谱例中，作为“第二转位省略根音”属九和弦的低音B，从转调目标调A小调来看正好处于II级位置，因此隐约带有了II级和弦的意味。于是我们顺水推舟，在后面接续了一个真正的V7。如果仅看低音声部，它实际上构成了一个“二-五-一（Two-Five-One）”，因而听感异常顺畅舒适。也就是说“完全不必紧接着就立刻解决”。在减七和弦之后接属七的第三转位、然后再继续转调……可以设计出形形色色的应用套路。

3. 使用增三和弦的转调

虽然不像减和弦那样拥有无可动摇的核心地位，但增三和弦（Augmented Triad）也同样具备与减和弦相同的“转位后结构形态保持不变”的性质，因此也可以用于等音转调。

将12个半音“以小三度为间隔四等分”得到的是减七和弦，而“以大三度为间隔三等分”得到的就是增三和弦。

增三和弦原本的登场频率并不算高，但在非自然小音阶、带有导音的小音阶（如和声小音阶）中以III级构筑和弦，就会得到增三和弦。特别是将其置于“第一转位”形态并进行到IV或VI和弦，算是一种固定程式。

在本例中包含“E♭-G-B”三音。在C小调的语境中B(♮)自然是导音，但通过转位与等音转换，其中的每一个音都可以成为导音。

这次E♭与D♯的等音转换成为了关键。在第1-2小节中，作为增三和弦出现的“G-B-E♭”中的E♭被转换为D♯，将其视作导音顺势半音上行，而其余声部保持不动。这样就构成了“G-B-E”这一E小调的主和弦第一转位。

第3小节中运用了相同技法，但去向并非Em而是EΔ7，一举平稳降落在了带有大量升号的G♯小调中，完成了华丽的收尾。

利用斜行进行和弦先现

话虽如此，大三度关系的转调从根本上来说是具有相当震撼感的。为了缓解这种突兀感，在上面的谱例中，高音声部与其他声部不同，在第2、4拍先行移动取到了下一个音。也就是说，如果四部和声的所有声部同时切换到下一个和弦，难免会产生明显的割裂断层感，因此声部通过错开时机进行斜行运动，使色彩变化呈现出细腻的渐变效果，这是一项极其精妙的技术。

这宛如合唱或管乐团中的“交替换气（偷气）”（若所有人同时换气会导致声音断裂，因此彼此错开时机换气的技术）。应当意识到，这种构思在将和弦打包视为单一色块的现代“和弦理论”中是极易被忽略的思维方式，平时应当多加留意体会。

大家对爵士乐通常抱有频繁转调的印象，但相较于流行音乐，古典乐也是一个转调极其频繁的音乐流派。然而，关于转调的实现方式，两者的侧重方向大相径庭，而这正是其引人入胜之处。

这虽然只是一个粗略的对比，但通过这样对立对照，有助于在脑海中对理论体系进行梳理与自如切换。而且，认识到这种音乐观念的差异反过来深刻塑造了各自的音乐理论体系——例如正因为大量使用“转位”和“省略根音”，古典理论才会设计专门的数字低音与转位标记——这对于建立多维、相对的理论视界至关重要。

总结

  • 通过使用转位，可以在保持低音声部平滑流畅的同时完成各种转调。
  • dim7与aug凭借其特殊的对称结构性质，可利用等音替换进行“等音转调”。基本上前者对应小三度关系的转调，后者对应大三度关系的转调。
