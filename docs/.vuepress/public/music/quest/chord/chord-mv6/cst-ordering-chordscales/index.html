1. 调式之树（Mode Tree）

最近几讲我们一直在马不停蹄地引介新音阶，海量的信息恐怕在大脑里已经有些拥挤混乱了。虽然此前我们把派生自3个母音阶的21个调式分别排成列表进行了归纳，但由于它们被母音阶人为分割开来，横向对比对照依然相当费力。

因此！我们将这27个调式按照音程特征逐级分支排列，独家绘制了一张树状系统图。我们将其命名为“调式之树（Mode Tree / 调式树）”。

虽然叫作“和弦音阶之树”或许更加精确，但名字还是短一点更利落……在绝大多数传统理论书中，各个调式都分散在不同章节，极少有人将其整合为一张一览无余的汇总全景图。毕竟除非开本极大，否则很难在跨页两张纸里浓缩如此庞大的信息量。这张图可以说是相当难得且珍贵的参考资料。

图表解说

“调式之树”以树的“根部”即根音为中心，首先根据大三度（M3）还是小三度（m3）向左右分叉，随后依据7th、5th、引伸音……逐级分流，顺流而下即可追溯到具体的音阶。整体设计上，大体上部汇聚升号较多、色彩明朗的音阶，下部汇聚降号较多、色彩暗淡的音阶。

在树干最初的第一个分叉处，下方标有 的标记，这是我们在此率先将对应减和弦的音阶分流了出去。由于异名同音解释的复杂性，如果在后续枝杈中强行推导会非常别扭，因此我们索性“从根基部分就将其作为脱离大调系/小调系和弦的第三极”独立分支出来。

在每个音阶的右上角，标注了其对应的和弦品质以及可用引伸音列表。

实心黑圆点代表和弦品质，例如上图代表“小七和弦”。灰底深灰字的“-9”因为是避用音，所以呈现为灰色。灰底白字的“13”，则是前文提到过的“存在见解分歧的避用音”，多利亚系的13th以及减和弦属于此类。

“调式之树”就像一样，当你想要寻找引伸音配置相似的调式、或想在相同和弦品质内替换尝试其他调式色彩时，它将是绝佳的参考指南。当然，这27个调式并非音乐中音阶的全部，若过度死板依赖这张表，创造力难免会受到局限。

实战演练：使用调式树

让我们实际利用调式树，来检验常见和弦的音阶归宿。例如在C大调中，作为进行到D–7的常见副属和弦——A7。

在多数常见情况下，除了带升号的三音（C♯）之外，其余音通常都遵循原调的自然音阶。顺次检验非和弦音：9th是带来鲜明清晰声响的“9”，11th是构成纯四度的避用音“11”，13th则是压在和弦音上方带来不协和的“-13”。

首先在调式树中轻快地切入属于属七和弦领地的左下区域……

于是，我们成功定位到这正是“Mixolydian ♭6”！仔细审视其音程，确实不过是混合利底亚将6度音降低半音而已。如果6度变成“13th”，从树状图上也能一眼看出它会无缝对接到正上方的“Mixolydian”。

探索变体色彩

此外在A7中，为了营造更强烈的“D小调色彩”或“经过减和弦色彩”，也有将B音降半音的变体形态。

这也同样可以从刚才的 Mixo ♭6 位置向上追溯其名称。二者的分水岭在于“9 还是 -9”，因此只需退回到该分叉点重新选择路径即可。

这样我们就能查明其对应的和弦音阶是“Phrygian Dominant（弗里几亚属调式）”。或者，根据“引伸音结构相似的音阶彼此相邻”、“上部排布明亮音阶、下部排布暗淡音阶”的结构特点，直接用肉眼扫视下方相邻的音阶，也是一种高效的查找技巧。

通过这种梳理比对：在还原B的情况下它冠以“混合利底亚”之名，即性质偏向V级属和弦；而在降B的情况下它变成了“弗里几亚”，仅从名称就能立刻洞察到它的和弦性格已经大幅向IIIm靠拢。

另外，左上角写着的类似型号编号的缩写，代表其母音阶与调式序号。“MM-V”表示“旋律小调第V调式”，“HM-V”表示“和声小调第V调式”。 在副属和弦中挑选音阶所承载的“音响深意”与“音阶间的相互脉络”，借助和弦音阶理论的系统整理，被极其清晰地具象可视化了。

2. 调式地图（Mode Map）

“调式之树”由于将各个调式呈纵向一列排开，纵览非常直观；但它也有一个相对的弱点：音响上极度相似的调式，在位置上并不一定相邻。 例如“弗里几亚”与“弗里几亚属调式”，两者仅仅相差一个大三度还是小三度的一音之差，但由于3rd是树根最深处的核心分叉点，导致它们被迫分隔在了左右两端……

为此！我们又绘制了一张根据各调式“音响距离的亲疏”呈网状铺展的图表！名之曰调式地图（Mode Map）。

SVG版 / PNG版

虽然它的排布看似错落离散，但因为能够利用横纵两个坐标轴进行多维表达，其相互关联性得到了极佳的呈现。例如“弗里几亚与弗里几亚属调式”、“爱奥尼亚与旋律小调”等在调式树中被拆散的组合，在这里都能用连线直接贯通；不仅如此，在爱奥利亚与洛克里亚之间，也精妙地安插了“爱奥利亚 ♭5 / 洛克里亚 ♮2”。同时，“属减音阶”介于减和弦与属七和弦两用枢纽的跨界位置，也得到了淋漓尽致的体现！

当然，视觉呈现的方式因人而异。比如按“利底亚”、“爱奥利亚”等调式族系分类成组，也会非常有趣。一边在乐器上实际弹响试听，一边按照自己最顺手的方式整理这些调式，仅是完成这项整理工作本身，就能让你的理解突飞猛进。

3. 和弦音阶理论的核心意义

一路走来经历了如此硬核死记的“地狱修行”，恐怕大家已经有些想不起当初为什么要把和弦音阶整理得如此琐碎了。“这样不厌其烦地给每个音阶挨个起名字，难道不是在强行装腔作势吗？”难免会产生这种困惑。在主要调式已然悉数登场的当下，让我们再次重申和弦音阶理论（CST）的存在意义。

演奏记忆的锚点

无形无质的音乐，只有通过语言符号化，才能成为便于在脑海中随身携带的信息与数据。这是音乐理论最根本的哲学。例如爵士乐手在练琴时，会建立“这是属减音阶的手感运指，这是变化音阶的手感运指……”的肌肉与认知记忆；如果没有这些名字，想要在大脑中整理存储这些极其复杂的语汇将极为艰难。即使是像“变化超级洛克里亚”这样看似冗长的名字，比起说“这是一个减七和弦，引伸音包含♭13，避用音是♭9和♭11”，信息密度依然要凝练精悍得多。

信息传递的高效载体

在人与人之间传递信息时，若想流畅自如地交流极高维度的音乐构思，逐一命名同样是不可或缺的利器。这在我们初讲CST时的对话小剧场中已经得到了充分印证。正如前文所述，CST正是这样一种“看似反直觉、实则通过准备大量专属名词来最小化实际流通数据量”的降维方法论。

创意灵感的调取库

在每个根音之上，都存在着海量的和弦与音阶选择。这个道理人尽皆知，但正因为有了命名与体系化的锚定，许多灵光乍现的创意才能被顺藤摸瓜地激发出来。我们在第V章学过的“音块（Tone Cluster）”、“四度堆叠和弦”、“复合和弦”都是这一规律的典型产物。

如今手握“调式地图”这一罗盘，在构思替换和弦与音阶时的创意，调取起来变得异常轻而易举。懵懵懂懂地任其飘散在虚空中，与配以明确的名字、被图式化归档随时待命，其激发灵感的敏锐度不可同日而语。

大脑认知的合理升级

正如我们此前所讲，我们此刻所经历的，正是“从4个音（和弦）迈向7个音（调式）的大脑合理升级”。不妨换位思考一下：如果一个完全不懂乐理的人问你：“就算不知道和弦的名字，凭感觉找自己觉得好听的音，不也能写出好歌吗？为什么非要学乐理呢？”你会如何回答？你一定会从上述“记忆”、“沟通”、“灵感调取”等维度向他解释音乐理论的无比便利。而和弦音阶理论，不过是将这套逻辑往更精细微观的层面上推进了一步而已。

因此，这段披荆斩棘的修罗之路绝非徒劳。在下一节中，我们将实际运用这些和弦音阶知识，全面丰富我们的音乐表现力。
