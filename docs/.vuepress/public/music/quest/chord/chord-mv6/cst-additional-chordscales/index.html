若干重要的和弦音阶

音阶收集之旅终于迎来了最终回。这里我们只再介绍最后4个和弦音阶。而且这4位在此前的学习中大家都已经或多或少打过交道，并非初次相识。因此，我们可以轻快利落地推进！

1. 两种属和弦系音阶

首先是两个属于属七和弦系统的和弦音阶。其实两者在前面的章节中都已经介绍过，所以很快就能讲清楚。

全音阶（Wholetone）

第一个是大家非常熟悉的“阶（Wholetone）”。

在旋律篇介绍它时，我们曾建议使用时最好不要过多考虑和弦；但若硬要检验其和弦品质，它实际上构成了“增大七和弦（augmented seventh / 7♯5）”。在流行乐的世界里，这是一种很难偶遇的和弦形态。 不过，在完全脱离了传统调性文脉、仅有6个音的“六音音阶（Hexatonic Scale）”全音阶中，异名同音的处理自由度极高。由于“♯5”也可以视为“♭13”，从这个角度思考，就会发现它完全可以对应到常规的属七和弦上。在实际创作中，它作为带来奇效的“绝招武器”，效果极其拔群。

变化属音阶（Altered Dominant）

第二个是在第V章已经介绍过的“变化属音阶（Altered Dominant）”。

其最大的特征，在于引伸音中同时兼备了 ♭9th 与 ♯9th。将 ♭9th 与 3rd 结合时，能够写出活用和声小调标志性“增二度台阶”的旋律线条；而将 ♯9th 与 3rd 结合时，则能写出依托平滑滑动的旋律线条。

关于 ♭13th，理论界也有将其视为 +5th 而标记为“±9, ±5”的观点。确实，“♭13th”这个名字难免会让人联想到它与下方半音处的纯五度（P5）相互交织的运动，但实际上该音阶中纯五度根本不被使用。从这个角度来看，写成“±5”或许更能让人准确把握该音阶的音响实质。

变化音阶与超级洛克里亚

顺便提一句，变化属音阶单看键盘上的物理构成音，与超级洛克里亚（Super Locrian）是完全相同的。

但是，尽管此前我们遇到过不少拥有多个别名的调式，但这两者的关系与那些别名完全不在同一个次元，它们绝非“同一音阶的不同称呼”。

Altered 拥有“大三度”，是与属七和弦深度绑定的和弦音阶。看似“小三度”的那个音实则是 ♯9th，属于可用引伸音（Tension）。 相对地，Super Locrian 拥有“小三度”，是与半减和弦绑定的和弦音阶。看似“大三度”的那个音实则是 减四度（o4th），它是压在和弦音上方半音位置的避用音（Avoid）。

将哪个音认知为和弦音、将哪个音认知为避用音，必然会直接左右你的实际演奏形态。如果仅凭键盘外观看起来相同就把两者混为一谈，就会面临无法凸显真正和弦音、反而在避用音上疯狂发力导致和声色彩支离破碎的严重危险。

D–7 G–7 Eø(-9,-13) A7

上例是在遇到 Eø 的场景下，正确弹奏“E超级洛克里亚”的演奏示范。在明确意识到这是半减和弦的前提下，着重强调小三度音，演奏呈现出了极其优美的音响质感。而“减四度”则仅作为乐句穿梭的经过音点缀，并未予以强调。

D–7 G–7 Eø(-9,-13) A7

而在这一例中，则是把“E超级洛克里亚 = E变化属音阶”生搬硬套死记硬背的人容易犯的错误示范。像演奏E变化音阶那样把减四度当成大三度和弦音来大肆演奏，结果直接摧毁了整个和声的美感。

归根结底，CST的立论起点正是“即便同样全是白键的音阶，为了清晰意识到各个和弦独特的音响差异，也要将其细分为7个调式”，因此绝不能因为表面构成音相同就将不同的和弦音阶混为一谈。不过，表面物理位置相同这一点，倒确实可以作为辅助记忆的拐杖。

变化音阶与属利底亚

如果对这一现象做进一步深挖：超级洛克里亚是旋律小调派生的“孩子”之一，是从旋律小调第vii级音开始的调式。例如E变化音阶，在物理键盘上可以说是将F旋律小调的起始点平移错位后的产物。

话虽如此，如果为了省事直接用F旋律小调来替代E变化音阶演奏，若不理解各音功能的本质差异，依然很难演奏出优美的音乐。不过，在旋律小调派生的调式中，有一个互换性极高的调式——那就是从旋律小调第iv级音开始的属利底亚（Lydian Dominant）。让我们对比一下E变化音阶与B♭属利底亚的内部结构：

你是否注意到了：它们的根音（Rt）与5th、以及作为向导音（Guide Tones）的3rd与7th，虽然互相对调颠倒，但音高其实完全是一模一样的！这意味着如果在需要演奏B♭属利底亚的场合演奏了E变化音阶，“原本弹的3rd和7th，恰好变成了对方的7th和3rd”。虽然在音乐意义上两者绝非完全等同，但至少在实际演奏中，几乎不可能发生致命的和声翻车。反过来，在想演奏B♭变化音阶时，用E属利底亚来代用也是成立的。

这看似某种奇迹，但如果联系**三全音代理（Tritone Substitution）**的原理来思考，就会恍然大悟。E7与B♭7的根音相距三全音，互为表里正反的关系，而支撑它们可以相互代理的逻辑，正是因为它们共享了相同的3rd与7th向导音。理解了这一点，就会明白它们和弦音的高度共通完全是顺理成章的必然结果。

变化音阶与属利底亚都是在属七和弦上演奏的核心主力调式，掌握好这对共生互通关系，在实战中将大有用武之地。

与“变音抵消”的关系

变化音阶拥有 ♯9th 这一相对罕见的音程。♯9th 与“小三度”是异名同音，与我们之前探讨的“变音抵消（变音消除）”课题息息相关。此前在III7上发响还原G时，我们将其解释为“变音抵消”。但严格来说，根据乐句线条的不同，也可以让听众觉得它是“重升F（F𝄪），即 ♯9th 的音”。

典型的例子就是像这样把G音作为向上倚靠至G♯的趋近音（Approach Note）来使用。从极度精微的理论诠释来看，因为它是“依附于G♯的相邻音级”，属于F的音级谱系。由于F音紧贴到了G♯的身边依附其上，因此该音在理论上被记为“重升F”。

异名同音的深度探讨，也终于推进到了如此幽微深奥的境地。

2. 两种大七和弦系音阶

截至目前，大七和弦系的音阶要么是具有平均明亮度的“爱奥尼亚”系，要么是以 ♯11th 为标志的“利底亚”系。为了展示“其实还有截然不同类型的存在”，我们在此额外补充介绍两种。

和声大调（Harmonic Major）

第一个是在“调式互换”一节中也曾提及的“和声大调（Harmonic Major）”。

它介于大调与和声小调之间，是能对应大七和弦的宝贵和弦音阶。它与古典音乐渊源深厚，如果要推选下一任母音阶候选，非它莫属。因此我们在此将其列为核心成员之一。

阿拉伯音阶（Arabic / 双重和声大调）

另一个是在旋律篇第IV章中偶遇过的“阿拉伯音阶（Arabic Scale）”。

这是一种不仅在阿拉伯，在拜占庭及印度音乐中也广泛使用的音阶，拥有繁多的别称。脱离民族色彩的西方理论命名中，它被称为“双重和声大调（Double Harmonic Major）”。这是因为前半段的“C-D♭-E-F”结构与后半段的“G-A♭-B-C”完全对称一致，看起来就像将两个和声大调拼接连缀在一起一样，因而得名。

虽然仅看和弦品质它可以对应大七和弦，但由于在 ♭2 与 M3、♭6 与 M7 之间形成了两个“增二度”，调性色彩极其奇特诡谲，听起来并没有普通大调那样的明朗感。就这一层面而言，它是极具异域风情的音阶。 这类带有鲜明民族色彩的音阶，不仅可以作为和弦上偶尔点缀的“调式”来使用，若作为母音阶在整部作品中大张旗鼓地铺展，同样能创造出引人入胜的迷人音响。

上例就是在旋律篇第IV章中使用阿拉伯音阶创作的音乐范例。归根结底，前面文章中介绍的21个和弦音阶都属于**“西方传统音乐”的基石，而在其藩篱之外，依然存在着广阔得多的无垠天地**。希望大家永远不要忘记这一点。怀抱着这样的深意，我们决定将这个源自民族音乐的音阶吸收为正式成员。

至此，大功告成！我们终于将整整27个和弦音阶全部介绍完毕。在这里，音阶的“收集大工程”告一段落。当然，世上还存在着其他形形色色的民族音阶、源自布鲁斯的音阶、五音或六音构成的音阶、以人工音阶为母体派生的调式、对现有调式进行微调变异的音阶，以及其他各种潜在母音阶候选：

  • Bebop Scale（比博普音阶）
  • Hungarian Minor（匈牙利小调）
  • Symmetric Augmented（对称增音阶）
  • ……
