1. 引伸音理论温故

在爵士乐中，关于引伸音（Tension）与避用音（Avoid Note）的知识具有举足轻重的战略地位。在和弦篇第IV章中，我们掌握了基础规则的骨架：凡是叠置在和弦音上方处的音级通常沦为避用音；但在属七和弦中，容忍宽容度大幅放宽；以及IIm7那特殊的避用音生态等。

接着我们又学到了：“是否属于调内自然音级（Diatonic）”是一大核心判别基准，以及“在同一音级度数上，自然音系与变音（±）系引伸音不可混杂并存”。 在属七和弦以外的和弦上，原则上仅限使用调内自然引伸音，因此选项并不宽裕。然而在属七和弦的领地内，却享有极其浩瀚的自由度。在第V章的“变化属和弦（Altered Dominant）”中，我们也对高阶应用级引伸音做了解析。 在专业爵士理论书中，关于引伸音的篇幅极厚，越是正统经典的著作，对每一个属七和弦所能搭载的引伸音剖析得就越是精微入微。在作为“入门篇”的本讲中，我们虽然不会过深铺展，但此前对新登场的三代理和弦的引伸音配置尚未涉足，因此在此进行针对性的升华补充。

属和弦（Dominant Chord）的语境界定

在爵士理论中，音乐家们往往不直呼“属七和弦（Dominant Seventh Chord）”，而是特意统称为属和弦（Dominant Chord）。之所以采用这种表述，是因为单纯表示和弦品质的“属七和弦”一词，会自动囊括源自布鲁斯音乐、混合利底亚旋法、多利亚旋法等生态中涌现出的特殊属七形态。那些属七和弦遵循着完全自成一派的文法，古典中“下行五度进行解决”等正格原则在它们身上根本不适用。 因此，为了构筑严谨自洽的理论体系，爵士乐理将那些和弦打上“非功能性属和弦”、“特殊功能属和弦”或“不具备属功能的属七和弦”等标签剥离出去；唯独将原调V7、副属和弦、三全音代理和弦等这些“真正恪守爵士功能和声逻辑的属和弦”统摄在一起，严正定名为“属和弦（Dominant Chord）”。 本章后续也将沿用这一专业规范称谓。

2. 原调属和弦/副属和弦与引伸音

虽然属和弦蕴藏着调用非自然变音引伸音的无限潜能，但理论讲解的起点，依然是从梳理针对原调而言的自然引伸音（Diatonic Tensions）起步的。

以此为基石，再逐一引介“在这个和弦上，还能有这样那样独门玩法”的高阶选配方案，这是正统爵士理论书最典型的教学脉络。

关于 9th

III7 与 VII7 的自然九度属于调外变音，因此选用 -9th（♭9th）反而是更为标准本色的选择，这一点与其他和弦不同。 +9th（♯9th）引伸音，在自由派乐理中正是所谓的“变音抵消（变音消除）”。爵士理论普遍将其解释为：“它是增九度。既然归根结底属于九度系引伸音，那么它与大三度音同时发响就是合法的”……但若翻看实际乐谱，会发现不少谱例直接以小三度（m3）的方式记谱（由于引伸音度数与记谱之间产生了错位，这对初学者来说难免容易产生混淆）。 虽然它被认定为可用引伸音（Available Tension），但鉴于其独特的异质性，我们在此特意用橙色标注。这种“变音抵消”的顺畅度因和弦而异，对于 VII7 上的 D 音，部分严谨理论书甚至不予认可其作为引伸音的资格。 顺便提一句，由于 +9th 与 -9th 之间相距全音，二者在物理上完全可以共存；只要你的审美需要，同时弹响两者在爵士理论中是允许的。

关于 11th

在所有属和弦的表格中，11th 一栏全都是空白。首先，未经升高的自然 11th（纯四度）由于直接压在核心骨架大三度音上方半音处，在所有属和弦中统统属于绝对避用音（Avoid）。 另一方面，如果是 +11th（♯11th / ），则属于可用引伸音，但在基础引伸音列表中通常不予默认收录。除 VII 级外它首先属于调外音，且 +11th 本质上与根音构成了三全音关系，仅凭这一点在使用时就需要乐手具备高度的审美留白与声部驾驭功底。 话虽如此，在真实的现代爵士演奏中，在 V7 上大量飙出 +11th 早已是司空见惯的家常便饭。

关于 13th

在 III7 与 VI7 中，顺应原调音阶推导出来的引伸音是 -13th（♭13th），该音会与五度纯五音发生半音打架碰撞。然而，由于纯五音在属七和弦中原本就是存在感最薄弱、可有可无的声部，在实际演奏中为了消除浑浊，乐手们极其普遍地直接将其彻底省略（Omit 5）。

大调系目标与小调系目标

在裁决非自然变音引伸音时，一个至关重要的航标，就是根据其解决目标的和弦属性进行阵营划分。虽然副属和弦全都共享属七和弦品质，但它们绝非同质之物：其解决目标的和弦，存在着是大调和弦还是小调和弦的重大分野。

正是这一分水岭，对引伸音的取舍审美产生了决定性的深远影响。

以 VI7 为例深剖

这一点在 VI7 上体现得最为淋漓尽致。它最终要解决到 II–7。以C大调为例，这意味着向D小调的局部微观离调；换言之，这等同于向包含一个降号（B♭）的全新调域进行转调。 将这一底层现实牢记于心后，就会豁然开朗：在 VI7 上选择降B音（♭9th）作为引伸音是何其顺理成章、天经地义！或者倒不如说，唯有这样选用，它与后续 II-7 的咬合纽带才最为坚不可摧，因此这种选择在实战中极其普遍主流。

相反，如果在 VI7 上把13度引伸音弹成 F♯，听众脑海中瞬间就会被诱导去期待后续将要走向 II 级的大三和弦（D大调）：

这并不是说绝对不能弹，我们在第IV章中确实也介绍过这种反常规用法。但平心而论，这种选择显然属于较为“破格例外”的偏门处理。 毕竟它原本是因为“能够强力咬合 II-7”才被作为前置小弟引入的，如今在小弟身上却公然吹出否定老大哥小调属性的 F♯，未免显得有些背叛反骨。因此，使用 -13th（♭13th）引伸音，天然承担着提前铺陈小调芳香、暗示后续即将迎来小和弦的预兆功能[1]。

由此，针对 V7 以及各级副属和弦的引伸音选用，确立了如下核心准则：

  • 解决目标为大调系 = 选用 9th、13th 更忠实于解决目标的调式色彩
  • 解决目标为小调系 = 选用 -9th、-13th 更忠实于解决目标的调式色彩

不过例如在 V7 上强行叠置 -9th，作为引入降A（A♭）带来下属小和弦式感伤忧郁色彩的高级技巧而广受青睐，因此这绝非死板的教条禁令。以上所有内容仅仅是“基本原则”与“行动指南”；然而借助这种规律性的系统梳理，创作视野无疑会变得无比通透澄澈。

3. 代理属和弦与引伸音

依托“三全音代理”机制引入的属和弦，被称为代理属和弦（简称 SubV）。针对这一族群，理论界有一套高度统一贯通的基准指南：默认以选用 9th、+11th、13th 为基本标配[2]。

其中最为精妙绝伦的要害，正是 +11th（♯11th） 这个引伸音。因为 SubV 是通过与相距三全音的根音进行对调而生成的，所以这个 +11th 必定精确对应着反转替换之前的原始和弦根音！借此，代理和弦向听众昭示了自己原本的血统出身，牢牢守住了与原调性之间的隐形纽带。因此在 SubV 中加入 +11th，堪称是一项极其高贵优雅且极度合理的艺术抉择。 此外，构成音中出现的非自然音部分，有时也可以反向替换为调内自然音，最经典的莫过于 ♭II7 中的 E♭ 音：视具体语境，将其还原为 E♮ 往往能与前后和声产生更加无缝的平滑衔接。

极具攻击性的激进引伸音

无论如何，上述指南统统属于“保守基准”，更大胆激进的进攻性选择永远向我们敞开。例如，在 ♭VII7 上尝试叠置 -9th（♭9th）会如何呢？ 其 -9th 是 C♭，即异名同音的 B 音；如果后续的 VI-7 采用九和弦形态，两者恰好能构筑出极度优美的连音线共通延留音（Tie）！

如果仅仅将其视作“B♭与B♮的刺耳碰撞”，会觉得荒诞不经；但若清醒意识到它是 C♭、纯粹作为小九度引伸音发响，一切就显得理所应当。让我们实际试听一下：

IVΔ VIIø ♭VII7(-9) VI–9

听听看，完全成立且惊艳至极！属于小九度特有的凶悍浊色霸道地凌驾其上。永远不要忘记：在偏离教条准则的蛮荒深处，往往沉睡着最迷人新奇的声音宝藏。

为即兴而生的理论法则

在明知存在海量进阶变体的前提下，爵士乐理为何依然不厌其烦地确立第一默认候补？其背后核心驱动力依然源于即兴合奏的文化生态。在没有任何语言交代的真空瞬间，乐手之间能够心照不宣地恪守“若无特殊说明便默认以这套音阶演奏”的默契潜规则，沟通成本将被降至最低。这一实战需求深刻型塑了整套理论的构筑范式。

4. 以根音为轴心的音阶视角转换

正如前述，在爵士实战演奏中，乐手们时刻置身于一种**“1度、3度、（5度、）7度作为骨架牢牢焊死，其余音级剧烈变幻漂移”**的动态高压环境之下：

久而久之，爵士乐手的大脑演化出了一种神乎其技的肌肉直觉：完全脱离调性的羁绊，纯粹以和弦根音为绝对基准点去瞬间洞悉音阶全貌的能力。例如刚才那个“激进的♭9th”绝招，若硬追问它是“从什么调借来的？”，乐手往往懒得推敲；但对于此刻所调用的音阶其内部各音级处于何等音程分布，其脑海中却洞若观火、分毫不差。

随着转调频次越来越高，“此刻究竟身处什么调”愈发变得扑朔迷离，最终留在乐手视野中唯一可供依靠的灯塔，唯有脚下和弦的根音。在这一绝境之下，以根音为原点重构音阶认知的范式革命便成了历史的必然。本章后半部分将要全面展开的“和弦音阶理论（CST）”正是对此的终极大一统总结；但在正式迈入之前，我们不妨先管中窥豹，领略一下这种以根音为轴心的思维有多么神奇迷人。

原始基准演奏

这是一段随处可见的经典爵士进行，第2个和弦是 III7。在这段演奏中，吹奏的是标准的和声小调乐句。现在，我们以 III 为绝对不动锚点，在底层暗中偷换为其他高阶音阶：

变化属音阶（Altered Dominant Scale）

这是在第V章“变化属和弦”中介绍过的利器。通过将5th与9th同时向上下全方位变异，交织出极具现代冷峻质感的音阶。这个音阶绝不是向哪个宏观调性借调的产物；它在大脑中纯粹被归档为：“只要以根音为起点按照这组音程排列展开弹奏，音响就会产生炸裂的酷感”。

实战范例

例如在此视频第199小节处的 A7alt，是体验变化属音阶色彩极其生动的教科书范本。贝斯手率先夯死根音A，钢琴左手在3rd和7th向导音之外叠加了 -13th（♭13th）；右手以分解和弦穿梭，其中在第3拍赫然砸响的 -5th（♭5th）极具标志性。 变化属和弦的核心要义正在于剔除常规自然的9th与5th、将其全盘变音异化；此处的 E♭ 展现出了唯有变化音阶才具备的冷冽锋芒，散发着无比地道的现代爵士毒性魅惑。

在某些前卫爵士曲目中，全曲会充斥着密集的 7Alt；乐手在每一次吹奏时，都在缜密思考该突出哪一个变音引伸音的特质。例如在稍早前的第195小节 Aalt7 中，乐手则重点突出了相当于变音抵消的 +9th。

全音阶（Whole Tone Scale）

这是将其替换为“通篇全音跨步”的全音阶示范。以和弦根音E为起点搭建全音阶，极其精妙地自动构成了G♯与D这对支撑属和弦推进引擎的核心三全音！爵士乐手将这一几何特性牢记在心，将其作为武库中出其不意的“秘密暗器”随时调取。

实战范例

在1:16处的 GΔ 起步，和弦经由 F♯ø → B7 → EΔ 一路穿梭，看似平稳转调至E大调；岂料翻过乐谱之后突然迎面撞上 C7alt，一股犹如魔法咒语般的奇异乐句呼啸倾泻而下！这正是以营造科幻迷离感著称的全音阶在施展神通。 在本曲中除了此处之外，针对 C7alt 多次施加了全音阶。即使具体的Solo旋律是现场即兴生成的，但“在这里我要祭出全音阶”这一宏观战术预案，早在演奏前就已在乐手胸中成竹在胸。

减音阶组合（Combination of Diminished / 属减音阶）

简称为“Condimi（コンディミ）”的音阶（即属减音阶）。若将该音阶的构成音隔一个抽出来看：E - G - B♭ - D♭，这赫然正是减七和弦的和弦音！再看剩下的另外4个音：F - G♯ - B - D，竟然同样是一个完美的减七和弦！

由两组减七和弦交织镶嵌组合而成，这正是其命名的根源。其音程步长也极具几何美感：“半-全-半-全-半-全-半-全”，半音与全音严格交替循环。对于即兴演奏而言，这是肌肉记忆极其友好的对称音阶。更妙的是，它毫厘不差地完整囊括了属七和弦的所有骨干构成音！

实战范例

在第130小节的 G7alt 处，乐手先以全音阶打了个招呼；而翻页来到第136小节再次遭遇 G7alt 时，乐手突然以暴风骤雨般的速度顺着音阶自上而下狂泻飞驰！仔细拆解这串令人惊叹的飞速跑动，就会发现其构成音丝毫不差正是纯正的属减音阶（Condimi）！

从尾部逆向回溯极易洞察：针对根音G，乐句落下的最后一个音是高半音的A♭；往上全音跳至B♭；再往上半音跳至C♭（=B）……清晰呈现出“半-全-半-全”的对称几何。 不仅如此，结合前后声部文脉更能读出深意：本例后续解决的目标是呈大调属性的 CΔ，而在以G为根音的属减音阶中，其13th正好是象征大调色彩的纯正E音！相对地，该音阶中完全不含E♭音；从这一声学事实可以看出：属减音阶在向大调和弦解决时，融入得最为浑然天成。 假若后续解决目标是 C-7，乐手在使用属减音阶时就必须有意识地克制避开这个E音，转而全力凸显A♭或B♭以规避调性打架。拿捏这种精微的声学分寸，正是衡量即兴Solo功力深浅的核心试金石。

因此驾驭这些高阶音阶绝非死记硬背构成音那么简单，必须通过对大师实战唱片的深入复盘，参透他们究竟是如何在特定节点激活特定音级的深意。通过将这些风味各异的音阶深植于大脑，爵士乐手得以在瞬息万变的实战中从容打出不同的王牌，享受着极其高妙的艺术博弈。

与“调式互换”的本质区别

就“置换音阶”这一动作而言，它与上一节探讨的“调式互换”看似极为相仿。然而二者存在着本质上的分野：调式互换始终以宏观调性为绑定基准、以整个调性的主音为轴心展开置换；而我们此刻所做的，则是纯粹以当下一瞬的和弦根音为轴心展开的超微观置换。 这种思维彻底特化服务于调性摇摇欲坠的无调性/不定调性环境，完全切断了与宏观调性的脐带，将所有注意力高度聚焦在“那一瞬间”的独立声学空间之上。

在通用乐理界，这种微观音阶替换并不被纳入“调式互换”的语义范畴，甚至根本未被特意命名。或许正是因为对于爵士即兴而言，这种动作早已成为如同呼吸般理所当然的日常本能。 即兴演奏这一深厚文化，催生了在电光石火的“当下瞬间”亮出独门兵刃的思维范式，进而催生出彻底颠覆传统大小调借调框架的崭新方法论体系。洞悉了“不同的音乐形态必然催生出截然不同的音乐理论”，我们在面对纷繁复杂的乐理学派时，心境自能通达豁达、自由无羁。
