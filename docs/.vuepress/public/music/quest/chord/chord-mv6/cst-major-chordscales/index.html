大调和弦音阶

2026.09.05和弦论

首先，我们来复习一下在上一节中介绍的“和弦音阶理论（CST）”的核心概要。

1. 前情回顾

首先，和弦与音阶是打包在一起的同一实体：将底层的音响形象以“纵向连接”表现出来的就是和弦，以“横向连接”表现出来的就是音阶。二者互为彼此存在的象征与暗示。

正如大调在其内部包容了7个自然音阶和弦一样，大调音阶在其内部也包容了7个调式（Modes）。至于这些调式的名称，则直接沿用了“教会调式”概念中所使用的名字。

将每个调式与对应的和弦绑定成套，将引伸音、避用音等全部信息明确展示出来，用“和弦音阶（Chord Scale）”这一个完整的数据包来呈现。

通过这种方式，不仅即兴演奏时的便利性大幅提升，对音响的理解也变得顺畅而清晰，同时还能让人从“调性这一思维枷锁”中解放出来。这就是我们之前所说的内容。

因此，我们本次要做的，就是梳理作为和弦音阶理论应用之最基本基石的大调各自然音阶和弦的“和弦音阶”。在不久前的章节中，我们曾以“爵士理论中以七和弦为基本”等为由罗列过和弦……

在了解了CST的概念之后，大家应该就能明白：仅仅这样，信息量是远远不够的。如果不能将这7个和弦全部像前面的“爱奥尼亚”那样整齐地信息模块化，我们甚至连起跑线都还没有站上。虽说从大调音阶生成和弦与调式早已是耳熟能详的内容，但作为让身体逐渐适应“和弦音阶”思维方式的“热身运动”，这恰好是最合适的内容。

2. 大调各级的和弦音阶

在此再次确认：接下来登场的“爱奥尼亚”、“多利亚”等词汇，在CST中代表的是和弦音阶这一整合数据包。这与旋律篇中探讨的“教会调式”有着相当大的语境差异，因此请大家务必在思维上做好明确切割后再行阅读。

音程的标记法

接下来我们将依次确认各音阶所包含的音程。在此，我们将尽可能采用直观且简洁的级数（Degree）表示法：

  • 大音程·纯音程（完程） → 仅写数字
  • 小音程 → 加 ♭
  • 增音程·减音程 → 加 + / o

第I调式：爱奥尼亚（Ionian）

爱奥尼亚是与大七和弦相对应的调式之一。由于纯四度（P4）与三度音发生碰撞冲突，因而成为和声避用音（Harmonic Avoid）。其声音色彩完全就是大调音阶的世界观本身，也可以说是象征大调“主和弦感（Tonic）”的调式。

第II调式：多利亚（Dorian）

多利亚是与小七和弦相对应的调式之一。其6th之所以成为和声避用音（Harmonic Avoid），理由稍显特殊：从和声角度来看，该音“与3rd构成三全音关系，其声音听起来与V7的转位极其接近，（尤其在ii-V进行中）会对下属和弦功能造成混淆”[1]。 由于其他和声避用音多源自强烈的“小二度不协和”，为了表示其性质不同，此处特意用黄色标记。

在小调系调式中，多利亚色彩较为明亮，是象征爵士乐招牌“Two-Five（二五进行）”中“Two”的代表性调式。

第III调式：弗里几亚（Phrygian）

弗里几亚是与小七和弦相对应的调式之一。小音程较多，具有沉重灰暗的音响色彩。两个避用音都是因为叠置在和弦音上方半音处而导致的。

第IV调式：利底亚（Lydian）

利底亚是与大七和弦相对应的调式之一。它没有任何一处音落在和弦音上方半音的位置，因此完全不存在避用音（Avoid）。正因如此，它也是一个非常容易进行即兴SOLO的调式，常被称作“演奏非主和弦功能的大七和弦时的基本候补音阶”。

第V调式：混合利底亚（Mixolydian）

混合利底亚是与属七和弦相对应的调式之一。在大调音阶各调式中，与属七和弦对应的仅此一个。它是象征V7质感的代表性调式。

第VI调式：爱奥利亚（Aeolian）

爱奥利亚是与小七和弦相对应的调式之一。音调比多利亚暗，但比弗里几亚明亮，属于标准程度的暗色调。它与多利亚的区别在于6度是大音程还是小音程。因此，小六度（minor 6th）所具有的黯淡感正是爱奥利亚的特征。

第VII调式：洛克里亚（Locrian）

洛克里亚是与半减和弦相对应的调式之一。由于5th变成了减五度（o5），与构成了纯五度（P5）的其他调式相比，其稳定性明显低得多。

以上内容虽然大家在学到和弦篇第VI章之前应该都已有所了解，但正如我们反复强调的，这仅仅是起跑线。首先通过这样整理信息，我们重新确认了各音阶的音程构成与属性。
