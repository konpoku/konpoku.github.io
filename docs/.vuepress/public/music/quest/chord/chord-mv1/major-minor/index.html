大和弦与小和弦

2026.09.05和弦论
和弦论和弦论基石与二音和声

上一篇中，我们讲解了调式内的6大主要和弦可以划分为两大类型。

用音程的刻度来衡量，二者的核心差异在于：究竟是按照 [0, 4, 7] 的模式叠置，还是按照 [0, 3, 7] 的模式叠置。本篇中，我们将深入透析这两类和弦的本质区别。

1. 和弦的命名与记谱法

这次我们打破常规，先从它们的正规命名讲起。类型1的和弦被称为大和弦（Major Chord / 大三和弦）；类型2的和弦则被称为小和弦（Minor Chord / 小三和弦）。

这与大调音阶/小调音阶、大调/小调的明暗二元对立完全一脉相承。

和弦名称（Chord Name）

当需要指代具体的某一个和弦时，便借用英文字母音名：

例如“Do-Mi-Sol”和弦，是“以 C 音为起点构建的大和弦”，因此被命名为 C 大和弦（C Major Chord）。同理，“La-Do-Mi”和弦则被称为 A 小和弦（A Minor Chord）。

在大家心知肚明“正在聊和弦”的语境下，直接简称为“C大（C Major）”、“A小（A Minor）”大家也完全能心领神会。这就是和弦的名字，即“和弦名称（Chord Name）”。

和弦代号（Chord Symbol）

然而在五线谱或铅铅笔吉他谱上记录和弦时，每次都要完整写下“Major”、“Minor”实在太繁琐了。于是，一套极其凝练的缩写代号应运而生：

由于大和弦是世间最主流、最具代表性的基石和弦，因此享有霸道特权：“什么后缀都不加”本身就默认代表“大和弦”。这真是一种近乎绝对统治地位的待遇呢。 与此相对，小和弦则取“minor”的首字母，以小写字母“m”来表示。请务必注意：必须是小写“m”，绝对不能写成大写。 像这样高度符号化的和弦简写记号，被称为和弦代号（Chord Symbol）。

记谱代号的方言变体

由于历史流派发展，和弦代号存在着类似“方言”般的各种写法：

最常见的变体主要有以上几种： ① 试图用大写字母“M”与小写“m”形成工整对仗； ② 属于较为严谨客气的写法，多见于较有年代感的古典乐理教材； ③ 则是将符号化贯彻到底的激进记法。

然而，对于原本什么都不用加的大和弦，画蛇添足地加上各种繁冗后缀是极不推荐的。除非在某些极易产生误读的特殊场合不得已为之；而即便如此，最不容易引发歧义的写法也是“maj”。 对于小和弦，“-（减号/连字符）”标记具有“手写飞快”的优点，但同时潜藏着“阅读时极易漏看”的缺点，可谓有利有弊，常被用于爵士乐理专著中。

2. 和弦音（Chord Tone）与声响特质

接下来补充几个至关重要的乐理专业术语：

构成某个和弦的各个音符，直截了当地被称为和弦音 / 构成音（Chord Tone）。 而在“叠丸子（三度叠置）”的最底部、担当整个和弦物理地基的音，被称为根音（Root）[19]。

在根音上方的那个音被称为三音（3rd），再上方的音则被称为五音（5th）。之所以是 3、5 这样跳跃奇数编号，是因为它是以音与音叠置的度数距离作为称呼基准的。在后续内容中，根音、三音、五音将分别简记为 Rt、3rd、5th 进行高亮表示。

我们统一将根音设定在同一高度，对比聆听按 [0, 4, 7] 间距构成的大和弦与按 [0, 3, 7] 间距构成的小和弦：

仅仅是三音（3rd）存在半音之微的差距，整体声响却判若云泥！这一分水岭源自根音（Rt）与三音（3rd）之间的间距究竟是【4个半音】还是【3个半音】。前文“二音和声”一课中实测过的【4半音】与【3半音】的明暗质感差异，直接决定了大和弦与小和弦的情感基调。 而在最顶部的五音（5th），在两种和弦中与根音的距离统统都是【7个半音】。它发出的是开阔纯澈的中性声音，丝毫不干扰三音所确立的明暗情绪，忠实地履行着为和弦增添物理厚度的辅助支撑角色：

因此，由三个音构成的和弦声响，本质上可以看作是二音和声之间互相加权叠加的综合产物。因此，即便未来我们往和弦里继续添加更多的音符，大和弦/小和弦骨子里原本确立的明朗或悲伤质感，基本上是绝不会被彻底抹杀的。

越来越有真正音乐理论的专业范儿了！虽然五线谱上的外表看起来都是整齐划一的丸子串，但基调和弦的本质属性严格按照“大、小、小、大、大、小”的固定顺序排列。 只要熟练驾驭这“两类共6个”核心和弦，就已经完全足够创作出动听美妙的完整歌曲了。而且，虽然单看只有两种简单类型，但依据前后和弦连接语境的不同，听众大脑接收到的情绪折射千变万化，通过不同组合足以营造出令人叹为观止的丰富音乐意境。 在接下来的整个篇章中，我们将全力以赴地深入探索这6大和弦的实战运用奥秘！

总结

  • **大和弦（Major Chord）与小和弦（Minor Chord）**是音乐世界中两类最核心的和弦形态。
  • 构成大/小三和弦的三个音，由低至高依次被称为根音（Root / Rt）、三音（3rd）、五音（5th）。
  • 和弦名称的标准书写格式是“根音音名”紧跟“和弦属性”。
  • 小和弦用小写字母“m”标示；若没有任何后缀，则默认代表大和弦。
