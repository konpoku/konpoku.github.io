1. 和弦篇概要

在这篇具有纪念意义的和弦理论开篇中，我们将简要介绍和弦理论的概貌。为了说明这一点，绪论中介绍的“三个层级”恰好派上用场。

粗略划分的话，音乐理论的内容正是这三种。将和弦理论的内容也划分为这三部分，就能清晰看清它的全貌。

和弦的名称

和弦（Chord），其实指的就是“多个音同时发出的声音”。

和弦 (Chord) : 多个不同音高的音同时发声的声音组合。 : 也有观点认为，至少需要发出“3个以上”不同的音才算和弦。

就像音阶一样，组合方式不同就会产生各式各样的声音效果。

首先要为各种叠加模式建立一套命名系统，使我们能用名字来称呼这些和弦。这就是和弦理论的基石。

正如绪论中所说，通过命名，原本看不见的音就变成了“易于记录和描述的数据”。这是深入理解音乐的巨大一步。

和弦的效果

命名之后，我们便会从各种角度对这些和弦进行“分类”，并阐明它们的声学“效果”。

  • 基础和弦 / 进阶和弦
  • 明亮和弦 / 阴暗和弦
  • 具有安定感的和弦 / 不稳定的和弦
  • 等等……

将和弦与和弦连接起来形成的序列被称为和弦进行（Chord Progression）。和弦越是进阶，其有效的连接方式就越受限。与其自己一点点去摸索，不如“早早掌握这些经典套路，把腾出来的时间用在更有创意的事情上”。

尤其是在本网站中，我们将以实际的热门歌曲为例，带你掌握“在这种地方使用这个和弦，就能获得这样的效果”。

和弦的风格

例如，在J-Pop、EDM、爵士和古典音乐中，所偏好的和弦进行完全不同。这在绪论的对比实验中已经解释过了。

即使现在还没有理论知识，相信你也能感受到两者的风格截然不同。某种流派中的王道手法在另一种流派中根本见不到，某种流派不喜欢的和弦进行在另一种流派中却备受推崇——风格迥异且不强求统一，正是音乐的趣味所在。 了解各个流派所追求的音乐性差异，不仅能按照各流派的传统惯例进行作曲，也能自由地进行跨流派融合。单凭直觉去实现这些不仅困难，而且非常耗时。而和弦理论就是帮你走捷径的工具。

简要概括和弦理论的要点如下：

  • 和弦的名称 为和弦命名，使其变成便于作为数据处理的形式。
  • 和弦的分类与效果 理解各个和弦的作用，学会有效运用它们。学习经典的常用和弦进行，让连接和弦的过程更加轻松。
  • 和弦的风格差异 通过了解各流派间和弦的风格差异，掌握适合该流派的和弦用法，并能够有意识地进行跨流派融合。

而在自由派理论中，这里面没有任何“规则”。即使某件事在古典理论书中被写成“规则”，在自由派看来，它也只是被描述为一种“这样做就会带有古典风味”的“风格”而已。

如果把音乐理论当成“规则的集合体”，会让人感到拘束；但如果把它当作分析并揭示各种音乐风格的探索之旅（Quest），是不是就令人兴奋起来了呢？

2. 第I章的旅程

第I章分为题为“基本体系”的前半部分和“连接理论”的后半部分。学到前半部分最后一篇“性质变换”时，你就基本上能够创作出如下的和弦进行了。

仅仅读完第I章的前半部分，就能掌握如此丰富多样的和弦！之所以说是“基本上”，是因为这里暂未介绍各个和弦的正式名称和详细用法，仅讲解到“通过不同组合也能做出这样的声音”这一阶段。

话虽如此，“万一读完第I章就停下来，岂不是只学了基础、依然被规则束缚”这种担忧，在“自由派”中是完全不存在的。“有兴趣就往前学，学累了就去搞创作”，希望你能这样循环往复，循序渐进，直到你想达到的境界。
