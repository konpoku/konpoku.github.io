小减五度和弦

2026.09.05和弦论
和弦论变异和弦、斜线和弦与转位持续音

这一次是“认识新和弦名称”的一回。 我们将与第I章中略过未讲的VIIm(♭5)，以及第II章中略过的IIm(♭5)和弦重逢，并深入探寻它们的使用方法。

上一讲我们对大和弦的五音进行了升降微调，这一讲自然就轮到了小和弦。

1. 小和弦的 ♯5 与 ♭5

和弦名称的命名规则与上一回如出一辙：五音升高就附加“升五度（♯5）”，降低半音就附加“减五度（♭5）”。

非常直观简单。

在上一次讨论大和弦时，我们提到“升五度（♯5）”更为重要；而在小和弦中，则是“减五度（♭5）”占据着压倒性的重要地位。“小升五度（m(♯5)）”和弦在现实音乐世界中极其罕见，因此在这里略去不谈[12]。

而“小减五度（m(♭5)）”无论在理论上还是实践中都具有非同凡响的意义，因此本次我们将把目光全力聚焦在它身上。

2. 与VII级和弦重逢

小减五度和弦在之前其实曾经匆匆露过一面。那就是以Do-Re-Mi-Fa-Sol-La-Si中的“Si”为根音构成的和弦。

在自由派理论的初期，它是被从基础主干和弦群中排除在外的。如今学到这里，我们终于迎来了与它的重逢。大家现在肯定一目了然：如果要以Si为根音构建常规的小和弦，构成音必须是Si-Re-Fa♯才行。而这个Si-Re-Fa的五音却被降低了半音。因此它正是一个小减五度（Flat Five）和弦。

降五度的结果，使该和弦内蕴了*“Si-Fa”这一三（Tritone）关系*。由于它带有一种不安而怪异的色彩，我们在第I至第II章中暂时跳过了它，但现在正是将它作为绝佳调味品加以运用的成熟阶段了！

第VII级和弦的用法

这个和弦能够大显身手的连接是相当有限的，原则上它绝大多数情况下会走向IIIm或III。

VIIm(♭5) III7 VIm

用五线谱记写如下：

观察根音的走向，和弦连续进行了两次下行五度（纯四度上行）的“强进行”。因此听觉上极具推动力与顺畅感；从小减五度的不稳定张力，衔接到III7饱满昂扬的情感冲劲，最后平稳着陆于VIm——这可以说是一段无可挑剔的黄金展开。这个进行极具牵动听众情绪的感染力，在流行音乐的抒情慢歌（Ballad）中被广泛且高频地使用。

3. 七和弦化

这是所有小减五度和弦的共通特性：如果仅保留三和弦的形态，它的音响会显得极其尖锐不稳定，在编曲上略显单薄难用。因此，通常的做法是将其升级为七和弦来强化整体的厚度与骨架。做法与之前的6个基础和弦完全相同，只要顺着调内音阶再向上叠置一个三度即可。

在和弦名称方面，由于“减五度”被视为附加修饰属性，因此放在最后面，称为“小七减五和弦（Minor Seventh Flat Five，或称半减七和弦）”。除了此前我们熟知的大七、小七、属七之外，无需添加任何临时记号就能直接构成的最后一个自然七和弦，就是这个VIIm7(♭5)。让我们来听听音响上的对比。

首先整体音响变得丰富饱满得多；而且Re-La之间形成了稳固结实的“纯五度”关系，为整个和弦构筑了坚挺的支撑骨架，使得它作为独立和弦的存在感与推动力大幅增强。

在大和弦或小和弦中，质朴纯净的三和弦自有其清澈干净的独特魅力；但对于小减五度和弦而言，七和弦形态占据了压倒性的优势。三和弦形态听起来往往单薄干瘪，因此在流行音乐中，基本可以遵循“若无特殊理由，一律使用七和弦形态（m7(♭5)）”的经验法则。

乐曲中的实际案例

这种“7-3-6”的进行，是直击听众心弦、掀起情绪波澜的强力武器之一，尤其在流行抒情曲（Ballad）中堪称杀手锏。

这些歌曲都属于抒情曲的范畴。在试听片段中，7-3-6出现于以下歌词处：

曲目 VIIm7(♭5) III7 VIm
谢谢（生物股长） (この)道を 確かめて行 くように
青春的瞬间（椎名林檎） (止ま)れ 何一つ変わ って
花水木（一青窈） (止ま)りま すよう に
Baby I Love You（TEE） I love U これからも Only one

这确实是一段极其擅长抒发强烈情感的进行。从声学上看，VIIm7(♭5)与III7都各自包含三全音，属于极具紧张张力的不稳定声响，而这两者接踵而至；与此同时，低音线条连续完成两次孔武有力的“强进行”。从这些维度来看，该进行在理论上拥有极其强悍的“情绪震撼力”。

若在“6个基础和弦”中加入这个第VII级和弦，传统乐理中所说的“自然音阶和弦（Diatonic Chords）”家族便宣告集结完毕。然而考虑到它内含与其他成员截然不同的不稳定音程，且由此导致其后续去向受到严格限制，我们依然应当清晰地认识到它所处的特殊定位。

3. 与VII7重逢

在第II章中我们介绍了“副属和弦（Secondary Dominant）”。它们是作为各个基础和弦专属“搭档”而存在的和弦。

IIIm和弦其实也有自己的副属和弦搭档VII7，只是因为它是第VII级和弦，我们在前面为了减轻负担而暂时隐去了。在此我们不妨顺便把它也消化掌握。

VII7和弦通常不是走向普通的IIIm，而是习惯性地走向III或III7，这是古典小调中极其经典的范式之一。

VIm IIm VIIm(♭5) III VIm

首先作为对比，上面是使用常规VIIm(♭5)和弦的进行。若将其替换为VII7……

VIm IIm VII7 III VIm

瞧，一段散发着典雅高贵气息的古典进行跃然纸上。虽然在现代流行乐中出现频率不算太高，但在需要营造纯正古典风味时却极其好用。个人感觉它自带一种“吸血鬼德古拉所居住的古典古堡公馆”般的神秘典雅气质。

在《空有愿望》（AKB48）与《Jobairo》（色情涂鸦）中，都使用了“VIm—VII7—III—VIm”这一充满浓烈古典小调韵味的经典进行。 这两首歌是否都隐隐流露出一种古风典雅的质感呢？其核心秘密正是引入了现代流行乐中较少见的古典式VII7和弦。

而在《Blackout》（ASIAN KUNG-FU GENERATION）中，VII7则是作为强烈的重音点缀出现，在最后唱到“しなやか”的地方惊艳亮相。

3. 其他根音上的经典用法

除了VII级，在其他根音上也有小七减五和弦能够大放异彩的经典模式。以下为你介绍剩下的3种经典范式。

IIm7(♭5) : 类似于IVm的深情哀愁

在“同主音小调（借用和弦）”那一章中，曾出现过一个IIm(♭5)和弦。

如今我们在此再次重逢。重新审视它的和弦音，原本的La♮变成了La♭，因此它的音乐性格与IVm非常接近，能够产生深切的悲伤与哀愁感。就像IVm可以替换IV登场一样，IIm(♭5)也可以直接替换原本使用IIm的位置。

IVΔ7 IIIm7 IIm7 V7 I

IVΔ7 IIIm7 IIm7(♭5) V7 I

上面是一段常规的4-3-2-5-1进行。而下面则将IIm7替换成了IIm7(♭5)。La♭所特有的凄楚哀愁色彩瞬间注入到了音乐之中。

IIIm7(♭5) : 更加深沉内敛的情绪陷落

VIIm7(♭5)是依附在副属和弦王牌III7前方、起到强化一连串情绪推进的存在。同理，**在VI7前方配置IIIm7(♭5)**也是一种极其经典的定式。

与常规的Mi-Sol-Si-Re相比，因为Si带上了降号（Si♭），带来了一种瞬间深陷沉郁、更加浓郁哀婉的情感波澜。将其套入经典的4-5-3-6系进行中，就能轻松驾驭。

IIm7 V7 IIIm7(♭5) VI7 IIm7 IVm I

听听看！当进入第三个和弦时，整段音乐的情感骤然变得深邃而揪心。这种极具张力的情感色彩，只有小七减五和弦才能淋漓尽致地呈现出来。如果换成我们早已熟悉的常规III7，又会是怎样一番景象呢？

IIm7 V7 III7 VI7 IIm7 IVm I

由于III7属于升号系的变化音，带有明显的“情绪高昂挺拔”之感，与IIIm7(♭5)所带来的下沉幽深意境截然相反。根据你想要表达的情绪底色，在这两者之间灵活选用即可。

这是一个实际的经典应用案例。在唱到“君だけが今では”这句的地方，IIIm7(♭5)赫然出现。浪漫深情，直击内心。完全可以将其作为抒情慢歌中的“必杀技”珍藏在武器库中。

♯IVm7(♭5) : 悬浮空灵与强烈的情绪涟漪

最后要介绍的是♯IVm7(♭5)。由于根音自带临时升号，向邻近的IV下行或者向V上行是它的经典骨架走向。

♯IVm7(♭5) IV IIIm7 VIm

从构成音来看，只要将IVΔ7的根音轻轻抬高半音，就构成了这个和弦。因此♯IVm7(♭5)→IVΔ7的线条移动中，根音仅仅平滑地下行了半音，带来了一种悬浮飘扬的情感瞬间归于沉静的独特听觉美感。

在AKB48的10周年纪念单曲《你是旋律（君はメロディー）》中，这个和弦大放异彩。在前奏开门见山的第一小节，和弦进行就是：♯IVm7(♭5)—IV—IIIm7—VI7！从最开端就肆无忌惮地释放着这个和弦撼动人心的魔力。

不仅如此，在歌曲4:10和4:27乐段转换的关键节点，首拍同样使用了♯IVm7(♭5)。由于副歌此前一直稳定在4-5-3-6进行中，听众按心理预期理应听到平稳的IV，此时突如其来的半音颠覆带来了极具冲击力的惊喜。

像这样，第一遍循规蹈矩地走4-5-3-6王道进行，到了第二遍将开头的4-5调包成♯IVm7(♭5)—IV，也是极富声誉的经典作曲技法。

这首在“同主音小调”一章中也曾提及。副歌以IVΔ7—IVmΔ7—IIIm7—♭III进行开篇，但在第二段循环时，开头的两个和弦被替换为了♯IVm7(♭5)—IVΔ7。

第一遍中第二个和弦IVmΔ7是调外和弦，以La♭的凄美为核心；而第二遍中开头的和弦是调外和弦，以Fa♯带来的挺拔与情感飞扬为亮点。虽然主旋律完全相同，通过和弦的巧妙重配却创造出了层次分明的丰富变化。

无论哪种用法，都强烈建议在七和弦形态（保留充沛厚度）下使用。

正如我们所看到的，小七减五和弦（m7(♭5)）特别是在以VII、II、III、♯IV为根音时，能发挥出非同寻常的威力。这一讲的内容可谓收获颇丰！

总结

  • 将小和弦的五音降低半音，即可得到“小减五度和弦”。
  • 内部含有三全音是其最显著的特征，音响具有极强的不稳定性。
  • 为了弥补三和弦形态下声音的单薄，音乐实践中极为常用其七和弦形态——“小七减五和弦（半减七和弦）”。
  • 哪怕不借助任何临时记号，从自然音阶的VII级音向上三度叠置，就会天然构成这一和弦。
  • 除VII级外，以II、III、♯IV为根音的形态也是历经考验的经典配器定式。
