减七和弦

这一回是“认识新和弦名称”的章节。

我们将学习带有特殊名称的新和弦。它具有独特的构成音与声响，虽然适用的场景有限，但具备很多有趣的特征，在音乐理论上具有极高的重要性。

1. 减七和弦

在第II章的副属和弦篇中，我们提到属七和弦（Dominant Seventh）的关键就在于它拥有[6个]的音程——“三（Tritone）”。

这种音响极度不稳定，而在后续和弦中将其解决，就成了畅快干脆的经典进行模式。 另一方面，三全音之外剩下的那两个音，则是我们早已熟悉、负责起骨架加固作用、听感“无色透明”的“纯五度”。

可以说，属七和弦是一个攻守兼备、平衡感极其优秀和弦。它同时兼顾了恰到好处的稳定感与不稳定感。

攻击性拉满的和弦

如果在此时把Sol音升高半音，原本“无色透明”的“纯五度”就会变成又一个“三全音”。

整张图瞬间变红了。由于同时产生了双重强烈的浑浊感，这就好比汉堡变成了巨无霸……不，简直变成了“纯肉无面包”的状态。这种攻击性拉满的和弦品质，就称为减七和弦（Diminished Seventh）[38]。

和弦记号写为“dim7”。这就是我们本次要讲解的和弦。

2. dim7的特征

dim7除了“坐拥两对三全音”之外，还拥有非常独特的构造。

等音程性

首先，减七和弦所有的构成音都是等间距排列的。

相邻两音之间都是相隔[3个半音]（小三度）。顶部的Fa与根音Sol♯之间，除去八度差异后也是[3个半音]。换句话说，以[12个半音]为一圈的八度螺旋，被dim7整整齐齐地四等分了。

将半音阶连成一个循环圈，就会勾勒出一个美丽的十字架图形。

对称性

这种等间距排列引出了一个更有趣的现象。例如，如果我们不用G♯，而是以B为根音去构建一个减七和弦，结果召集来的依然是原班人马。

仅仅是换了谁来当队长，成员面孔完全是一模一样的。这是因为把12音环等间距切分才会出现的奇妙现象。也就是说，G♯dim7、Bdim7、Ddim7、Fdim7的所有和弦音组成完全一致[39]。

因此，将减七和弦理解为“4个音组成一个家族（Family）”，可能会更容易理解。

3个家族

键盘上一共有12个音，每4个音组成1个家族，那么总共就能形成3个家族。具体如下：

C-E♭-G♭-A 家族

C♯-E-G-B♭ 家族

D-F-G♯-B 家族

利用这种“构成音完全相同”的性质来进行转调，也是一种经典的技巧[40]。它真是一个充满了趣味特性的和弦。

3. dim7的运用方法

dim7是一个个性极强的和弦，因此在很大程度上，我们需要通过背诵“在何种情况下以何种形式使用”的经典模式来掌握它。

恐怖悬疑风格的运用

第一种用法，是利用它双重三全音的浑浊音响，脱离大调/小调的常规世界，营造出恐怖悬疑的氛围。

G♯dim7 B♭dim7 Adim7 Bdim7

就像这样，仅仅将dim7连续串联起来，就能自然而然地营造出浓郁的恐怖悬疑BGM感。在游戏音乐或影视配乐中具有很高的实用价值。

这一段则是在古典式的小调世界中间插入了一段dim7区域。因为它的浑浊度比属七和弦还要更上一层楼，掌握之后将成为极具杀伤力的武器。

流行音乐中的运用

在上面的钢琴曲中也是如此，在减七和弦后面接上半音上方的大/小和弦是最经典的套路，能够顺畅地化解不协和感，利落地过渡到下一个和弦。在流行音乐中，尤其是在VIm前面放置♯Vdim7是最常见的定式。

IVΔ7 V7 ♯Vdim7 VIm7

它发挥着类似于副属和弦III7的作用，而且旋律也更容易搭配。像这种适合流行乐的dim7用法还有好几种模式，我们将在第IV章进一步介绍。

辅助减和弦（Auxiliary Diminished）

此外在爵士乐语境中，用Vdim7来代替V7也是常见手法。

VIm7 IIm7 Vdim7 IΔ7

原本不稳定的音响，在此恰到好处地升华为一种时髦现代的质感。同样地，将IΔ7和弦做成Idim7→IΔ7的形式，像sus4那样注入“紧张→释放”的调味剂也很棒。

IIm7 V7 Idim7 IΔ7

原本以为通过II-V之后会顺理成章地解决，却被一个奇妙的和弦把解决推迟了。这种反差带来了一种意想不到的趣味。在声乐曲中可能会有些难以搭配旋律，但如果是器乐曲，就可以毫无阻碍地随心插入。 这种减和弦的用法，因其具有“辅助性”的意味，被称为辅助减七和弦（Auxiliary Diminished Seventh）[41]。

在第III章中，我们介绍了形形色色犹如“秘密武器”般的奇特和弦，而在怪异与扭曲程度上堪称王者的，正是这个减七和弦。

音程构成

最后我们来仔细确认一下它的音程构成。减七和弦与小七减五和弦（半减七和弦）之间只差了一个音。

像这样，以小七和弦为基准，关联记忆“降5音、降7音”，或许会更容易记住。

减七度

“Si - La♭”这两个音之间的距离，比平时“Si - La”构成的小七度还要再窄一个半音，因此被称为减七度。“比‘小’还要窄的音程，就叫作‘减’”，这是我们在第III章开头介绍过的知识。

根音、小三度、减五度、减七度，就是dim7的和弦构成音。不知不觉中，我们已经学到了相当高阶的内容！

总结

  • 将m7(♭5)的第七音再降低半音得到的和弦称为“减七和弦（dim7）”。
  • 减七和弦具有极度不稳定的音响，在恐怖悬疑类BGM等场景中大显身手。
  • 将原本应该出现I或V的地方品质改变为dim7的用法，称为辅助减和弦。
