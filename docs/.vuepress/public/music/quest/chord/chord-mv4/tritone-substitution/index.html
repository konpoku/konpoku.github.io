三全音替代（Tritone Substitution）

2026.09.05和弦论
和弦论流行乐转调技法与引申和弦

这一期是“掌握全新调外和弦”的一讲。

久违地，我们要再次拓宽和弦武器库的疆界了。这是一个虽然使用场景相对特定、却极富辨识度的独特和弦，是定义爵士乐标志性色彩的和弦之一。在想要营造爵士风情时，它将成为你的得力利器。

1. 属解决（Dominant Resolution）

属七和弦拥有一种非同寻常的推动力。V7和弦与I或VIm和弦之间有着极其强韧的牵引连接，若去探究这股磅礴力量的底层源泉，便会发现其中隐藏着“紧张与解决”的极致结构之美。

V7和弦所蕴含的张力非同小可：首先，Si是强烈导向Do的强倾向音；其次，Fa也是强烈导向Mi的强倾向音。而Fa与Si这两个音的组合本身，便构成了极度刺耳浑浊的“三（Tritone）”音程。不仅如此，V和弦本身作为属功能和弦，本能地渴望着向主和弦解决。因此在V7和弦中，这种尖锐的音程冲突与强烈的调性倾向性相互交织叠加并无限放大，使整体处于一种剑拔弩张的极度紧张状态[1]。当这股紧绷的张力随着迈入下一个和弦而瞬间烟消云散时，便在听者心中激荡起无与伦比的释怀快感。

尤其在“V7 → I”的进行中，贝斯低音也同时完成了动力澎湃的“纯四度上行（或纯五度下行）”，堪称完美诠释“紧张与解决”的典范动作。这种由V7迈向I的运动，被称为属解决（Dominant Resolution）[2]。

特别是在爵士乐理论中，属解决是整个理论大厦展开的核心起点，由此衍生出了一系列叹为观止的高级技法。在本文中，我们就将介绍其中最具代表性的杀招——“三全音替代”。

2. 三全音替代

归根结底，支撑属解决庞大能量的核心支柱，正是Fa与Si这两个音。于是音乐家们便思考：如果存在另一个同样拥有‘Fa与Si’的和弦，是否就能完美替代V7的职能呢？ 经过层层筛选，最终脱颖而出、被委以重任的，正是根音位置发生大腾挪的♭II7和弦。

♭II7和弦的组成音为Re♭–Fa–La♭–Si，极其完美地包含了Fa与Si[3]。不仅和弦品质同样是如假包换的属七和弦（Dominant 7th），而且其根音恰好位于目标I级和弦的上方，滑向I级简直顺风顺水。作为替代者，它堪称天造地设的“不二人选”。

更绝妙的是，根音由Sol被替换为了Re♭——而‘Sol与Re♭’之间恰恰也是相隔三全音的关系！相隔三全音遥遥相望的两个属七和弦，竟然共享着同一个“Fa与Si”构成的三全音核心。这不得不让人惊叹于和声体系中深藏的数理对称之美。

这种替代技法被称为三全音替代（Tritone Substitution），而由此引出的♭II7和弦则被称为替代属和弦（Substituted Dominant）。

三全音替代 (Tritone Substitution) : 将某个属七和弦，替换为与其根音相隔三全音（/减五度）的另一个属七和弦的技法。

替代属和弦 (Substituted Dominant) : 基于“三全音替代”原理引入的调外属七和弦。 : 在进阶理论中，除♭II7之外还会衍生出更多级别的替代属和弦。

在爵士乐谱中，替代属和弦通常被标记为“subV”（sub即Substituted的缩写，V代表属和弦）。请千万不要将这里的“sub”与下属和弦（Subdominant）中的“sub”混为一谈。

3. 聆听替代属和弦的实际音效

我们通过实际构建和弦进行来对比聆听：

VIm7 IIm7 V7 IΔ7

这是经典的爵士6-2-5-1进行。在V7处迎来了身心舒畅的标准属解决。如果在此施加三全音替代，换上♭II7和弦……

VIm7 IIm7 ♭II7 IΔ7

声音就变成了这样！听觉上散发出更为浓郁洗练的纯正爵士风味，气质焕然一新。这就是替代属和弦的声音魔力。由于它带有极其特殊的张力与半音下行滑动的冲力，其后续进行去向基本上专属于I级主和弦。

音阶的选择

由于♭II7的组成音与原调大相径庭，在旋律配器时该选用何种音阶难免令人费解。这与同主音小调借用和弦类似，取决于你希望保留多少原调底色、以及渴望制造多大幅度的异域反差。

降号偏多的演奏

若在旋律中大肆混入Mi、Sol、Si的降号音，就会营造出一种迷失在另一个遥远陌生调性中的浓烈离调感[4]。

听起来几乎彻底脱离了C大调的引力轨道。为了让它与C大调保持若即若离的羁绊，通常建议Sol音不要加降号。

降号较少的演奏

反之，若在演奏中让Mi、Sol、Si完全保持自然还原状态，其质感就会与原本的V7更为贴合，从而呈现出一种完全不破坏调性骨架的优雅演奏。甚至在极端情况下，哪怕连Re与La都直接弹奏自然还原音，也是完全可行的。

Mi与Sol的还原毫无破绽；而把Re与La也做还原处理，虽然会与和弦本身的Re♭、La♭产生刺刀见红的激烈半音碰撞，在传统死板的教科书理论上属于违规操作。

但正如大家亲耳所听，这种碰撞反而别有一番前卫现代的时髦感！伴奏声部与旋律声部的音阶彼此分离各行其道却能碰撞出奇异妙味，正如我们在旋律篇探讨过的“布鲁斯音符（Blue Note）”一样，具有打破常规的独特艺术价值。

4. ♭II7的品质改变（大七和弦化）

由于♭II7所携带的爵士风味过于醇厚浓烈，“紧张与解决”的戏剧性过于露骨，有时在某些曲风中会让人觉得略显刺眼喧闹。作为一种更加温和内敛的平替方案，业界演化出了将其品质改变为大七和弦（Major 7th）的形态。

它退去了传统爵士的烟熏感，转而散发出一股空灵梦幻、醇厚温润（Mellow）的奇妙色彩，适用面瞬间变得极其宽广！我们试着将其引入流行音乐语境中：

IVΔ7 IIIm7 IIm7 ♭IIΔ7 IΔ7

在4-3-2-1进行的末端，巧妙嵌入了♭IIΔ7。这在许多经典流行歌曲的尾奏（Outro）中极其多见。

实际范例

这首歌曲（《探险队》主题风格）主歌极为罕见地采用了“IIm7– ♭IIΔ7– IΔ7– V”的和弦架构。由于抹去了Fa与Si的三全音，它没有刺耳的浑浊与剑拔弩张的紧张，取而代之的是大七和弦独有的流光溢彩与诗意。这种如梦如幻的奇幻氛围，与“探险队”的主题形成了绝妙共振。

需要明确的是，由于♭IIΔ7抽掉了Fa与Si的三全音骨架，严格从定义上讲它并不属于“替代属和弦”。但鉴于它同样能在IIm与I之间承担极其丝滑的半音下行过渡桥梁，将二者成对打包记忆是最聪明的做法[5]。

5. “里和弦”（背面和弦）

在当代日本音乐界，这个“替代属和弦”通常被通俗地冠以“裏コード（里和弦 / 背面和弦）”的称谓。这一名称源于：在上审视时，Sol与Re♭恰好处于正对着的圆心正背面极端位置。

把根音直接翻转到五度圈的背面，故名“背面和弦”。这个名字摆脱了学院派的晦涩，极具直观形象的通俗魅力。在日本本土流行乐坛，这个俗称的普及度甚至远超“替代属和弦”与“三全音替代”。

三全音替代的无限延展

本讲我们仅以V7为靶向示范了三全音替代；而事实上，在现代高级和声中，只要是属七和弦（包括各类副属和弦），无一例外均可实施三全音替代！这在高级爵士乐编配中是一项无处不在的看家本领，关于这套更加恢弘进阶的三全音替代宇宙，我们将在第VI章的爵士理论篇中全面揭晓。

总结

  • 作为V7和弦的绝妙替代，可以使用♭II7和弦。在通俗术语中常被形象地称为“里和弦 / 背面和弦”。
  • 对其进行品质改变得到的大七和弦♭IIΔ7，同样可以在完全相同的半音顺滑语境中大放异彩。
  • 这项技法与构想本身的正式学术名称为“三全音替代（Tritone Substitution）”，国际通用学名为“Substituted Dominant（subV）”。
