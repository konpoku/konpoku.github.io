1. 学习转调的前提

自然平滑的转调与突兀剧烈的转调

根据用音细节的微小差异，转调既可以是极其自然平滑的，也可以是剧烈突兀的。要顺畅自然地过渡到远关系调，确实需要一定的理论技巧；然而，“自然平滑的转调 ＝ 最好”并不成立。特意打破音乐的连续流动，或者故意制造出一段调性暧昧不明的悬疑时刻，同样是极具魅力的音乐表现手法。在接下来的文章中，我们主要探讨“如何实现平滑自然的转调”，但请务必记住，平滑绝非“唯一正确的转调法则”。

成对记忆

在深入研习具体的转调技法时，强烈建议大家将上行与下行成对记忆。掌握向上转调的同时，也把向下半音转调作为一对来共同理解。 这是因为，如果歌曲在“主歌 → 副歌”处发生了转调，那么在下一段主歌到来之前，通常必须重返原本的调。否则，就会出现第1段A段与第2段A段处于不同调的突兀情形。除了“在歌曲最后一段副歌转调并直接收尾”的模式外，我们必须妥善备好重返原调的手段。 因此，分析一首歌的转调手法时，一定要连带分析它是如何回归原调的。将“上行”与“下行”捆绑成对来掌握，这是我们接下来讲解的一贯原则。

2. 向上半音转调

首先从流行音乐中最具代表性的转调手法——向上半音转调开始。

向上半音转调是J-Pop中的黄金定式，尤其在最后一曲副歌进入前具有标志性地位。相比第1段和第2段，在最后唯独将副歌升高半音演唱，能带来直击人心的情绪高潮。同时，它还能翻新声音质感，给听觉注入新鲜刺激。在向上半音转调中，音阶的所有成员几乎被彻底洗牌替换，必然会带来极具冲击力的新鲜感。我们先通过实际曲例来感受其效果。

在唱完“心であれたら”（若能拥有这般心境）之后，立刻在其上半音处插入了“Ah-”的伴唱哼鸣，这正是转调的瞬间。原先的D♭调在此跃升为了D调。

在本系列文章中介绍的所有曲目均为4/4拍，因此拍号在此便予省略[1]。

在进行“向上半音转调”时，最经典的做法正是如上例所示，以V级和弦为跳板，走“从转调前的V级直接滑向转调后的V级”的路线。由于此时和弦处于极不稳定的张力状态（属功能），因而极易顺势撬动调性的位移。 基本上，只要在转入新调后，扎实稳固地演奏像“Vsus4– V– I”或“IIm– V– I”这样强有力的和弦进行来确立新调的中心音，那么即便“入口处（切换瞬间）”略显突兀，也会被听众作为极佳的“紧张与解决”全盘接纳。

以III7为跳板的模式

这是在常规的主歌 → 副歌切换中进行向上半音转调的范例。在“转入”上半音时，同样是借由属和弦，但这里选用的是副属和弦III7。

从带有5个升号的B调直接滑入毫无升降号的C调。像这样只要意识到把属和弦直接平行滑动即可，转调听起来是不是就变得易如反掌了？

如何从向上半音转调中回归？

与《HANABI》不同，这首歌在进入第2段A段前必须平稳返回初始的原调。回归的最佳契机就在间奏。因为间奏没有歌词演唱，哪怕把和弦编排得复杂一些也不会干扰人声，因而是实施二次转调的绝佳温床。正因如此，在间奏后半段插入能顺滑连接新调的和弦、从而回归原调，便成了回归的经典定式。

这是在即将进入第2段A段前夕的和弦进行。在过渡处，特意插入了一个既不完全属于C调也不完全属于B调的F♯m7和弦。随后接续F♯sus4，在没有直接鸣响纯正F♯大三和弦的情况下平稳着陆到B和弦。这大概是因为A♯音对C调而言过于刺耳突兀，通过避免让其过早暴露，从而有效缓冲了变化的剧烈感。在接缝处只确定了F和C的升号，在最终需要挂上5个升号的目标调中，克制地只先引入前两个。将转调打造成如渐变色般细腻平缓的过渡，这堪称极其高超的匠心。

当然，若不做如此缜密的考量，仅仅直接弹奏转调后的Vsus4 → V，同样能够相当自然地回归主调。从审美倾向上看，典雅温婉的J-Pop更偏爱不着痕迹的平顺转调；而在摇滚或热血华丽的动画歌曲（Anime Song）中，略显粗犷狂野的生硬碰撞反而会被视作极具张力的亮点。在实操中，唯有依靠亲身摸索与推敲，才能逐步建立起对平衡感的精妙把控。

3. 向下半音转调

与向上半音转调成对的，便是向下半音转调。在坐标系中观察，其运动轨迹自然呈现为与前者完全对称的镜像。

由于“向下转调”通常会给歌曲带来沉静、放松感，往消极了说就是情绪下沉（Tone down），因此除了作为从向上半音转调中复位回归的手段之外，在副歌处主动向下半音转调的歌曲在市面上极为少见。

这就是极其罕见的在“主歌 → 副歌”处实施向下半音转调的特例。同样是在长延长的V和弦之后，于其下方半音处演奏“V–I”落地并确立调性。

实际上在D和弦处，巧妙融合了Dsus4与D的乐句织体，进一步增强了向G和弦解决的倾向力。

副歌向下转调的深层动机

之所以转调，最显而易见的动机固然是追求“声响色彩的蜕变”，但这并不能充分解释为何偏偏选择“向下”。另一个极关键的隐性动因，在于音域与Kernel（音核）功能的关联性。 在这首歌中，B段与副歌都唱到了全曲的最高音C，但由于调性发生了转变，该C音在各自调内的角色定位——亦即Kernel属性，发生了本质颠覆。

如上所示，在B段中，C音是首调唱名中的Mi，属于极其稳定的音；而在副歌中，C音在首调中变成了Fa，化身为我们熟悉的强倾向音。 这在流行人声创作中是至关重要的权衡：人类声带的有效演唱音域非常狭窄，半音之差其发声质感与肌肉发力就可能天差地别，真假音的取舍也是重大课题。有时歌手的生理极限决定了最高音无论如何不能再往上挪了。遇到这种情况，通过巧妙运用转调，我们就能在“固定的人声音域枷锁”之内，为相同的物理极限音符“换装”赋予全然不同的Kernel功能张力。

如何从向下半音转调中回归？

转调切入的方式固然重要，回归的艺术同样不可小觑。在《世界上只有爱》中，它是如何重返主调的呢？我们分析一下间奏结尾的和弦走向。

要回归就必须向上半音转调，但这里并没有采用像《HANABI》那样“原调V → 新调V”的粗暴冲刺。那种方式带有极其露骨的煽动情绪效果，用在副歌回落到主歌的转折点显然格格不入。 作曲者在此特意使用了经过品质改变的大VI级和弦E，并由此下行滑落至E♭——调性明明整体上升了，听觉上却巧妙地植入了一种“下沉回落”的错觉。令人叹为观止的匠心！😇

因此，从某个调迁徙至另一个调，绝不存在唯一僵化的死法。能否在具体的情境中精准拿捏，取决于是否能契合当前的音乐语境。这正是和声的深邃迷人之处。

半音上下转调的共通底色

无论是上半音还是下半音转调，两者最大的共同特征是调号变化幅度极大。向上半音转调对应调号-5，向下半音转调对应调号+5。即便没有绝对音感的普通听众，在转调发生后的很长一段时间里，也能直观感知到旋律与和声中出现了截然不同的频段，从而收获极强的新鲜感。由于音阶成员大换血，在转入新调时，依托新调的V级和弦，或者更加考究地铺垫Vsus4–V等声部动线来引导入新调，是立足之本。只要牢记这些要领，半音转调就能在你的手中运用自如了。

总结

  • 半音上下转调是调号跨越±5的深度转调，因此能带来戏剧性、颠覆性的音响色彩刷新。
  • 鉴于音阶成员被彻底更替，在转入或退出时借助V级和弦搭建导向新调的动线是最典型的范式。
  • 决定转调听感的，不仅在于“从哪调到了哪调”的终点坐标，更取决于达成该位移的过程细节。和弦根音的步法以及调号变化是以何种节奏次序渗透完成的，都是决定成败的关键变数。
