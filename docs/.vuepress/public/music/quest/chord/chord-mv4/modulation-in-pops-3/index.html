流行音乐转调技法 ❸ 全音转调

1. 向上全音转调

与上一篇介绍的向上转调具有相近效果的，便是“向上转调”。

其纵轴与横轴的位移均为相对克制的+2，且调内基础和弦（在三和弦范畴内）仍有两个保留共用，因此其特点是不像半音转调那样露骨夸张。

在半音转调中不曾存在的“转调前后的共通性”，在此成为了一大核心亮点。

全音转调非常讲究前后“动线的顺畅感”，建议大家从B段开头仔细聆听。乃木坂46的《再见的意义》（サヨナラの意味）切入转调的手法极具乐理智慧：首先在副歌前夕唱到“（不可替代的）足迹”处，引入了属于调外和弦的VIsus4 → VI进行。

这是和弦品质改变（Quality Change）技法，通过“意料之外的明朗色彩”，为乐曲注入了“仿佛透入一缕希望”的情感底色。在此处，通过将这个大VI级和弦“重新解读”为新调的V级和弦，自然平顺地完成了转调。

原来如此！这种“重新解读（Reinterpretation）”的技巧，对于实现丝滑无缝的转调至关重要。当听众刚听到C和弦的瞬间，心理感受到的自然是原调大VI级特有的质感；然而紧接着听到它接续向F大和弦时，大脑便会恍然大悟：“咦？刚才的C–F难道其实是新调的V–I解决吗？咦？”，仿佛被巧妙地施加了障眼法。等回过神来，转调早已尘埃落定。 因此，有些听众甚至可能只会隐约觉得音乐变亮了，却根本意识不到“这其实是转调”。这就是良好意义上的不着痕迹。

枢纽和弦（Pivot Chord）

换个角度看，这里的Csus4–C和弦，甚至可以解释为在这一瞬间已经完成转调了。无论将其视作转调前的VI级，还是转调后的V级，逻辑都极其顺畅通达。也就是说，这里正是两个调彼此交织重叠的地带。像这样“能够同时从转调前后的两个调性进行双重合理解读、因而成为转调极佳接缝衔接的和弦”，被称为枢纽和弦（Pivot Chord / 中介和弦）[1]。

利用枢纽和弦实现的转调称为枢纽和弦转调（Pivotal Modulation / 共有和弦转调）。 充当枢纽的节点，就像咸淡水交汇的入海口一样，是两股调性潮水交融的地带。借助枢纽和弦能达成浑然一体的顺畅转调；反之，若完全舍弃枢纽和弦，则能制造出突如其来的骤变反差。

用旋律引导至新调

《再见的意义》在旋律编织上也暗藏玄机。进入C和弦的那一刻，原本E音的降号虽已被拿掉，但要彻底过渡到F大调，还需要化解另一个阻碍——A音的降号。

所谓“化解降号”，就是“通过发出A♮还原音，冲刷掉听众脑海中残留的A♭印象”。而作曲家是在哪个节点完成这一步的呢？实际上在F和弦正式奏响之前，早在伴奏停留在C和弦时的旋律线里，就已经提前抛出了A♮音！

换言之，作曲家并没有等到副歌小节的第一拍强拍，而是提前了半拍挑明了F调的身份。如此一来，听众在踏入副歌强拍的刹那便不会产生丝毫“咦？”的违和感，副歌得以行云流水般舒展绽放。在如此微小的细节处，处处流淌着职业作曲家的深厚功底。

如何从向上全音转调中回归？

这首歌同样是在主歌 → 副歌处转调，因此在下一段主歌到来前必须重返主调。《再见的意义》全曲没有单独的间奏段落，于是它利用副歌收尾处的“余韵”时隙，通过向下全音回落的进行重返原调。

显而易见，这里极其简洁直接：通过演奏回归目标调的“IV– V– I”经典进行，以所有人耳目昭彰的形式明确宣告回归。A♭–B♭进行在回归前的F调中相当于♭III和IV级，前者属于大家耳熟能详的同主音小调借用（Parallel Minor），而后者则是极其标准的枢纽和弦。

2. 向上全音 + R转调

向上全音转调是调号+2的转调。以C大调为例即通往D大调。然而所谓“调号+2”，除了明媚的D大调之外，也可以选择走向它的“关系小调（Relative）”——B小调。

操作方法非常简单：只需将前述“把VI重新解读为V之后接V–I”的套路，顺理成章地换成接V–VIm即可。

这就是生动的实战范例。在《创圣的大天使》（創聖のアクエリオン）中，从“不要受伤，我的翅膀”开始的副歌前夕过渡段，大量运用了斜杠和弦构建出幽深玄妙的听感。我们来分析一下它是如何转调的。

起初的♭VI与♭VII与其说是直接服务于转调，不如说是在助跑蓄力，预告“马上要有宏大的事情发生了”。而在转调发生的刹那，正是套用了前述“将原调的VI重新解读为新调的V”的手法。连续使用sus4和弦的设计，则进一步加深了调性的虚实莫测。

如何从“全音上+R转调”中回归？

至于如何从此处“回归”原调：在副歌结束后的间奏中，极其干净利落地从B大和弦滑向Bm，再顺势将该Bm“重新解读”为原调的VIm，从而重返故调。

此处是在间奏中途完成复位，在编曲上也从转调瞬间直接切入伴唱哼鸣，其思路并非追求毫无痕迹的自然过渡，而是有意将空气骤然切换的戏剧感作为视听特效来放大。不同于上一讲的半音转调，全音转调在调内基础和弦中存在天然的重叠交集。正因如此，“枢纽和弦”这一技术才有了大显身手的舞台。根据构思意图，转调既可做得丝滑入微，亦可雕琢得波澜壮阔，掌握这一点大有裨益。

3. 向下全音转调

另一方面，在副歌处向下全音转调的曲目相当罕见。根据转调的普遍心理声学特性，下行转调难免伴随着情绪回落降温的风险。在此我们仅做简要的曲例分享。

这是《龙珠Z》的标志性主题曲《CHA-LA HEAD-CHA-LA》。其副歌处直接从E调转调到了D调。要彻底完成转调，必须打消掉附着在D音和G音上的升号。这首歌妙就妙在：它并没有依靠和弦的推力来牵引转调，而是突然来了一个急停静音（Break），仅凭一段电吉他独奏乐句强势换调！

贝斯线与和声织体瞬间抽空，调性骨架瞬间悬空虚化。此时果断切入带有还原D音的吉他短句，直接将乐曲一把拽进了D调的领空。而且这段吉他乐句写得极具巧思——硬要给它配和弦的话，它暗合了F♯m7 → Bm7的轮廓，即D调内部的3–6进行。正因如此，它才能丝滑无比地扎入D调的IV级和弦。

此外在这首歌中，早早在B段部分，D大和弦就已经作为♭VII级和弦提前亮相过了。从B段中途便有意将调性模糊化，为转调铺设温床。在重返主调时，它同样巧妙运用了“持续音（Pedal Point）”来虚化调性。

全音转调总结

上一讲探讨的半音转调由于调号变动过于庞大，战术上基本依赖“无论如何先硬砸出新调的V级”；而本讲的全音转调，调号位移仅为±2，两调之间存在共同和弦，因此展现出了声部更加细腻顺滑、控制更为微妙的手法。在实施转调时，仔细琢磨“在何种时机、以何种姿态推出音阶的新成员”，是制胜的关键。

总结

  • 全音转调在t轴（音高）与s轴（调号）上均为±2的温和位移。由于调号变化有限，其听觉冲击不像半音转调那般剧烈。当希望在副歌中更上一层楼展现明媚宽广的情绪时，向上全音转调尤为实用。
  • 在向上全音转调中，将通过品质改变引入的大VI级和弦重新解读为新调的V级和弦，是最经典的模式。
  • 在向下全音转调中，反向将V级重新解读为新调的VI级，则能促成自然的过渡。
  • 在转调前后两个调中均“共有”、可作为转调无缝接缝的和弦称为“枢纽和弦（Pivot Chord）”。“共有”在广义上指“可在两调中均获得合理解释”，狭义上则专指“必须同时是两调的自然音阶和弦”。
