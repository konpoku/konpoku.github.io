强力和弦（Power Chord）

和弦论扩展和弦、副属和弦与同主小调借音

本篇是一期专门解锁“全新和弦代号”的特色特辑。

这项技法主要以摇滚类流派为绝对核心，在古典和爵士乐中极少露面。然而其背后的减法哲学与声学思维完全可以广泛迁移应用到各大流派中；而且原理非常浅显易懂，非常推荐大家将其作为拓展武器库的实用技能牢记于心。

1. 省略音（Omit）

在第I章的“性质变换”中，我们探讨了将音符位置微调的“变位”技法。然而在音乐中，除了改变音高，还有一种更为决绝的操作——直接“把某个音抽掉”。本篇要介绍的正是这种“音的减法”。

将和弦中的某个构成音拿掉的行为，被称为省略（Omit）。“Omit”原本就是英语中表示“排除、省略”的日常词汇，算不上什么晦涩的专业黑话。 不过在正规和弦代号中，“omit”有着清晰严谨的写法：例如在 C 大和弦中拿掉三音（3rd），就会明确记作“Comit3”：

只有在需要向演奏者明确勒令“必须把该音抽离”时才会用到这种代号，因此平时的使用频次并不算太高。那么问题来了：人们究竟为什么非要大费周章地把和弦音抽掉呢？我们从这里开始深入探讨。

2. 强力和弦（Power Chord）

在所有省略音技法中，出镜率最高、最为举足轻重的莫过于抽掉三音的“omit3”。原因无他：因为这在整个现代摇滚乐领域中几乎是如同呼吸般普遍的绝对基石！在深入理论之前，先来感受一下它的真实声响吧！

伴随着电吉他猛烈的失真过载（Distortion），演奏出的 omit3 和弦散发出极其强悍、孔武有力的冲击力。正因如此，在摇滚乐的世界里，omit3 和弦被赋予了一个极具力量感的专属盛名——强力和弦（Power Chord / 五和弦）。 特别是在硬摇滚（Hard Rock）、朋克（Punk）以及重金属（Metal）等流派中，比起传统的大三/小三和弦，以强力和弦作为通篇骨架演奏的曲目多如牛毛；尤其在快节奏、充满冲击力的硬核乐曲中，强力和弦甚至占据着绝对压倒性的多数地位。

当作为摇滚强力和弦使用时，在和弦代号上通常极其简洁地标注为数字“5”。因为和弦构成音只剩下根音（Rt）与五音（5th），故以“5”命名：

由于在摇滚乐中强力和弦实在过于普遍，在很多实体乐队总谱上甚至懒得特意标出“omit3”或“5”，而是直接打印普通三和弦符号，然后在下方的吉他六线谱（TAB谱）上直接画出强力和弦的标准指法。

为什么摇滚音乐人会对强力和弦如此痴迷？这背后交织着几个极具趣味的跨时代历史背景……

演奏门槛极低，极易上手

首先最纯粹的原因：在吉他指板上按强力和弦实在是太简单了！

通常只需两到三根手指就能按出规整的强力和弦（甚至可以省略高八度重复的根音，仅用食指与无名指2根手指就能横扫琴弦）。只要掌握了这套固定手型，接下来只需在琴颈上整体左右平移滑行，就能瞬间弹奏出全天下12个音级根音的强力和弦！

这种极致的极简操作，客观上对20世纪后半叶摇滚乐在全世界年轻群体中的野蛮生长与光速普及，起到了功不可没的巨大推动作用。

性手枪乐队（Sex Pistols）于1977年发布的传世朋克名作《God Save The Queen》几乎全篇都由强力和弦筑成。尤其在 2:47 处的现场画面中，可以清晰看到吉他手仅仅保持着固定手型在指板上潇洒地平移滑行扫弦。

创作和弦进行变得轻而易举

三音（3rd）原本是和弦的灵魂命脉——它的半音位置直接决定了一个和弦究竟是“大和弦（明朗）”还是“小和弦（忧伤）”：

一旦把三音拿掉，C 与 Cm 就全都坍缩成了“C5”，原本的明暗属性荡然无存。然而对于很多对繁琐乐理一窍不通的摇滚青年而言，这反倒成了一大天降恩赐！因为如此一来，他们完全可以把“调内的 I、IV、V 是大三，II、III、VI 是小三”这套调性基本规则彻底抛诸脑后！

例如在 C 大调中写出 1-5-6-4 进行时，正统理论要求按 C - G - Am - F 排布，唯独第6级的 A 必须使用小三和弦。对于乐理小白来说这往往是极易踩雷绊倒的陷阱；但只要换成强力和弦，这一切顾虑烟消云散——直接无脑按出 C5 - G5 - A5 - F5，听起来依然霸气炸裂、无比和谐！这在当年究竟给朋克青年的创作带来了多么巨大的解放，可想而知。

清澈纯净的物理声响

另一个深层动因来自纯粹的声学物理特性：加了失真效果器（Distortion）的电吉他音色包含着极其庞大繁复的高频泛音成分，琴弦振动极其饱满炸裂。在如此浓郁的音色下，哪怕是 Do-Mi-Sol 这样规整的三度音程，泛音之间也会疯狂互相干涉打架，极易产生令人烦躁的混浊泥泞感：

对比钢琴与失真吉他的音色，吉他声部由于单音泛音过于华丽厚重，弹完整三和弦确实显得有些杂乱拥挤。而换用强力和弦，就能完美避开这种声学打架：

虽然舍弃了三音带来的明确明暗属性，但在硬核风格中这种模糊性反倒广受欢迎：它能避免小和弦过分幽怨凄凉的“小家子气”。例如在 1-5-6-4 进行中，从 V 走向 VIm 原本会让情绪明显滑向阴郁；但若换成强力和弦，整段音乐的骨力立刻变得干脆利落、刚劲明朗：

对古典高雅传统的叛逆

由于三音执掌着和弦的情感性格，在古典和声学中被严苛定性为“除非追求某种空洞的极端特殊效果，否则绝不可省略的灵魂核心”；在爵士乐理中同样被奉为最神圣不可侵犯的导向音，原则上绝不允许抽离[54]。

古典管乐严格保留三音

爵士编排中三音绝对必不可少

因此，悍然抽掉三音的声响在客观上天然构成了对上流高雅教条的公开反叛与决裂。这也从精神图腾的层面上解释了为何强力和弦会与摇滚乐的反叛灵魂达成如此天造地设的共鸣。

各个维度的现实条件汇聚在一起，最终将强力和弦推上了摇滚乐的王座。电吉他与音箱放大器的物理器材特性重塑了音乐语言——强力和弦背后蕴含着极具魅力的声学演进史。

调性引力在大脑中的自动脑补

或许有人会好奇：当和弦彻底丧失了大/小性质，真的能支撑起调性音乐的自洽运转吗？ 这正是人类大脑“认知机制”的高超之处：只要听者的潜意识中已经确立了调性大厦的引力场，大脑就会自动为缺失的三音进行“脑补填充”：

用全篇强力和弦弹奏卡农进行

这是以王道“卡农进行”为蓝本、全篇仅用强力和弦弹奏的音频。虽然没有任何一个三音，但结合前后上下文语境以及听觉记忆的调动，大脑依然能自动补全出原曲纯正的 C 大调风味！若上方再唱出旋律线，信息补全就会更加确凿。正如我们在前文所揭示的：听觉认知时刻受到“记忆与语境”的双重重构。

不过需要指出的是，如果在歌曲一开头孤零零地砸下一记 A5 和弦，初次聆听的听众是无法断定这首歌究竟是 A 大调还是 A 小调的：

A5 D5 E5

在这段极简范例中，连续排布了 A-D-E 三个强力和弦，依然无法判定调性虚实。后续究竟会如何展开？ 最符合预期的走向可能是切入 A 大调，使用带有3个升号的 A 自然大音阶：

A5 D5 E5

然而，它完全可能突然拐入 A 自然小调：

A5 D5 E5

创作者心中通盘知晓，但初听者是无法未卜先知的。这可能导致“以为很燃，结果很丧”的心理预期落差。因此在创作中清晰认知三音缺失所带来的双刃剑效应，是极为成熟的编曲素养。

3. 声学物理上的“合体”特质

在特定声学物理条件下，多个频率的声波交织重叠时，会在人类内耳中融合成一束浑然天成的超粗复合单音。失真吉他的强力和弦恰好完美契合了这一声学物理条件！因此，虽然吉他手手指按的是和弦，听起来却仿佛是一股被极度加粗加厚的大号单音：

这是按 6-7-1-2 根音走位的强力和弦范例。在第VII级位置按纯五度强力和弦时，其五音按物理关系必然会弹响一个带有升号的 F♯ 音。这显然是一个脱离了当前自然音阶的“调外离调音”。然而除非极度仔细分辨，听众根本不会察觉到有任何刺耳离调感，只会听到一条被极度加粗的“La-Si-Do-Re”粗壮旋律线顺滑推进！

如果缺乏这种声学物理常识，死读传统乐理的人可能会觉得“天哪，调内怎么能弹 F♯？太违和了，必须改成 Sol 或 Fa”；然而在物理现实中，无论是改成 Sol 还是 Fa，听起来反而会产生极其生硬刺耳的突兀违和！

改成 Fa 的反面教材

虽然只有细微差异，但后两者明显显得极其别扭。因此在这种物理语境下，弹奏 F♯ 才是唯一真正符合音乐听觉审美的正解。传统教条派可能会指责这是“弹错了调外音”，但立足于声学物理，弹奏纯五度强力和弦具有绝对无懈可击的正统性。

这再次雄辩地证明：音乐理论不能仅仅在五线谱纸上谈兵。声音在空气中振动的物理声学现实才是终极标准，请永远不要忘记亲手按下琴键、用耳朵去验证真实听感的重要性！

4. 用强力和弦弹奏标志性连复段（Riff）

在摇滚乐中，贯穿全曲反复洗脑演奏的特色旋律被称为连复段（Riff）：

面对这些一旦听过就终生难忘的洗脑乐句，当旋律速度适中时，乐手们通常会直接把整条单音旋律全盘用强力和弦加粗演奏：

此时它听起来已经不再是单纯的伴奏和弦，而是一条被浇筑了强劲物理力量的钢铁主旋律。这正是强力和弦那“合束为一”的独特声学魅力。

强力和弦虽然以摇滚乐为主战场，但其蕴含的“通过省略三音打造中性超然质感”、“将多音聚为一束制造震撼气势”的减法哲学，在影视配乐、现代电子乐中同样具备辽阔的借鉴空间。学会了加法之后再驾驭减法，你的和声格局必将跃升至全新维度！

总结

  • 将和弦中的某个音刻意抽离拿掉的操作称为“省略（Omit）”，用“omit”进行标记。
  • 从大/小三和弦中将三音（3rd）省略后构成的五度和弦被称为“强力和弦（Power Chord）”，通常记作数字“5”，是现代摇滚乐的核心支柱。
