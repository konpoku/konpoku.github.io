近亲调（相关调）

本篇是一期专门“理清乐理术语”的知识特辑。

我们在准备篇中系统学习了“调性（Key）”，本篇将进一步探讨调与调之间的亲疏关系。例如在发生离调或转调时，分析“究竟转到了何种关系的调”便需要借用这套专属术语。它主要是为下一篇的内容做前置知识铺垫，无需死记硬背，了解其内在脉络即可。

1. 庞大的调性家族

在十二平均律中一共有 24 个大小调：包含黑键在内从 Do 到 Si 共有 12 个音，每个音分别对应一个自然大调和一个自然小调，总计 $12 \times 2 = 24$ 个调。在这 24 个调之中，有些调与当前调性血缘极近，有些则天各一方极为疏远。 因此在音乐理论中，将血缘亲近的调统称为近亲调（Closely Related Key / 相关调）；将关系疏远的调统称为远关系调（Distant Key / 远隔调）。本篇的核心任务，就是逐一盘点这些“近亲调”。

2. 四大近亲调

近亲调共有4类。它们的共同特征在于：各自都与基准调性维系着极高密度的相同构成元素。

主调（Tonic Key）

所谓“关系”必然是相对而言的，作为衡量基准的核心调性被称为主调（Tonic Key）。在本篇中，我们以大家最熟悉的“C 大调”作为主调展开论述。

同主音调（Parallel Key）

调式中心音（主音）相同、唯独大小调性质相反的调被称为同主音调（Parallel Key / 同名调）。例如对于“C 大调”而言，其同主音调正是“C 小调”。简而言之，就是中心音不动，直接将大调与小调属性对调。

更细致地说：当主调为大调时，其同主音调必然是小调，因而该调亦具体被称为同主音小调（Parallel Minor Key）；反之，当基准主调是小调时，其对应的同主音调则被称为同主音大调（Parallel Major Key）。

关系大小调 / 平行调（Relative Key）

调号完全一致、由关系音阶构建而成的调被称为关系大小调（Relative Key / 平行调）。

请特别注意：中文乐理中的“平行调”在传统上常被用作 Relative Key 的同义词，极易与“同主音调（Parallel Key）”字面混淆。其核心判据在于：调号（升降号数量）完全相同。对于“C 大调”而言，其关系大小调正是“A 小调”。 回忆准备篇中讲过的“关系音阶（Relative Scale）”——因为采用的是完全同一套音阶物理音符，所以被称为关系调。

属调（Dominant Key）

以原调的属音作为全新主音领袖的调，被称为属调（Dominant Key）。

在 C 大调中，“属音”是哪个音？从主音向上数5个音级的音被称为属音：Do-Re-Mi-Fa-Sol，显然是“Sol（G）”。以该 G 音为领袖构建的调——即“G 大调”，便是 C 大调的属调。

下属调（Subdominant Key）

以原调的下属音作为全新主音领袖的调，被称为下属调（Subdominant Key）。

在 C 大调中，“下属音”是第4音级 Fa（F）。因此以该 F 音为领袖构建的“F 大调”，便是 C 大调的下属调。

3. 五度圈上的近亲地图

若想迅速查找任意调性的关系大小调、属调与下属调，再次大显神威！ 因为这三大近亲调在几何位置上全都被紧紧环绕在主调的身旁：

在五度圈上，主调的顺时针紧邻邻居是属调，逆时针紧邻邻居是下属调；处于同一径向扇区内圈的，正是其关系大小调。 正因如此，五度圈呈现出一条美妙的物理法则：“属调”比原调恒多出1个升号（或少1个降号）；“下属调”比原调恒多出1个降号（或少1个升号）。

至于同主音调（Parallel Key），虽然理论上只需将大小调属性对调，若想在五度圈上视觉定位，它则稳稳坐落在逆时针旋转 90° 的位置：

无论以哪个调为主调，这一几何规律分毫不差。

虽然介绍了这四大近亲调，但坦白说在日常创作中这一纯理论知识的直接调用频次并不算太高，更多活跃在古典乐曲式分析与严肃转调研究中。日后当碰到“某某调”等学术名词时，只需回忆起“曾经学过这篇”，随时回过头来速查对照即可。

最后将四大近亲调汇总对照如下：

中文术语 英文术语 核心判据
同主音调 Parallel Key 中心主音相同，大小调性质相反
关系大小调 Relative Key 调号完全相同，中心主音不同
属调 Dominant Key 以原调第5音（属音）为主音
下属调 Subdominant Key 以原调第4音（下属音）为主音

[!NOTE] 语言翻译的跨文化趣闻：在英文中，“同主音调”被称为 Parallel Key，而“Parallel”字面直译正是“平行”；但德语古典和声学中却将“关系大小调”称为 Paralleltonart，早年东方乐理部分从德语直译，导致中文和日文中“平行调”常被指代为 Relative Key，造成了英德术语间的倒错[55]。在阅读外文资料时需留心分辨。

总结

  • 与特定基准主调血缘关系最为深厚紧密的调性，统称为近亲调（相关调）。
  • 近亲调主要涵盖同主音调、关系大小调、属调、下属调四大类。
